# 参考版本继承

用户提供旧提示词、旧视频或修改意见时，先建立版本继承表，再设计新方案。

## 五类标记

- 锁定成功项：已验证有效，除非与新要求冲突不得修改。
- 必须保留：剧情、台词、动作结果、角色身份、空间事实等硬约束。
- 仅参考：镜头气质、节奏、表演强度或特效风格，只学方法不照抄内容。
- 允许修改：构图、焦段、运镜、动作细节、环境反馈或时长安排。
- 已失败项：拖镜、穿帮、错误指代、动作不清、特效无因果、口型重启等，禁止继承。

## 执行

1. 给每个来源标注版本和优先级。
2. 把用户最新明确指令设为最高优先级。
3. 成功项按元素继承，不整段复制旧提示词。
4. 新方案逐项说明保留、修改和删除的原因。
5. 冲突无法同时满足时向上游报告，禁止默默覆盖。

可复制 `assets/revision-state.template.json`。
