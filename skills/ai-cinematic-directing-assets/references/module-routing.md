# 关键词与模块路由

关键词检索只解决“可能需要什么”，场景诊断负责判断“到底该不该用”。机器可读索引见 `assets/directing-module-catalog.json`。

## 四步调用

1. 从剧本动作、台词状态、场景说明和用户反馈提取标准关键词。
2. 在索引中召回候选模块，允许同一关键词命中多个候选。
3. 对每个候选核验“使用条件”和“禁用条件”。不满足时记录未调用原因。
4. 在满足条件的模块中选择能覆盖当前剧情功能的最少集合。

## 优先级

`用户最新明确要求 > 不可修改剧情事实与台词 > 场景诊断 > 连续性与物理因果 > 专业模块建议 > 风格装饰`

## 典型消歧

- “拔剑”：若只是亮出武器并说话，候选为刀剑对峙；只有出现挥砍、突刺、格挡或闪避才进入刀剑交锋。
- “震惊”：优先判断角色看到了什么，再选择反应递进；不能直接套瞪眼张嘴。
- “鬼”：若鬼尚未攻击，优先恐怖揭示；若发生追赶，增加追逐；若能力释放，再增加异能因果。
- “慢动作”：只有关键受力、能力规则或决定性瞬间需要时间放大时使用，普通打击和反应禁用。
- “长台词”：冻结完整语言单元，再按动作触发、语义和反应变化拆成多个逐镜原文片段；第一片段动作触发开始，后续片段无停顿承接，不把整个分镜组写成一个长镜头。

## 输出调用记录

```text
候选关键词：拔剑、威胁
召回候选：刀剑对峙、刀剑交锋、威胁表演
实际调用：刀剑对峙、威胁表演
未调用：刀剑交锋；原因：双方尚未挥砍、突刺、格挡或闪避
```

## 基础导演能力与条件模块

叙事视点、信息边界、镜头主体与动静选择是每场基础判断，不等待关键词触发。双人及多人关系、画幅适配和注意力交接按场景需求加载。候选模块的“参考文件”指向具体执行规则；画幅与视觉形态独立组合，不能仅因“3D”自动调用环绕、夸张表演或特效。
