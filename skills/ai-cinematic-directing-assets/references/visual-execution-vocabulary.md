# 画面执行表达库

本库用于把抽象导演意图写成视频模型能执行的画面语言。它提供选择维度，不规定固定镜头数、固定15秒、固定台词字数或必须使用的特效。

## 四层摄影表达

每镜按需要分别写清，禁止混成一句“电影感运镜”：

1. 景别：特写、近景、中近景、中景、中全景、全景、远景，用来决定观众读表情、动作还是空间。
2. 摄影机位置：平视、俯拍、仰拍、顶拍、低机位、高机位、斜侧、过肩、主观视角，用来建立关系和权力。
3. 主要运镜：固定、推近、拉远、横移、跟拍、环绕、升降、摇摄、甩镜。每镜只保留一个主要运镜，写明起点、方向、速度变化、停止点和最终焦点。
4. 光学与时间手法：焦点转移、景深变化、变焦、慢动作、定格等。只有剧情确实需要时使用，不能代替人物表演。

## 动作与表演句法

有效动作至少包含：`主体标准名称 + 起始状态 + 身体路径或发力 + 接触对象 + 结果状态`。人物镜头再加入一至两个可见微动作，例如手指收紧、喉结滚动、呼吸变浅、重心后撤、视线先移向出口再回到对方。

情绪不能只写“激动、恐惧、愤怒”。要写情绪如何出现在眉眼、嘴角、呼吸、肩颈、手部、步态和说话策略中。说话者开口时，听者和其他画面内人物依据自己已获得的信息产生克制反应；没有任务的人物移出画面。

## 特效与光影

- 光线首先继承场景资产和全局色卡；轮廓光、逆光、体积光、闪烁或反射必须有现场光源。
- 动作特效必须有来源、路径、接触、受力结果、环境反馈和消散。刀光、粒子、尘土、水雾、碎屑或速度线不能脱离实际动作单独出现。
- 情绪性粒子、回忆柔光、闪白、黑场和慢动作只在叙事转折需要且不会覆盖关键信息时使用。
- 特效直接写进发生的计时镜头，环境音写在对应镜头末尾，动作音与接触同时发生。

## 转场

淡入淡出、叠化、声音先行、声音延续、动作完成点、视线匹配、道具或构图匹配、甩镜和遮挡转场都必须有可见或可听依据。上一镜的结束状态必须成为下一镜的开始状态；组间还要更换镜头签名，默认禁止同一人物特写硬接同一人物特写。

## 明确不吸收的僵化规则

- 不强制每段15秒或每段5—6镜；服从当前模型上限和完整事件。
- 不按固定字数公式拆对白或内心独白；使用实际试读，第一片段由动作触发，后续片段无停顿承接。
- 不把2—3秒动作镜头、3—4秒慢情绪镜头当硬模板；普通镜头仍以项目既有规则为准。
- 不因资料列出了效果词就逐项堆叠；任何技巧都必须回答“为何此刻需要、资产空间是否允许、切镜后如何继承”。
