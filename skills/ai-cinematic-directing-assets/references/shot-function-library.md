# 镜头功能库

镜头必须先有功能，再选择景别和运镜。一个镜头可以有一个主功能和一个辅功能，但不能同时承担过多任务。

## 通用功能

- 建立空间：交代出口、障碍、人物距离、危险来源和行动方向。
- 建立关系：用同框、前后景、肩后视角或高低位置说明亲疏与权力。
- 引导注意：从环境、道具或视线转向信息核心。
- 揭示信息：让观众第一次清楚看到关键人物、物件、UI或变化。
- 保留信息：遮挡、浅景深、画外声或局部构图延迟揭示。
- 反应验证：用另一人物的可见反应证明事件强度或关系变化。
- 权力转移：通过站位、景别、机位高度、进退和注视改变强弱关系。
- 动作准备：交代重心、手部、武器轨迹、目标和发力方向。
- 动作结果：清楚展示位移、破坏、受力、落点和余波。
- 情绪转折：在呼吸、眼神、肌肉、姿态或声音变化时靠近人物。
- 喜剧回收：给反差或误会后的明确反应，不重复解释笑点。
- 结尾钩子：在新危险、异常信息、人物决定或未完成悬念上结束。

## 删除或合并条件

- 与前后镜头重复同一信息，没有新的表演或空间变化。
- 只展示人物站着、看着、等着，期间没有情绪、视线、声音或摄影变化。
- 只是为了换景别而换景别。
- 需要依靠后期删掉前摇或拖延尾巴才能顺畅。
- 破坏完整台词、动作链或反应链。

## 常见功能组合

- 对峙：空间建立 → 威胁细节 → 被威胁者反应 → 权力关系定格。
- 长台词：关系建立 → 情绪转折靠近 → 听者反应与结论落点。
- 打击：动作准备 → 释放路径 → 接触或闪避 → 环境反馈 → 结果反应。
- 恐怖揭示：正常空间 → 异常细节 → 角色察觉 → 延迟揭示 → 反应或危险逼近。
- 喜剧：正常预期 → 反差台词或动作 → 短促反应 → 关系恢复或升级。

这些是功能顺序参考，不是固定镜头数量模板。
