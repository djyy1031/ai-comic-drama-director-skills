# 摄影语言到画面描述

选择镜头后按本镜实际用到的类别查阅，不把全表塞进提示词。焦段、景别、机位、运动、焦点和时间分别决定；每项专业选择都用具体画面结果表达，数字和术语只作辅助。不穷举每个毫米数，相邻焦段按视角、实际机位与目标构图推导，不能把未列数字随意归为神奇的独立效果。

## 通用编译顺序

先确定剧情功能和此刻主体，再确定摄影机位置与取景，然后选择需要的光学与运动。内部保留使用时机、理由、执行条件、拍法、衔接和有需要的简化方案；最终只写本镜选择的执行描述。

句式：`焦段或拍法；摄影机位于何处、朝向哪里；画面拍到哪些部位、主体与背景如何排列；哪些内容清楚；具体事件发生后摄影机或焦点如何变化；停在哪个画面。`

只补能区分当前拍法的必要信息。例如“中景”需说明腰部以上与关键手势；“过肩”需说明谁的哪侧肩膀及被看人物；“推近”需说明相机前移和起止构图。不能用“高级、自然、电影感、压迫感”代替上述内容，也不要求固定镜头编造运动路径。

## 焦段与机位距离

以下按全画幅等效视角作沟通参考，不保证生成模型模拟真实光学。画幅、传感器或虚拟摄影设定不同会影响取景；最终以描述的画面结果与已确认资产为准。项目已锁定的摄影基准继续保留；已选择的写实3D国漫预设默认50mm，其他3D风格、2D和仿真人均按自身项目基准执行。其他焦段局部声明，不改整组基准。

**共同条件**：透视首先受观察位置影响。相同机位换焦距主要改变取景与放大倍率；保持人物在画面中差不多大、同时调整摄影距离，才会形成常见的广角近摄与长焦远摄比较。背景“更近、更小”指视觉关系，不能把墙、门或人物模型真的移动和缩放。

| 参考焦段 | 可选用途与条件 | 可执行的大白话示例 | 避免误写 |
| --- | --- | --- | --- |
| 14—20mm超广角 | 环境尺度、近处障碍与深处目标同时重要；可见空间需有依据 | 摄影机设在门内低处，近处门框占两侧，人物全身在中景，走廊尽头仍可见，地面线条向深处汇聚 | 不自动鱼眼弯曲，不把脸贴边，不新增未见房间 |
| 24—28mm广角 | 人物与环境互动、近距离空间压力 | 从人物侧前方较近处取上半身，两侧环境仍入画，近处手臂比后方门框更突出，纵深明显 | 近摄效果不适用于所有远机位；不得拉长身体 |
| 32—40mm中等广角 | 双人关系、走位和环境线索 | 摄影机退至能容纳两人膝部以上的位置，两人之间的距离、手部动作和身后出口同时可读 | 不规定35mm只能全景；近拍脸仍可能强调透视 |
| 45—55mm标准视角 | 常规关系与行为观察 | 摄影机位于坐姿眼高，拍到腰部以上和桌面双手，脸部为主体，后方门的位置可辨 | 不宣称50mm必然自然、无畸变或背景全清晰 |
| 65—85mm中长焦 | 较紧的表演取景、单人反应 | 摄影机在较远的斜侧位置，取胸口以上，脸与肩为主，减少两侧杂物；背景保留轻微虚化的地标轮廓 | 景别与虚化须单独指定；不因85mm自动给特写 |
| 100—135mm长焦 | 从远处观察、隔离主体或紧凑背景 | 在较远可用机位取胸口以上，远处窗框相对人物显得较大，前后间隔在画面里较紧；窗框实际不动 | 不把空间压缩写成房间缩短，不默认背景全糊 |
| 180—300mm及更长 | 远距离观察、人群中选择特定主体；需要足够机位距离 | 从远处取人群中一人的肩部以上，视野窄，经过的近处人物短暂遮住画面边缘，目标重新露出后仍在原位置 | 不用于无退让空间的狭小房间，不凭焦段新增遮挡人物 |

微距与鱼眼是拍摄能力或投影特征，不是上述焦段序列的必然终点：

- **微距**：只有极小关键细节需要读取时使用。写“画面只容纳指尖和戒指表面，刻痕占据主体，周围手掌自然落到画外，焦点停在刻痕”；不把戒指实物变大，不用细节代替动作因果。微距可有不同焦段，仍守非脸部特写时长限制。
- **鱼眼**：只在明确需要弯曲空间的主观或风格镜头中使用，写“画面中央人物可辨，四周直线向边缘弯曲”。不能把所有超广角当鱼眼；不得以该风格破坏既定角色身份或资产结构连续。
- **变形镜头风格**：有项目依据才描述横向光学特征、椭圆散景等，耀斑需有对应亮光源；不拉宽脸、不自动加黑边、不靠术语承诺电影感。

## 景别转成取景范围

| 景别或构图 | 本镜应写出的画面 | 导演选择依据 |
| --- | --- | --- |
| 大远景 | 人物全身很小，环境占绝大部分，明确人物在地标哪侧 | 环境与处境比微表情更重要 |
| 全景 | 人物从头到脚完整入画，脚下接触、行动路线与目标可见 | 交代走位、空间或完整身体动作 |
| 中全景 | 取膝部以上，保留重心、双手与人物间距 | 行为和关系同时重要 |
| 中景 | 取腰部以上，说明关键手势是否在画内 | 对话中的身体任务或双人互动 |
| 中近景 | 胸口以上，肩颈与脸部清楚，说明双手是否画外 | 读取判断与克制反应 |
| 近景或脸部特写 | 明确取肩部以上或脸占主体，眼睛与嘴部保持可读 | 关键心理落点；不能每句自动贴脸 |
| 极近特写 | 只取眼部、嘴角或道具指定局部，保留身份和动作依据 | 局部信息确实改变观众理解 |
| 双人或群体关系镜头 | 说明谁在前后左右、取到哪里、哪些反应必须同时看清 | 同框不是景别，需另写范围与层级 |

不同资料的景别叫法不完全统一，身体范围比名称更明确。不要只给“主体占40%”而不说明拍到什么；没有必要不堆精确百分比。

## 机位、视点与构图

| 术语 | 应写成什么 | 条件与误用 |
| --- | --- | --- |
| 平视 | 摄影机接近当前人物眼高，镜头大致水平，说明所见侧脸或正面 | 坐姿和站姿的眼高不同 |
| 低机位仰拍 | 摄影机低于人物眼睛，朝上看脸与上身，说明是否保留下巴下方和上部空间 | 低机位不等于贴地，强势须由上下文支持 |
| 高机位俯拍 | 摄影机高于人物眼睛向下看，头肩与脚下空间按需入画 | 不自动把人物拍成弱者，不虚构高处平台 |
| 顶拍 | 摄影机在主体上方近乎垂直向下，头顶、桌面与座位关系清楚 | 需要俯视区域证据，不适合靠正脸读微表情 |
| 正面、斜侧、侧面 | 分别说明两眼均可见、脸一侧更多可见、主要看见侧脸轮廓，并写视线目标 | 角色面朝镜头不等于看镜头，不能无因直视观众 |
| 过肩 | 摄影机在甲指定肩后，甲肩膀占某侧前景小部分，乙面部清楚位于中景 | 明确肩位与轴线，不能遮住关键脸和手 |
| 纯单人画面 | 只取当前人物，前景不带另一人的肩部，交代真实视线方向 | 去掉前景不表示另一人已离场 |
| 角色主观视角 | 摄影机位于该角色眼睛观察位置，沿该角色视线看向已知目标 | 不是普通过肩；眼高、遮挡、可见范围须吻合 |
| 倾斜构图 | 画面地平线倾斜，门框也呈斜线，人物身体仍保持真实重力 | 相机滚转不是世界倾倒；只在有主观或风格依据时使用 |
| 框中框或遮挡 | 用已有门框、窗缘或肩膀围住人物，说明遮住哪里、露出哪里 | 不为了构图增加建筑结构 |
| 负空间、对称 | 明确人物偏哪侧、空白留给哪个目标；或人物与建筑围绕中线排列 | 空白不等于必须有人出现，对称不必然表达权力 |

## 摄影机运动与光学变化

每次运动都结合剧情触发和起止画面。下表只说明区别，实例中的人物与物件必须换成当前已核验的实际对象；不得因表里出现就新增事件。

| 拍法 | 大白话执行方式 | 主要收益与边界 |
| --- | --- | --- |
| 固定 | 摄影机位置、朝向与焦距不变，由人物动作或注意力推进画面 | 不给无任务固定镜头套轻微漂浮 |
| 推近 | 摄影机朝人物实际前移，从胸口以上收至更紧脸部构图，背景相对变化，决定形成时停住 | 让观众经历靠近；不是仅放大画面 |
| 拉远 | 摄影机实际后退，从单人近景逐渐显露双方距离及已有环境 | 揭示处境；路线与新露区域需已知 |
| 横移 | 摄影机沿人物侧方平移，近处门框相对后景滑过，露出原先被遮住的主体 | 用视差和遮挡揭示；不是原地摇头 |
| 摇摄 | 摄影机原地向左或右转，取景从甲转到乙，位置不变 | 连续转移注意力，停止方向明确 |
| 俯仰摇摄 | 摄影机位置不变，从手部向上转到面部，或从面部向下转到目标 | 垂直注意力变化，不等于摄影机升降 |
| 升降 | 摄影机整体升高或降低，交代朝向是否保持、前景遮挡如何改变 | 跟随起身或揭示层次；不是只转镜头 |
| 后跟、前领、侧跟 | 分别从人物后方同向前进、人物前方后退、人物侧面平行移动，写清间距和停点 | 选择要看目标、面部还是步伐，不统称跟拍 |
| 弧线移动 | 摄影机沿人物周围一段明确弧线，从斜前方移到侧方，始终说明轴线侧与背景变化 | 关系或观察角度变化，不自动转满一圈 |
| 高位或摇臂式移动 | 从已知高处向低处或反向移动，写路线及由环境转向人物的构图变化 | 器材名称不能代替路线，不穿越屋顶 |
| 手持感 | 指定小幅受控的不规则扰动，主体仍可辨，冲击后恢复稳定 | 服务主观压力，不持续随机乱晃 |
| 甩镜 | 摄影机原地快速转向，途中短暂方向性模糊，停在新主体后立即清楚 | 突发注意力；方向、终点与模糊范围明确，局部需兼容全局规则 |
| 变焦 | 摄影机位置不动，视野逐渐收窄或扩大，主体与背景一起被放大或缩小取景 | 观察式强调，不写成机位接近或透视改变 |
| 推拉变焦 | 摄影机后退同时收窄视野，主体大小基本维持，背景相对主体逐渐显大；或前进配合扩大视野取得反向效果 | 仅关键心理转折，属于一个协调光学效果；遵守项目对复合拍法的允许范围，受限时用切近或单纯推近替代，不擅自豁免 |

慢推不一定从台词第一字开始，固定也不一定持续整组。不要把“远离主体的机位”误写成摄影机正在后退；不要把“空间显深”写成背景向后运动。任何方向按当前场景与屏幕关系明确，不只写抽象的前后左右。

## 焦点、景深和时间表达

- **浅景深**：写哪个人物或物件清楚，哪些前后对象柔和模糊、仍需保留哪些轮廓。多人反应同时重要时不可全部抹掉；不只给光圈数字。
- **深景深**：写前景手部、中景人物与后景门口都能辨认，按任务选择范围；不是所有纹理一律同样锐利，也不能靠锐化生成未知细节。
- **转焦**：摄影机不动，先清楚的甲逐渐变虚，乙逐渐变清楚，写交接触发与停止焦点。相同焦平面上的两个人不宜只靠真实转焦选择，应换取景或遮挡。
- **失焦再恢复**：确有主观视觉异常时，写清短暂模糊的对象、持续进程与恢复目标；不能让人物变形或当作一般转场。
- **慢动作**：写清被延长观看的具体动作和可读变化，例如布料受力、脚步落点；属于呈现速度改变，不能无因增加动作或延长台词。对白速度按既定声音方案，不随动作自动拉慢。
- **定格**：明确停住哪一刻的画面及声音是否延续；只有原文或上游允许的风格需求才用，不拿静止画面凑时长。
- **运动模糊或清晰断续感**：需要时描述运动轨迹短暂拖影或快速动作边缘较清楚的观感，不只写快门角度；关键接触仍需读清，局部与全局画质限制冲突时先解决。

## 接到下一镜

硬切要写下一镜主体、取景与被接管的信息；视线匹配要写先看哪里、后镜展示什么及对应眼高；动作匹配写准确动作阶段并遵守项目禁切边界；形状匹配要有真实可见形状而非仅说“高级转场”。声音先行和延续写来源、跨越哪个切点及后期安排，不把下一组画面或声音混进本组正文。可参考已有叙事与剪辑库，不另设机械衔接套路。

## 组合与冲突检查

一镜只选完成任务需要的参数与效果。禁止把各表的一行任意相加，例如固定机位却写前移、顶拍却要求正脸、强浅景深却要多人不同距离都清楚、未说明协调效果却又推又变焦。

最终遮住专业名词与数字，文字仍应能回答：看见谁和哪些身体部位、机位在哪里、空间是什么样、谁清楚、镜头如何改变、哪里停。未知焦段按上述物理维度推导，不能照搬邻近数字的情绪标签。若具体模型未能实现，依据实际失败简化拍法，不预先声称模型不懂或保证执行。
