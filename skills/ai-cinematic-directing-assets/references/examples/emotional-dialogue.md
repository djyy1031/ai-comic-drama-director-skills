# 案例：长台词情绪递进

完整台词：“张三，你知道吗，李四为了你放弃了一切。而你却为了一己私欲，亲手把李四害死了！”

诊断：主类型为关系争执，主要功能是情绪升级与指控，视觉优先级为脸部表演和听者反应。完整原文冻结为同一语言单元；最终语言直接分配进正常计时镜头。

语言单元 DIALOGUE-01：由张三完整说出原文，语气从克制转为愤怒；所有逐镜片段依序拼回完整原文，切镜时不重新起句、不重启呼吸。

建议镜头顺序：

1. 3 秒，双人中景建立两人的距离与关系；张三把证物按在桌面后开始说：“张三，你知道吗，”。
2. 3 秒，李四肩后看张三的中近景；张三无停顿承接上一镜继续说：“李四为了你放弃了一切。”
3. 3 秒，张三近景缓慢靠近，下颌收紧、呼吸加重；张三无停顿承接上一镜继续说：“而你却为了一己私欲，”。
4. 3 秒，切李四反应；张三声音作为画外连续声无停顿承接，完成：“亲手把李四害死了！”

四个镜头的原文片段顺序拼接后逐字等于完整台词。具体起止时间由上游根据实际试音连续排布。

禁止：把前半句放在一个分镜组、后半句放到下一组；每次切镜重新起句；为凑时长添加无信息的沉默。
