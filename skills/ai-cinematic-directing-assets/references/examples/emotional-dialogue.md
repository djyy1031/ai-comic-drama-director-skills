# 案例：长台词情绪递进

完整台词：“张三，你知道吗，李四为了你放弃了一切。而你却为了一己私欲，亲手把李四害死了！”

诊断：主类型为关系争执，主要功能是情绪升级与指控，视觉优先级为脸部表演和听者反应。完整原文冻结为同一语言单元；最终语言直接分配进正常计时镜头。

本例说话者为王岚，听者为张三；原文提及的李四已死亡，不入镜。假定本场已确认两人在桌旁，证物在王岚手边。情绪判断留在内部，正文用下颌、视线、手部与说话节奏表现。所有语言片段拼回完整原文，切镜不重新起句；不照搬本例人数、拍法或时长到其他剧本。

建议镜头顺序：

1. 双人腰上中景，摄影机在桌侧固定拍摄，王岚、张三和桌面右手都可见。王岚右手把证物按向桌面，同时对张三说：“张三，你知道吗，”声音压低，目光停在张三脸上。张三原先伸向证物的左手停住。
2. 王岚胸上中近景，张三右肩在前景。摄影机在张三右肩后方，王岚说到“放弃了一切”时沿桌侧空隙缓慢靠近，停在王岚肩部以上。王岚继续说：“李四为了你放弃了一切。”下颌收紧，嘴角绷住，话尾加重；镜头让观众逐渐靠近指控者的反应。
3. 王岚腰上中景，摄影机在桌侧固定拍摄，脸和右手同框。王岚继续说：“而你却为了一己私欲，亲手把李四害死了！”右手掌仍压着证物，身体向桌前倾，眉间收紧；“亲手”短促加重，不新增拍桌动作。
4. 张三肩上近景，摄影机在王岚身旁固定拍摄。张三看着王岚，眼睛短暂眨一下，嘴唇张开又合上，肩膀向后收；没有新增回答。此处反应的长短由原文节奏和实际表演决定，不补无信息空等。

前三镜的原文片段顺序拼接后逐字等于完整台词。具体起止时间由上游根据自然表演和实际试音排布，不固定三秒一镜。

禁止：把前半句放在一个分镜组、后半句放到下一组；每次切镜重新起句；为凑时长添加无信息的沉默。
