# 场景诊断与导演意图

先回答“这场戏为什么存在”，再决定镜头。场景可以有多个类型，但必须选一个主类型和一个主要剧情功能。

## 主场景类型

- 对话与关系：告白、试探、争执、谈判、安慰、审讯、喜剧互怼。
- 悬念与恐怖：异常出现、危险逼近、身份揭示、误导、惊吓回收。
- 动作与武打：对峙、起手、交锋、压制、反转、终结、余波。
- 追逐与逃生：发现威胁、启动、障碍、距离变化、脱险或被截停。
- 奇观与异能：能力展示、能量释放、环境改变、规则验证。
- 信息与系统：规则宣布、界面反馈、消息读取、任务选择。
- 日常与喜剧：人物关系铺垫、反差、误会、包袱、反应回收。

## 主要剧情功能

从以下选择一个主功能，允许最多两个辅功能：建立空间、建立关系、传递信息、隐藏信息、制造疑问、升级冲突、改变权力、完成动作、揭示结果、释放情绪、制造笑点、留下钩子。

## 必须诊断的变量

- 战斗是否已开始：`未开始 / 临界 / 已开始 / 已结束`。
- 当前优势方与优势来源。
- 观众此刻已知、角色已知和需要隐藏的信息。
- 情绪起点、转折点、落点。
- 视觉优先级：脸部表演、身体动作、空间关系、道具、特效或UI。
- 本组不可切断的连续单元：完整台词、动作链、视线交换或环境变化。
- 连续性风险：轴线、左右位置、朝向、持物手、服装状态、光区、道具状态、声音延续。

诊断结果只用于选模块，不得成为新增剧情的依据。
