# 人物表演系统

只选当前事件真正需要的信号。目标是让人物像在解决问题，而不是让脸部轮流展示情绪。

## 五项场景动力

1. **当前目标**：角色此刻想让具体对象做什么。写“迫使掌柜承认撒谎”，不写“表现愤怒”。
2. **阻碍与代价**：谁或什么挡住目标；失败会失去什么。代价必须来自原文事实或已经冻结的人物设定。
3. **策略**：角色当前采用的办法。策略必须是能表演的动作动词，例如试探、讨好、羞辱、诱导、拖延、施压、恳求。
4. **表演节拍**：策略失败、新信息到达、权力变化、距离变化或人物作出决定时换节拍。完整场景常见 2—4 次变化，但不为了数量硬拆。
5. **潜台词**：台词表面与真实目的之间的差异。潜台词通过目标和行为泄露，不让角色直接“演潜台词”。

## 听与反应

- 听者不是等待说话的空白人物。理解对方意图后，视线、呼吸、手部或姿态可在话尾之前先变化。
- 困难回答前先出现极短的判断、吞咽、避视、吸气或决定，再开口；立即以同一速度回答会像背台词。
- 重要消息需要“消化时刻”，但停顿中必须发生判断、拒绝、控制或决定，不允许无内容静止。
- 对方的音量和速度变化会改变听者的身体状态；听者不一定同样提高音量，也可以用更安静的反应夺回权力。
- 反应镜头承载说话者画外连续音时，只改变画面归属，不重复台词。

## 身体、任务与距离

- 先定义重心、动作速度、开放或封闭姿态、呼吸，再选择面部细节。
- 人物可一边完成原文允许的实际任务一边交谈。手上有真实任务能减少舞台式乱比划。
- “中断任务”是表演标点：人物一直切菜、写字或擦桌，听到关键信息后突然停住，说明这句话改变了人物。
- 距离变化必须有动机。靠近可能是施压或求助，退开可能是防御或关系断裂，站起可能是夺权，坐下也可能是拒绝被带节奏。
- 人物地位通过行为呈现。控制者通常动作更少、停顿更从容、注视更稳定；弱势者可能碎动作更多、频繁自触或用眼神请求许可。反常变化是剧情事件，不能滥用。

## 眼神生命

- 眼睛有明确目标，并随思考在人物、道具、出口或危险点之间自然转移；禁止整镜冻结盯住一点。
- 眼睛通常略早于头部到达新目标，让思考先于转头可见。
- 眨眼频率与状态一致：压力下可能出现短促眨眼，控制时可以更慢更少；“几乎不眨眼”仍需有缓慢、有意图的视线移动。
- 近景越紧，动作越少。特写优先保留眼神、呼吸和决定，不堆眉毛、嘴角、点头和手势。

## 表演DNA与单场适配

长期角色可建立表演DNA：身体基线、说话节奏、固定习惯及触发条件、掩饰方式、面具破裂条件、走路方式和锁定声线。它是跨集资产，不直接塞进每个镜头。

单场适配必须：

- 只保留当前姿态、任务和节拍能实际发生的行为。
- 不能发生的习惯要转换出口，例如爱踱步的人坐着时可转为脚尖压力、纸张折叠或身体微摆，但不能凭空删除其紧张动力。
- 习惯动作必须有触发条件，不能每镜重复成为机械招牌。
- 强烈状态具有惯性。受到威胁后的呼吸、僵硬和警惕必须进入后续镜头，直到发生足以改变状态的新事件。

## 群戏

- 所有入画人物都必须有表演任务。主角承担主要信息和动作；次要人物与背景人物使用更克制的视线、呼吸、手部、姿态或正在进行的生活动作回应现场。
- 背景人物只对自己实际看见、听见和知道的信息作出反应，不能提前表现后续剧情，也不能用过强动作抢走主体注意力。
- 画面不需要某人物产生任何反应时，优先让该人物离开构图或保持画外；禁止把可见人物当作静止陈设。
- 群体反应按人物关系和注意力形成先后波次，默认不同时作出相同动作。
- 事件后优先明确“谁最先理解、谁随后确认、谁拒绝反应”，不用给所有人同一种震惊表情。
- 人物移动必须有趋近或远离的目标。没有动机的人不在背景里无意义走动。
- 威胁形成时，可用群体从细小活动突然进入有意义的静止制造重音；不能靠所有人同步后退或同步张嘴。

## 常见失败修复

| 失败 | 修复 |
|---|---|
| 只写“愤怒地说” | 写人物要迫使谁做什么，以及手、呼吸、距离怎样变化 |
| 听者直到话说完才启动表情 | 让理解与身体反应在关键字或话尾之前开始 |
| 整场一直吼叫 | 标出策略失败点，切换到安抚、沉默施压、讥讽或退出 |
| 手势逐字解释台词 | 让手继续实际任务、先于台词变化、与台词矛盾或保持不动 |
| 停顿只是拖时间 | 在停顿中放入判断、拒绝、控制呼吸或作出决定 |
| 每次切镜情绪归零 | 把上一镜出镜状态完整写入下一镜入镜状态 |
| 特写动作过多 | 只保留眼神、呼吸和一个决定性变化 |
