# 表情动作参考库

本库收录 70 个从表情参考资料提炼的可执行表演条目。同名、近义表情保留为变体，不宣称为 70 种独立情绪。条目只提供眉眼、嘴部、视线、呼吸和姿态等动作候选，不携带参考人物的身份、脸、性别、服装或视觉风格。

## 分镜调用规则

1. 先确定人物知道什么、正在看谁、想达到什么目的，再选表情；同一种情绪可因人物性格、关系和掩饰程度选用不同变体。
2. 每个表演节拍选一个主表情，通常保留 2—4 个可见信号。情绪转变写成“触发 → 变化 → 镜尾状态”，不将多种表情同时叠满脸。
3. 覆盖所有出镜人物：主体写具体表情变化，听者写接收信息后的反应，背景人物写低强度表情、视线目标或正在进行的行为。看不清脸的远景人物以头部、姿态和动作表现，不硬写不可见微表情。
4. 背景人物只对其能看到、听到的信息反应；按立场分配不同反应和时机，不同步瞪眼、转头、微笑。未受事件影响者可自然专注原有事情，不必凭空增加情绪。
5. 每次明确视线对象，将“侧方”“远处”替换为当前场景中的实际人物或位置。参考图中的直视镜头不自动迁移为角色看镜头。
6. 说话过程中保留眉眼与下颌状态；咬唇、紧闭嘴、鼓腮、捂嘴等动作安排在开口前或停顿处，不能与清晰说话同时持续。
7. 下一镜继承泪痕、紧绷、笑意和疲惫，变化需有事件触发。只迁移表情语言，不迁移参考人物的脸、年龄、服装、性别或美术风格。
8. 强度分为轻／中／强，由剧情选择；背景通常低于主体。克制人物不机械套用夸张鼓腮、嘟嘴，强烈爆发也不一律压成微表情。
9. “眼睛发亮、眼里冒火”等改为目光聚焦、眼睑抬起、眉间收紧等动作；不生成发光、改瞳孔颜色或五官变形。泛红、血丝、黑眼圈需剧情依据，不作为情绪必需品。
10. 这是艺术表演参考，不用表情反推现实人物的真实心理。库中未覆盖的情境可补充新条目，标明为新增设计，不冒充原图内容。

## 调用格式

内部记录：人物／出镜层级／已知信息／情绪与目的／参考编号／强度／触发／视线对象／具体变化／镜尾继承。

最终分镜提示词展开为自然语言，不只写编号或“生气、悲伤”。每个人只保留当前镜头能看清、能执行的信号。

示例（仅示范写法，不代表已确定剧情）：

> 听到拒绝后，甲原本的浅笑缓慢收住，眉心压紧，下颌绷住，目光仍停在乙脸上。乙避开甲的目光，嘴唇微启又闭合。背景中能听见对话的丙轻皱眉，看向甲后收回视线；更远处未注意到对话的丁仍低头专注手中原有事务。镜尾保留甲的紧绷与乙的回避。

对应内部参考：甲 E01 → D06，乙 C08；丙为依剧情补充的低强度关注反应。背景反应不添加额外台词或改变剧情。

## 后续补充

新资料按 H、I 等组号继续收录；同名表情建立变体关系。当前缺少独立的恐惧、警觉、厌恶、疼痛等完整系列，后续有可靠资料时再补齐，不将现有惊讶或愤怒条目一概替代。
