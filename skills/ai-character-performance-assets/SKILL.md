# 人物表演资产库

本 Skill 是独立表演层。接收已经锁定的剧情事实、原文台词、在场角色、上下场状态和已有镜头计划，返回结构化人物表演方案，供 `$ai-cinematic-directing-assets` 或 `$make-ai-comic-drama` 编译。核心原则是：表演是人物在阻力下为具体目标采取的可见行为，不是直接展示“愤怒、悲伤、害怕”等情绪标签。

## 权限边界

- 不新增、删除、改写、拆句、调换原文台词和剧情事实。

- 不决定分集、分镜组边界、最终镜头时长、摄影机、灯光、美术和资产绑定。

- 不凭空补写人物身世、口音、声线或习惯；证据不足时标记待确认。

- 只处理当前事件真正出场的角色，不为画外提及者生成表演。

- 返回中性表演数据，不直接替代 Seedance 最终提示词。

## 输入要求

至少需要：来源锚点、不可修改事实、原文台词、当前完整事件、在场角色标准名称、上一镜结束状态和本场预期结束状态。已有角色表演DNA、锁定声线、空间关系或镜头计划时一并提供；缺失时只做有原文证据的最低限度推断。

## 执行流程

1. 先判断人物在当前场景中想从谁那里得到什么，用指向对象的动作动词写“当前目标”，不用情绪词代替目标。

2. 确定阻碍和失败代价；没有文本证据时明确标记“仅能确认表层阻碍”，不得编造深层动机。

3. 识别策略变化：施压、试探、安抚、回避、拖延、诱导、恳求、威胁等。策略失败、新信息出现、权力变化或决定形成时才建立新表演节拍，不按标点机械拆分。

4. 将每个节拍转换为少量可见行为：视线、呼吸、手部、姿态、重心、距离、正在做的实际任务、说话节奏和听者反应。一个镜头只保留最能传达当前变化的 2—4 个行为信号。

5. 为说话者和听者同时设计表演。听者反应可以在话尾之前开始；困难回答先有判断或决定，再开口。反应镜头不能重复或重启说话者音轨。

6. 覆盖当前画面内每一个人物，包括前景主角、次要角色、门外偷听者和背景人物。每个可见人物都必须有符合自身信息、目标和处境的表情语言或动作语言；背景人物表演强度低于主体，但不得中性木站、同步复制主角或提前知道未获知的信息。

7. 对每条对白、内心独白、旁白、画外音或系统语音建立“语言单元”：冻结完整原文，再按自然语义和表演变化给出可连续拼回原文的建议片段。第一个片段必须由可见动作或明确现场事件触发；后续片段必须标记为“无停顿承接”，不得只写抽象时间区间。

8. 记录入镜状态、触发、行为变化和出镜状态，使强烈事件后的呼吸、僵硬、疲惫、警惕或关系变化延续到下一镜，不得切镜后自动归零。

9. 按 [输出约定](references/output-contract.md) 返回方案。需要设计对白、群戏、身体任务、人物地位或眼神生命时读取 [人物表演系统](references/performance-system.md)。

## 固定规则

- 完整原文只在结构化“语言单元”中冻结一次；最终视频提示词允许把原文连续切成多个逐镜片段，但所有片段按顺序无缝拼接后必须与原文逐字一致，不得漏字、改字、倒序、重复或重新起句。

- 对白视觉拆镜优先跟随策略、信息、权力、距离、动作触发或反应归属变化，不按固定字数或标点机械切分。

- 第一语言片段必须写清“什么动作或现场事件发生后开始说/开始内心独白”；后续片段必须写清“切镜后无停顿承接上一镜继续”，并继承同一音色、音量、呼吸、语气和思考进程。

- 语言时长优先使用已锁音色的实际试读或试音；尚无音频时，按角色声线、情绪、重音、停顿与动作触发做逐句估算并标记 `ESTIMATED`，不得用统一字数公式硬切。上游进入生产前必须改为 `ACTUAL_READ` 或重新校时。

- 一条语言单元默认只属于一个分镜组。确实无法避免跨组时，上游必须另行批准并设计不同景别或机位的转场桥；本 Skill 只报告风险，不自行批准。

- 普通对话镜头通常由上游安排为 2—5 秒；本 Skill 不把长对白包装成一个长镜头，也不自行批准超过 6 秒的一镜到底。

- 人物必须有实际行为。可使用整理、擦拭、数钱、做饭、收拾、写字等原文允许的身体任务；禁止为“画面动起来”添加改变剧情的新动作。

- 关键台词可用“正在做的事情突然停止”形成重音，但停止必须由信息或决定触发。

- 身体朝向、眼睛目标和人物距离是三项不同信息，不能用“看着对方”一笔带过。

- 固定声线属于角色资产，只在有依据时锁定；单场情绪改变声音的力度、速度和呼吸，不改变角色的基本音色身份。

- 主表演档案只作为资产保存；生成单镜方案时必须重写为当前状态，不得整段粘贴造成提示词膨胀。

- “背景人物”不是“不表演的人”。只要人物进入画面，该人物必须具有可见的注意力目标、身体任务或情绪反应；如果剧情不需要该人物反应，应将该人物安排在画外，而不是留在画面里傻站。

## 输出与校验

结构化结果可复制 [人物表演方案模板](assets/performance-plan.template.json)，并运行：

`python scripts/validate_performance_plan.py <人物表演方案.json>`

输出必须让上游看清：谁想要什么、受什么阻碍、正在用什么策略、策略为什么改变、说话者做什么、听者何时反应、状态如何进入下一镜。

## 所有风格的情绪可见变化

所有风格项目中，情绪变化必须编译为可见的角色表演；具体部位、幅度和质感服从角色资产及风格，不能把文学比喻作为视觉执行指令。适用于眼神、面部颜色、肌肉、呼吸和身体反应；原文对白、旁白和内心独白逐字保留，只改写其外侧的表演说明。剧情明确要求的超自然变化按剧情单独处理。

- 每个变化写清：触发事件或关注对象 → 具体部位与动作 → 幅度及发生过程 → 镜尾保留状态。选择当下最有效的2—4个信号，不为补字段增加多余动作。

- “眼睛放亮、眼里冒火、脸红、脸色铁青、石化”等词不能独立承担视觉说明；最终动作描述直接用具体效果替换，不把危险比喻再抄在括号中。情绪标签可辅助语气，不能代替表演。以下写实细节仅作具体呈现示例，2D和风格化角色按已锁定线条、材质与幅度表达同样的变化，不强制真人皮纹。

- 眼神变化优先写注视目标、眼睑开合、眉间松紧、眨眼和视线停留。虹膜、瞳孔、眼白维持既有外观；眼中反光只来自已锁定场景光源，不因兴奋增加亮度或光效。

- 肤色变化确有剧情需要时，写清局部位置、低强度、自然过渡以及基础肤色保留。羞赧通常只在耳廓或颧部出现淡淡红润，不能扩散成整脸均匀红色，不改变眼白、嘴唇、颈部及全身颜色。暗光或远景难以读出时，优先用避视、抿唇、低头等动作，不加强红色或改变曝光。

- 强烈情绪由目光、呼吸、姿态和声音力度共同表现，不靠放大眼球、改骨相、拉伸五官、肤色突变或全身抽动。具体幅度服从原文，不将所有表演压成同一种微笑或微动作。

- 切镜继承已经形成的表情与局部肤色状态，不每镜重新由零变红、叠加饱和度或自动恢复。角色身份、年龄、基础肤色、妆容和场景光影保持锁定。

- 交付前逐镜人工检查上述歧义：动作文字被按字面画出来时是否仍符合已锁定的风格与角色身份；若产生未要求的发光、涂色、变形或特效，先重写正向表演，再针对实际风险加一句局部限制。不要把所有限制复制成每镜长负面词表。

### 常见表达的执行示例

以下是按场景选择的写法，不是每镜套用的固定动作。

| 原始概括（仅供内部识别） | 可用于真人镜头的具体效果 |

|---|---|

| 眼睛放亮／眼前一亮 | 听见提议后，视线从桌面移到说话者脸上，上眼睑略抬，眉间舒展，嘴角慢慢上扬，目光专注地停在说话者身上；眼球保持原有颜色和亮度。 |

| 害羞脸红 | 听见打趣后先避开视线，抿住嘴角，轻低下头；耳廓和颧部逐渐出现很淡的红润，边缘自然融入原肤色，其余面部维持原来的颜色与明暗。 |

| 怒火中烧／眼里冒火 | 视线紧盯目标，眉头向内收紧，下颌绷住，吸气加重后压低声音开口；眼睛外观与现场照明保持不变。 |

| 脸色铁青／脸黑了 | 笑意收住，嘴唇抿紧，眉间压低，停下手中动作后定睛看向目标；用肌肉紧张表现不悦，保留正常肤色。 |

| 吓得脸白／石化 | 听见消息后动作骤停，上眼睑抬起、嘴唇微张，吸气短暂停顿后缓慢呼出；保留原肤色、皮肤纹理和身体形态。若原文要求病理苍白，另据剧情写低幅度渐变。 |

| 热泪盈眶／眼红 | 下眼睑边缘逐渐积起一层薄泪，眨眼后少量泪水沿脸颊落下；眼球和整张脸保持原色，不用满脸红色表达悲伤。 |

| 浑身发抖 | 指尖出现轻微不规则颤动，肩背紧绷，说话前努力稳住呼吸；脚底仍站稳，不全身高速抽动。 |

## 局部外观变化与跨镜继承

局部变化的部位、原因、程度和跨镜继承适用于所有风格；以下人体皮肤示例按角色实际结构选用。写实风格保留真实皮纹，2D按既有线条与色块表现，风格化3D按既有材质与表情幅度表现，不强加毛孔或写实解剖。基础肤色来自角色资产；红润、压痕、淤青、黑眼圈都是原皮肤上的局部状态，不替换为一块新的纯色材质。

- 有剧情依据才加入身体变化，不为表现情绪额外增加淤青、血丝、肿胀或伤痕。原文语言保留；视觉说明把概括展开为具体效果。

- 每次写清具体部位、相对范围、相对原肤色的色差、强度、边缘过渡及发生或继承状态。按镜头可读性选择必要细节，不机械填表、不靠精确色号表达人体颜色。

- 局部颜色低于纯色涂抹的饱和度，保留皮肤纹理、掌纹、皱褶及既有光照明暗；过渡自然且不规则，周围仍是原肤色。肤色较深时优先用细微色调、局部明暗及有依据的质感差异表现，不统一套粉红、紫蓝或灰白色。

- 手掌发红：按实际触碰或摩擦区域呈现轻微不均匀红润，掌纹可辨、边缘渐淡；没有全掌受刺激的依据就不扩大到全掌、手背或手臂。其他部位同样按实际受影响范围限定。

- 淤青：只有原文或已锁定伤情需要时呈现，在明确受伤位置形成边缘模糊、不规则的低饱和暗红紫或青褐色差，原肤色从边缘及较浅区域仍可见。颜色和范围服从已确认伤情与经过时间，不随切镜换色、扩大或自动增加肿胀，不自行推断精确伤龄。

- 黑眼圈：限定在下眼睑至眼下浅沟的区域，表现为相对原肤色稍深的灰褐或低饱和青褐暗影，靠近下睑较明显，向面颊自然渐淡；保持原皮肤纹理。原文要求浓重时增加相对深浅，仍保留渐变，不画成环绕眼眶的纯黑圈，不把眼白、额头和整片面颊染黑，不用淤伤替代疲惫。

- 不把生理颜色当作灯光效果：皮肤局部色差随原场景照明呈现，光源、曝光、白平衡不因该变化改变；暗处看不清时不提高饱和度、不让皮肤自发光。颜色状态与阴影分别记录。

- 切镜后继承部位、范围、程度和纹理，衣物遮挡时无需强行露出。出现、加重或消退须有剧情与时间依据；禁止重复叠色，也不能几秒内无因消除既有淤青或黑眼圈。

- 交付前检查：去掉情绪词，仅按视觉说明生成，是否会像油漆、妆面色块、黑眼罩或全身换肤？若会，返修为原肤色上的局部自然色差。少量针对性限制用于消除实际歧义，不给每镜堆全身负面清单。

示例（按剧情选用，不自动新增状态）：

- 手掌受摩擦后：掌根接触处比原肤色略红，范围局限在接触区，掌纹清晰，红润边缘逐渐融入周围皮肤；手背颜色保持原样。

- 已有前臂淤青：前臂外侧原伤处保留一小片不规则、低饱和青褐色差，中央略深、边缘渐淡，皮纹和侧光阴影仍连续；不新增肿块。

- 疲惫的重黑眼圈：两侧下眼睑下方保留明显但低饱和的灰褐暗影，向面颊柔和减淡，眼白和上眼睑保持原外观，脸颊仍是角色原有肤色。

## 逐句表演必查

每句语言及建议片段必须明确“情绪是什么 → 对谁、想达到什么目的 → 用什么语气说 → 身体怎么配合”；压低声音不等于情绪，情绪标签不等于表演。按 [输出约定](references/output-contract.md) 记录逐句表演，跨镜续说继承情绪、意图、语气与身体状态。原文无依据时只作最低限度推断，不新增动机或动作剧情。

## 通用逻辑与风格表现

本技能能力适用于两个模型、所有视觉风格、时代和画幅。风格只改变动作表情的幅度与呈现方式，不省略情绪、对象与目的、语气、身体配合、光源因果或连续性。写实示例中的毛孔、肤色和肌肉细节不强加给2D或风格化角色；已确认的动画夸张、压缩伸展或特效按具体风格执行，仍守角色身份、动作因果与前后状态。
