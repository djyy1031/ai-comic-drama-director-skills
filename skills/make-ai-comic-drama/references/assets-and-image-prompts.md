# 资产与生图提示词

## 表格只保留四列

1. 资产类型：人物、场景或道具。
2. 原文资产名称：直接使用小说中的角色名、场景名或道具名。
3. 剧情功能与重要程度：说明它为什么存在、是否反复出现、影响哪些剧情。
4. 提示词：放入生成该资产所需的全部内容。

禁止再拆出首次出现、五官、发型、服装、空间结构、材质、参考图、构图、画风、负面提示词或画幅等独立列。需要这些内容时，全部归入同一个“提示词”单元格。

正向提示词与 Negative Prompt（负面提示词）必须放在同一单元格，形成一条可以整体复制的提示词。

## 人物资产

核心女主角必须读取 [核心角色资产提示词固定模板](character-asset-prompt-layout.md)，并严格遵守标题顺序和六格布局。

女主角提示词必须包含：

- 用途、资产类型和输出规格。
- 整体风格定位。
- 女主角核心气质。
- 脸部设计：脸型、眉毛、眼睛、鼻子、嘴唇、皮肤。
- 发型。
- 身材比例。
- 服装固定与服装材质表现。
- 角色设定表布局。
- 核心美型方向、渲染和最终效果。
- 强制角色一致性。
- Negative Prompt。

提示词要根据原文角色重新写具体内容，不能只把参考提示词中的“周宁”替换成新名字。年龄、职业、气质、脸部识别点、发型、服装和故事状态必须来自当前作品。

男主角或重要配角沿用同样的完整度和六格布局，只把“女主角核心气质”改为与角色身份相符的“男主角核心气质”或“角色核心气质”。核心女主角不得改标题。

## 场景资产

场景提示词在同一单元格写清：用途与输出规格、确定的 2D 或 3D 风格、场景原文名、时代时段、空间结构、入口出口、门窗家具、固定物件、材质颜色、环境光影、四格固定布局、强制场景一致性和 Negative Prompt。

场景资产必须遵守以下固定规则：

- 完全无人物、无人影、无人体局部、无动物、无车辆移动和无动态道具。
- 输出 15360×8640、16:9 横向、16K 分辨率、极致细节的纯场景资产图。
- 使用 2×2 四格无框分屏。四格等大、无边框、无间隙、无标题、无文字、无数字、无标注、无 Logo 和无水印。
- 精确还原同一个纯场景的四个标准正反打视角，顺序固定，不得增加、删除或调换：
  1. 场景整体全景：完整交代空间结构、入口出口、核心区域和固定物件关系。
  2. 正向中景：摄像机位于入口，从入口向场景深处拍摄。
  3. 反向中景：摄像机位于场景深处，从深处朝入口方向拍摄，与第二格形成标准正反打。
  4. 核心区域近景：聚焦剧情主要发生区域，同时保留足够固定环境信息用于定位。
- 四格只能切换摄像机位置和景别。场景内所有物体必须完全静止，不能移动、增减、旋转、替换、变形或改变状态。
- 四格共享完全相同的时间、天气、环境状态、色调、曝光、白平衡、主光方向、光源数量、阴影方向、物体比例、空间结构、摆放位置、材质纹理、磨损痕迹和环境细节。
- 先明确唯一画风并贯穿四格，例如“2D 半写实国漫场景”或“高预算 3D 国漫电影场景”；禁止同一资产图混用写实、动漫、游戏或不同渲染风格。
- 画面保持干净，只保留原文和剧情必需元素，不添加装饰性杂物、无关标牌、临时道具或模型自行想象的元素。

Negative Prompt 至少禁止：人物、人影、人脸、手脚、人体局部、动物、移动物体、物体漂移、家具换位、门窗换位、比例变化、材质变化、纹理变化、光源跳变、色温变化、天气变化、时间变化、阴影方向变化、不同场景、不同装修、额外物体、缺失物体、重复物体、动态模糊、错误透视、鱼眼畸变、分格边框、分格间隙、标题、文字、数字、标签、Logo、水印、低清晰度和风格漂移。

## 道具资产

道具提示词在同一单元格写清：用途与输出规格、确定的 2D 或 3D 风格、道具原文名、剧情功能、固定外形、准确比例、材质、颜色、标识、磨损细节、三视图固定布局、强制道具一致性和 Negative Prompt。

道具资产必须使用三视图：

1. 正面视图。
2. 侧面视图。
3. 背面视图。

三视图在同一张横向资产图中从左至右等宽排列，使用正交视图、相同摄影机高度、相同比例、相同中心线、相同光照、相同材质和干净中性背景。必须是同一个道具，正面、侧面和背面的结构能够准确对应。除用户明确要求外，不增加透视图、45 度图、打开图、内部结构图、零件图、细节图、手持图、人物参照或剧情变化状态。

Negative Prompt 至少禁止：不同道具、比例不一致、结构对应错误、侧视图变成 45 度、透视畸变、材质变化、颜色变化、标识变化、磨损位置变化、缺失零件、额外零件、重复道具、手持道具、人物、手、装饰场景、复杂背景、投影遮挡结构、文字、标题、数字、标签、尺寸线、Logo 和水印。

## 参考图职责

参考图职责也写进“提示词”单元格：

- 人物图锁脸、发型、身形、服装和关键配饰。
- 场景图锁空间结构、门窗家具、材质和主光方向。
- 道具图锁外形、比例、材质、颜色和标识。
- 站位或动作图只借位置、朝向和运动轨迹，禁止复制原背景、方框、箭头、网格和文字。

## 2D 与 3D

2D 漫剧使用稳定轮廓、固定五官、清楚线稿、受控上色、固定服装和一致背景结构。禁止线条闪烁、脸部漂移、服装跳变和突然换画风。

3D CG 漫剧使用稳定角色模型、统一拓扑和材质、PBR 材质、皮肤次表面散射、毛发系统、布料模拟、虚拟摄影机和电影级灯光。禁止模型重塑、比例漂移、贴图闪烁、塑料皮肤、塑料头发、布料穿模和肢体穿插。
