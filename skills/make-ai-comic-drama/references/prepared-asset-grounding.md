# 成品资产驱动分镜

## 触发条件

用户在分镜设计前提供已经完成的场景图、角色图、道具图、声音文件、资产目录或明确的资产标准名称时，先调用 `$ai-storyboard-asset-grounding`。只给剧本、没有成品资产时保持原有流程，不要求用户临时制作资产，也不伪造核验状态。

## 固定顺序

`冻结剧本事实 → 查看真实成品资产 → 资产锚定包PASS → 人物表演 → 导演镜头 → 执行连续性检查 → Seedance编译`

用户只需要分镜提示词时，资产锚定包仍在内部使用，最终只交付原有 Markdown 分镜文档。

## 主流程裁决

- 剧本控制事件、人物出场、原文语言和顺序。
- 已核验资产控制场景结构、固定陈设、材质、光源关系、角色身份外观、道具外观状态和声音绑定。
- 用户明确修正优先于不确定推断；全局控制提示词控制统一画质、风格和负面要求。
- 文件名匹配不是内容核验。能读取的图片、声音和文档必须查看实际内容；缺失、多候选、不可读或冲突要报告，不能凭剧本常识填成 `VERIFIED`。
- 单张场景图优先用参考视角左/右、前/中/后景及固定地标描述，不把画面左侧误写成世界西侧，也不虚构图外完整格局。

## 编译要求

- 等号绑定名逐字使用锚定包标准名称，只列本组真实调用资产。
- 相邻分镜组分别完整复写必要空间、光线和道具状态，不写“同前”，也不重新设计。
- 摄影机机位和运动只能在资产证据允许的区域内，不能穿墙、穿家具或进入未知空间。
- 剧本需要而背景图未出现的独立道具，只有存在对应道具资产时，才可放入不改变固定格局的合理承载位置。
- 锚定包为 `ERROR` 时，只返修最早缺口；不能绕过检查直接输出“资产一致”的提示词。
