# 项目要求与统一叫法

## 开工前要知道什么

把下面内容填进电子表格的“02项目总案”：

- 原始素材：只有题材、小说、大纲、剧本，还是已经有分镜。
- 改编方式：尽量忠于原文、允许商业化重做，还是从零原创。
- 发布形式：人工智能漫剧、预告片或其他。
- 发布平台和观众。
- 画面比例、集数、单集时长。
- 视频模型一次最多能生成几秒。
- 画风、参考图和明确不要的风格。
- 使用哪些生图、视频、配音、口型和剪辑工具。
- 原作、人物、音乐、字体、声音等是否有版权或授权。
- 最终要概念方案、可生成素材，还是能继续剪辑的完整素材包。

缺少但影响不大的内容可以先假设，必须写清楚。影响版权、时长或结果方向的内容不能擅自决定。

## 三种改编方式

- 尽量忠于原文：不改事件原因、人物选择、关系变化和关键台词意思，可以删重复内容，但要列出删改记录。
- 商业化重做：可以重排、合并角色、改台词和结局，但要真正改变世界、人物动机、冲突原因和解决办法，不能只换名字。
- 从零原创：重新建立人物、世界、冲突和视觉风格，不能照搬现成作品。

## 常用编号

下面的英文字母只是电脑核对资料时使用的固定编号，使用者不需要理解或背诵英文。只看编号前面的中文名称即可。

- 项目 `PRJ-001`
- 集 `EP-001`
- 场 `SC-001`
- 镜头 `SH-001`
- 一次视频生成任务 `SEG-001`
- 人物 `CHR-001`
- 场景 `LOC-001`
- 道具 `PROP-001`
- 服装版本 `CST-001`
- 参考图 `REF-001`
- 图片用途 `IMG-001`
- 台词 `DIA-001`

编号一旦开始生产就不要重复使用。删掉的内容保留编号并标记“已停用”。

## 几个容易混淆的词

- 场：同一时间、同一地点发生的一段戏。
- 镜头：从画面开始到剪切为止的一段连续画面。
- 生成段：一次提交给视频模型的任务，可以只有一个镜头；模型实测稳定时才能放多个镜头。
- 人物参考图：用来锁定脸、发型和衣服。
- 场景参考图：用来锁定房间、门窗、家具、材质和光线。
- 站位参考图：用来锁定谁站左边、谁站右边、相隔多远。
- 前后统一记录：写清每个镜头开始和结束时人物、衣服、道具、位置和光线，避免下一镜突然变化。

## 必须停止的情况

版权不清却要求商用；没有授权却要模仿真人脸或声音；内容和时长明显冲突；模型能力未知却要求保证复杂效果；平台规则没有官方来源和核验日期。遇到这些情况必须说明，不能假装能直接生产。
