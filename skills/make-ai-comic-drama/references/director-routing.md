# AI影视导演语言资产库调用

“人工智能漫剧导演”是总流程与最终裁决者；`$ai-cinematic-directing-assets`（AI影视导演语言资产库）是专业导演协调层；`$ai-character-performance-assets`（人物表演资产库）与 `$ai-shot-execution-continuity`（镜头执行与连续性检查库）是两个窄专业模块。四者职责不能互换。

## 总导演保留的权力

- 原文忠实、分集、分镜组边界、时长、模型版本和最终提示词格式。
- 母资产、子资产、文件夹接入、声音规划、审核闸门与生产状态。
- 对专业库返回结果进行取舍、编译和最终审核。

## 调用时机

完成原文标准化并准备设计分镜组时，对每个完整事件建立“导演调用请求”，至少包含：

- 不可修改剧情事实和原文台词。
- 当前完整事件、人物、场景、道具与资产标准名称。
- 上一组结束状态、本组预期结束状态。
- Seedance版本、单组上限、视觉风格和画幅。
- 用户提供的参考版本、锁定成功项、允许修改项和失败反馈。

随后按以下顺序调用：

1. `$ai-character-performance-assets`：基于不可修改事实和原文台词，返回人物目标、阻碍、失败代价、策略变化、潜台词、身体任务、听者反应、表演节拍和状态继承。
2. `$ai-cinematic-directing-assets`：吸收人物表演方案，形成候选镜头功能、摄影、动作和逐镜语言片段。
3. `$ai-shot-execution-continuity`：在候选镜头形成后，逐镜和逐切点检查第一帧、空间、朝向、视线、道具手、轴线、光线、物理、语言触发和连续承接。
4. 执行检查为 `ERROR` 时返回最早问题位置修正候选镜头；通过后由导演协调层返回“导演镜头表示”。

“导演镜头表示”至少包含：

1. 场景诊断与导演意图。
2. 实际调用模块及满足条件。
3. 每个镜头的功能和存在理由。
4. 角色表演、摄影、动作动力和特效因果。
5. 入组、出组和跨组连续性状态。
6. 模型适配提醒。
7. 人物表演方案来源与状态。
8. 镜头执行与连续性检查来源与状态。

## 编译顺序

`冻结剧情事实 → 导演调用请求 → 人物表演方案 → 候选导演镜头 → 镜头执行与连续性检查 → 导演镜头表示 → 模型适配 → 资产等号绑定 → 纯净视频提示词 → 三轮审核`

专业库返回的是中性导演方案，不能直接当最终 Seedance 提示词。总导演要根据项目的 Seedance 2.0 或2.5规则、3D全局固定段、资产命名、字幕限制和声音边界完成编译。

## 条件选择

- 关键词只用于发现候选模块。必须检查剧情功能、动作是否实际发生、空间条件和禁用条件。
- 出现“剑”但只是对话威胁时，调用刀剑对峙与威胁表演，不调用交锋或命中特效。
- 出现长台词时，人物表演模块按策略、信息、权力、动作触发或反应变化建立表演节拍；完整原文优先留在同一分镜组，最终按逐镜原文片段连续说完，不能返回一个覆盖整段的连续语言镜头块，也不能另列独立计时音轨。
- 出现鬼怪但核心是身份误导时，调用恐怖揭示与反应递进，不自动套战斗。
- 只选择当前事件需要的最少模块，禁止整库堆叠。

## 不可用时的降级

如果目标设备缺少任一专业 Skill：

1. 缺人物表演模块时使用导演库内置角色表演降级规则；缺执行模块时使用导演库的状态账本与摄影连续性基础规则；缺协调层时由主 Skill 使用内置动作导演规则。
2. 对每个缺失模块分别记录 `FALLBACK_INTERNAL`，不得用一个总状态掩盖具体缺失来源，也不得假装已调用。
3. 不因为缺少伴随 Skill 而删除剧情或停止安全可完成的基础工作。

## 审核

- 专业库是否改变了原文事实或台词。
- 每个镜头是否有新增信息、表演推进、关系变化、动作完成点或有效空间交代。
- 是否把候选关键词误当成模板触发命令。
- 是否存在只为“电影感”而增加的多余运镜。
- 出组状态是否完整写入下一组入组状态。
- 人物表演是否以目标和策略驱动，听者是否在说话期间持续反应，状态是否切镜后归零。
- 每个相邻切点是否均有执行连续性结果；检查失败时是否已经返修，而不是直接进入最终提示词。
- 最终提示词是否已经按所选模型编译，而不是直接复制中性导演表示。
