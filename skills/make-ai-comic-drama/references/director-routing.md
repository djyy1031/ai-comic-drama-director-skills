# AI影视导演语言资产库调用

“人工智能漫剧导演”是总流程与最终裁决者；`$ai-cinematic-directing-assets`（AI影视导演语言资产库）是专业导演知识层。两者职责不能互换。

## 总导演保留的权力

- 原文忠实、分集、分镜组边界、时长、模型版本和最终提示词格式。
- 母资产、子资产、文件夹接入、声音规划、审核闸门与生产状态。
- 对专业库返回结果进行取舍、编译和最终审核。

## 调用时机

完成原文标准化并准备设计分镜组时，对每个完整事件建立“导演调用请求”，至少包含：

- 不可修改剧情事实和原文台词。
- 当前完整事件、人物、场景、道具与资产标准名称。
- 上一组结束状态、本组预期结束状态。
- Seedance版本、单组上限、视觉风格和画幅。
- 用户提供的参考版本、锁定成功项、允许修改项和失败反馈。

随后调用 `$ai-cinematic-directing-assets`，要求返回“导演镜头表示”：

1. 场景诊断与导演意图。
2. 实际调用模块及满足条件。
3. 每个镜头的功能和存在理由。
4. 角色表演、摄影、动作动力和特效因果。
5. 入组、出组和跨组连续性状态。
6. 模型适配提醒。

## 编译顺序

`冻结剧情事实 → 导演调用请求 → 导演镜头表示 → 模型适配 → 资产等号绑定 → 纯净视频提示词 → 三轮审核`

专业库返回的是中性导演方案，不能直接当最终 Seedance 提示词。总导演要根据项目的 Seedance 2.0 或2.5规则、3D全局固定段、资产命名、字幕限制和声音边界完成编译。

## 条件选择

- 关键词只用于发现候选模块。必须检查剧情功能、动作是否实际发生、空间条件和禁用条件。
- 出现“剑”但只是对话威胁时，调用刀剑对峙与威胁表演，不调用交锋或命中特效。
- 出现长台词时，调用对话与角色表演；完整音轨留在同一分镜组，只说一遍。
- 出现鬼怪但核心是身份误导时，调用恐怖揭示与反应递进，不自动套战斗。
- 只选择当前事件需要的最少模块，禁止整库堆叠。

## 不可用时的降级

如果目标设备未安装 `$ai-cinematic-directing-assets`：

1. 主 Skill 继续使用本 Skill 内的 [动作导演模块调用规则](action-direction.md) 和 [导演提示词与资产模块库](directing-asset-library.json) 完成基础方案。
2. 在项目数据中记录 `library_status = "FALLBACK_INTERNAL"`，并在交付说明中明确标注“专业导演语言资产库未安装，已使用内置基础规则”，不得假装已调用。
3. 不因为缺少伴随 Skill 而删除剧情或停止安全可完成的基础工作。

## 审核

- 专业库是否改变了原文事实或台词。
- 每个镜头是否有新增信息、表演推进、关系变化、动作完成点或有效空间交代。
- 是否把候选关键词误当成模板触发命令。
- 是否存在只为“电影感”而增加的多余运镜。
- 出组状态是否完整写入下一组入组状态。
- 最终提示词是否已经按所选模型编译，而不是直接复制中性导演表示。
