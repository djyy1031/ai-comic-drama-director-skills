# 审核与状态闸门

## 审核原则

三轮审核职责独立。每轮输出 `PASS`、`WARNING` 或 `ERROR`，并写明对象、证据、影响和返修动作。重复检查三遍不算完成三轮审核。

严重程度：

- `ERROR`：违反原文、模型时长、必要资产、连续性或硬格式，必须返修。
- `WARNING`：可生产但有明显稳定性、节奏或成本风险，需要人工决定。
- `INFO`：非阻断优化建议。

## AUDIT 01｜原文忠实度

只检查故事与来源：

- 人物、身份、关系和出场范围。
- 台词顺序、含义和说话人。
- 动作、事件顺序、场景、时间和剧情结果。
- 人物动机、情绪内核和信息揭示顺序。
- 压缩、合并和视听转译是否有记录，是否擅自删改核心内容。
- 执行描述使用的标准名称是否与原文和资产表一致。

不在这一轮评价资产够不够或模型是否容易生成。

通过状态：`AUDIT_SCRIPT_FIDELITY = PASS`。

## AUDIT 02｜资产覆盖与合理性

只检查生产依赖和数量：

- 每组角色、服装、状态、场景机位、道具、UI、VFX和声音是否覆盖。
- 已有母资产是否优先复用，是否错误重复创建。
- 场景现有机位能否覆盖；新增机位是否真正有价值。
- 子资产是否缺失、必要性评分是否合理、是否过度生产。
- 必须资产状态是否为 `READY`，缺失资产是否进入生产清单。
- 资产文件夹是否已自动扫描并与标准名称匹配；多候选和未识别文件是否已处理。
- 每个标记为 `READY` 的图片、音频或视频是否存在逐项内容审核证据；禁止仅凭文件名或文件存在判定通过。
- 声线、环境底噪、动作声、转场声和关键声音是否有来源或待制作项。

不在这一轮修改剧情或重新导演分镜。

通过状态：`AUDIT_ASSET_COVERAGE = PASS`。

## AUDIT 03｜连续性与可生成性

站在视频生成与剪辑角度检查：

- 分镜组符合当前 `model_profile` 的时长；未混用另一模型规则。
- 普通小镜头时间连续闭合；连续语言表演块只检查外层总时间，内部镜头不应被错误卡死子时间点。
- 每集时长是否按原剧本自然形成，是否存在为90秒、120秒或分镜组目标时长而增加的空镜、重复反应、无作用运镜、慢放或静止拖延。
- 每个镜头是否从第一帧进入有效表演或摄影运动；较长镜头是否持续有动作、微表情、视线、环境反馈或镜头语言进展。
- 普通完整台词是否被机械拆句；长台词、长独白和长系统语音是否保持同组、完整音轨只说一遍，并在内部切镜时保持语气、音量、呼吸与口型连续。
- 人物位置、朝向、姿态、视线、服装、状态和动作轴线连续。
- 道具持有者、左右手、外形、开合和损耗状态连续。
- 门窗、家具、场景结构、机位和主光方向稳定。
- 上一镜头结束状态能成为下一镜头开始状态。
- 同场景相邻组是否拆在完整语义、情绪落点或动作结束处，是否复写一致的场景结构、光影、天气、风向和人物左右关系。
- 是否明确人物运动轴线或对话轴线、摄影机允许活动侧、视线和行进方向；是否发生无理由越轴、方向错误或人物左右翻转。
- 连续组是否使用视线匹配、正反打、动作完成点或连续声音自然衔接；是否错误依赖重复首尾帧造成停顿或卡顿。
- 每个运镜是否写清摄影机起点、轴线侧、路径、速度、停止位置和最终焦点；是否堆叠冲突运镜。
- 高强度动作是否具有可读的发力准备、动力传递、接触、受力结果和余波；是否出现受击方提前飞出、破坏先于命中或高速位移错误绕后的情况。
- 特效是否固定来源、颜色、传播路径、先后关系、环境影响和禁止形态；局部失焦、过焦、手持或震动是否由动作触发、关键接触清晰且及时恢复。
- 是否存在复杂度过载或确实需要额外 Blocking；首帧、尾帧默认不生产，只有特殊情况才评估。
- 执行描述是否存在模糊代词、缺失主语或无法唯一绑定的对象。
- 每个含对白、内心独白、旁白、画外音或系统语音的小镜头或连续语言表演块，是否以 `视频严禁出现台词、内心独白与系统语音字幕。` 结束；不能只在分镜组末尾统一添加。
- 环境声、BGM功能、转场声和对白避让是否合理。

通过状态：`AUDIT_CONTINUITY_GENERATABILITY = PASS`。

## 生产裁决器

只有三项全部为 `PASS` 才能：

`PRODUCTION_READY = TRUE`

任何 `ERROR`：

- 标记受影响的集、分镜组、镜头、资产或提示词。
- 返回最早需要返修的阶段。
- 建立新版本并重跑依赖审核。
- 禁止直接覆盖冻结分镜或假装问题已解决。

## 最终成片审核

视频和粗剪完成后另做最终检查：

- 最终时间线从开始到结束不超过180秒。
- 分集声音执行表使用真实时间码。
- 对白清楚，BGM和高强度音效完成避让。
- 环境声、动作声、转场声和剧情专用声音衔接合理。
- 声音素材状态和授权状态明确。
- 视频、音频、文字和剧情UI没有违背禁字幕与内容要求。

通过后：`FINAL_EPISODE_READY = TRUE`。

## 状态依赖

建议状态顺序：

```text
SCRIPT_IMPORTED
EPISODES_READY
SHOTGROUPS_READY
SHOTGROUPS_LOCKED
MASTER_ASSET_ANALYSIS_READY
MASTER_PROMPTS_READY
WAITING_FOR_MASTER_ASSETS（可选暂停）
SUB_ASSET_ANALYSIS_READY
PRODUCTION_TABLES_READY
AUDIT_SCRIPT_FIDELITY_PASS
AUDIT_ASSET_COVERAGE_PASS
AUDIT_CONTINUITY_GENERATABILITY_PASS
PRODUCTION_READY
VIDEO_ASSETS_READY
ROUGH_CUT_READY
SOUND_CUE_SHEET_READY
FINAL_EPISODE_READY
```

配置、冻结分镜或资产版本改变时，所有下游状态标记为 `STALE`，从受影响阶段重新审核。
