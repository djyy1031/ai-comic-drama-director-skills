# 分镜提示词模板、职责与交付检查

每次写分镜提示词都读本页，包括只交一两个镜头。先在内部完成各环节，再编译成纯净正文。下文的职责、检查问题和占位说明只供 Codex 使用，绝不复制给视频模型。示例人物、时长、焦距不是新剧本的默认值。

## 谁负责什么

| 环节 | 必须交给主技能的结果 | 交付前要查 |
| --- | --- | --- |
| `make-ai-comic-drama` 主技能 | 冻结原文事件、台词与因果；确认模型、画幅、时长；编译纯净提示词；逐项验收 | 原文没漏改；新增动作不改剧情；每组在已选模型时长上限内；各项全过才交付 |
| `ai-storyboard-asset-grounding` 资产核验 | 用户已给的场景、站位、角色、道具图中实际可见的锚点 | 实际打开对应原图；位置、朝向、固定地标、遮挡和可达机位有证据；未知处不假装已核实 |
| `ai-character-performance-assets` 人物表演 | 每个入镜人物的目标、当前可见行为和情绪变化；每句语言的情绪、可听语气、对象与同步动作 | 表情写出起点、触发、眼眉嘴/呼吸/动作如何变化；不能只写“疑惑”；旁人只回应听到或看到的信息；OS闭口 |
| `ai-cinematic-directing-assets` 导演摄影 | 每镜清晰主体、所有入镜者、景别、焦距、机位、固定或运动、镜头的信息变化和切点 | 第一眼知道拍谁；焦距明确是摄影机镜头；构图容得下动作与表情；机位路径可执行；切镜带来新信息 |
| `ai-shot-execution-continuity` 连续性 | 内部比对每镜首尾、人物站位、手、道具、轴线、语言和声音进度 | 切后不换位、不换手、不重演动作；反应及时；环境声连续；只把本镜实际首帧状态写入本镜正文 |
| 主技能＋文字校验脚本 | 纯净正文与可机器识别的格式检查 | 没有 `**`、`&#...`、待核备注或“上一镜／下一镜”的剪辑指令；固定禁字幕句准确；脚本通过后仍做语义复核 |

资产缺失时可以交明确标注的文字审阅草稿；不能称机位、站位或成片已核验。模板不能替代实际图片、试读或生成视频。

## 可复制正文的格式

完整分集先在复制区外写：`第X集｜总时长X秒｜共X个分镜组｜各组时长：X秒、X秒……`。每组标题标组名和时长；每组独立 `text` 代码块。代码块里只放视频模型应生成的内容。只交一两个镜头时，只使用逐镜格式，不强加完整组栏目。

完整组正文顺序：

```text
用户本次锁定的完整全局约束，逐组原样复写。
实际发声角色=实际音色标准名称=
实际出镜角色=
实际场景=
实际道具或特效=
【摄影机运动总设定】
本组实际使用的轴线、机位活动范围和固定或运动方式。
【场景与光影】
已核实的可见空间、固定地标、时段和光线。
【起始站位】
按本站位图写人物相对固定地标的位置、朝向、视线、距离、持物手。
【语言连续性总锁】
本组实际发声者、音色、语言种类和原文顺序；同一句只发声一次，OS无口型。
【0—X秒】
摄影机镜头焦距N毫米，人物标准姓名与另一人物标准姓名双人腰上中景；清晰主体是……。摄影机位于……，朝……拍，眼高……，固定／沿已核实路径……；本镜实际构图……。
首帧……。人物甲……；人物乙……。人物甲在本镜第0.1秒开始……，情绪……，可听语气……，同步做……：“原文台词”。OS人物嘴唇闭合、无说话口型。
环境与动作音效：来源、质感、远近、发生时点和音量关系。
视频严禁出现台词、内心独白与系统语音字幕。
整体环境音效：跨镜底声、动作声和静默状态；无背景音乐。
```

上方各项是填写位置，不是可直接提交的内容。删除未使用的角色、道具、特效槽；替换所有占位词。资产槽仅写实际调用项，发声角色用 `角色=音色=`，未发声角色、场景和道具用 `标准名称=`；没有已核实音色时留待绑定槽，不编造。四个固定栏目必须有本组具体内容。语言镜末尾独立一行准确写固定禁字幕句；组末的整体环境音效不属于末镜。

单镜正文顺序：时间段 → 镜头拍谁及焦距、景别、身体范围 → 有依据的机位与画面 → 首帧及所有入镜人物的可见表演 → 本镜语言及声音 → 独立音效行 → 如有语言则用固定禁字幕句结尾。第一句示例为“摄影机镜头焦距50毫米，林夜单人胸上中近景”；双人须同时点名两人。过肩写清前景肩膀归属；如果另一人的手入镜，写“沈清月胸上中近景，林夜的右手局部入镜”，不要称画面只有沈清月一人。

切镜接法只在内部状态账本核对：上一镜结束的手到哪里，下一镜首帧手在哪里，语言和声音处于什么进度。本镜正文写“首帧，林夜的右手已经抬在两人之间”“沈清月第0秒继续内心独白……”等本镜可生成的状态；不写“接上一镜、下一镜要、不能重新抬手、待场景图核对”。如完整项目要求组间剪辑说明，放在代码块外。

## 交付前逐项检查：任一项失败即返修

1. **剧本与因果｜主技能**：原文每个事件和每句语言按顺序覆盖；新增表演能说明它表达原文哪层信息；不能让角色提前知道、提前回神或改变剧情结果。
2. **资产与空间｜资产核验＋连续性**：逐个对照本组真实场景图与站位图，核人物相对地标的位置、前后、朝向、视线、手和道具；换机位只改变画面投影；机位、运动路线与遮挡可执行。无法核验时标注为草稿，不能伪造细节。
3. **镜头｜导演摄影**：首句明示摄影机镜头焦距、被拍者标准姓名、人数、景别、身体范围、清晰主体；机位有起点、朝向、高度；运动有触发、路径、速度、停点；固定镜也有画面变化。相邻镜不重复交付同一信息。
4. **表演｜人物表演**：逐镜列出所有实际入镜者；每人都有符合其所知的表情或动作。每个关键表情有起点、触发、可见变化和对象；不以“出神、疑惑、发现自己”代替可拍行为。每句语言都写情绪、可听语气、对象、同步动作；OS闭口，其他人物听不到OS。
5. **时间、切点和声音｜连续性＋主技能**：每镜起止相接，各组从0计时且不超已选模型上限；切后首帧有新反应或持续动作、声音，开口与动作并行，句末不空等；跨镜手、道具、视线、光线、底声不重置；音效有来源、时点、远近和音量；没有擅加背景音乐。语速未试读时只称规划时长。
6. **纯净交付｜主技能＋脚本**：逐镜正文只含本镜生成任务，去掉内部审核语、跨镜剪辑指令、占位词、Markdown和HTML残留；固定禁字幕句逐字一致且独立成行。运行 `scripts/validate_prompt_light.py`；完整项目如另有专用脚本也运行，但任何脚本通过都不代替前五项的画面推演。

上述检查在每次交付前执行，不把这张表复制进视频模型提示词，也不默认另交给 Patrick。发现错误直接修改正文后重查受影响镜头及相邻切点。
