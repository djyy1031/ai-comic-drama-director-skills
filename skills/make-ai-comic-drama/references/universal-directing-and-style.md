# 通用导演逻辑与风格适配

这是所有项目共用的规则入口。适用于Seedance 2.0与2.5，仿真人、2D、3D、皮克斯式风格化动画及其他用户指定风格，古装、现代或其他时代，16:9、9:16和其他画幅。支持范围不依赖是否已有某个风格的全局模板。

## 一套不变的导演与制作逻辑

所有项目执行：冻结原文和配置 → 有成品时核验资产 → 人物表演 → 导演镜头 → 执行连续性检查 → 启用时制作或复用站位图 → 加入对应风格与画幅表达 → 编译完整提示词 → 审核交付。模块根据当前事件是否需要某项能力调用，不按画风或模型关闭。资产尚未提供时走明确标记的文字方案，不伪造核验。

- 每句明确情绪、对谁及目的、具体语气、配合的动作或表情；跨镜继承情绪、意图、呼吸、语气、身体与道具状态。听者及所有入镜人物具有符合已知信息的反应，不能只给说话者表演。
- 每镜内部回答：什么时候用、为什么用、需要什么条件、具体怎么拍、下一镜怎么接、做不到时怎么简化。选择此刻主体、信息揭示顺序、构图、景别与动静，不机械轮流拍说话者。
- 焦段、摄影机高度、角度、构图、运镜、景深与对焦全部写成当前可见画面。运动说明触发、起止构图、路径、速度和落点；固定镜头用表演或信息推进，不自动附加漂移。不规定运镜比例。
- 初始站位、真实空间与画面左右、身体朝向、视线、道具左右手、资产身份、遮挡和摄影机可达区都要明确。不得无依据越轴；明确设计的越轴也须重建方向，不靠切镜瞬移人物、家具或光源。
- 光线始终有项目世界中的来源，方向、明暗、色彩和阴影前后连续；机位改变不移动光源。昼夜、天气、时代和风格决定光源及呈现方式，不决定是否检查光影。
- 台词逐字、逐人、逐序保留；首次由动作或现场事件触发，跨镜不重启，内心独白无说话口型。动作和走位在完成点切；跨组独立复写状态，剪辑说明放代码块外并由下一组兑现。
- 每组完整包含项目全局段、实际资产等号绑定、摄影机运动总设定、场景与光影、初始站位、语言连续性总锁和逐镜时段。禁字幕、剧情UI局部例外及音乐后期处理对所有风格一致。
- 普通对话单镜2—5秒为主，无既有批准不超过6秒；非脸部特写最多2秒。这些是统一项目规则，不是模型或画风专属限制。无意义空镜、停顿、动作、运镜均不用于凑时长。

## 模型只带入单组上限

按Patrick明确的制作配置：

| 模型 | 单次分镜组最大时长 | 导演与表演流程 |
| --- | --- | --- |
| Seedance 2.0 | 15秒 | 共用本页及专业技能 |
| Seedance 2.5 | 30秒 | 共用本页及专业技能 |

实际组时长大于0且不超过当前上限。没有2.5专属20秒最低值、3—7镜/5—12镜硬配额、对白句数或独立运镜套路；也不要求把组填满。按完整事件、语音与动作容量选择自然组界，同场景内容可合理合并，但不能为少组数牺牲表演或提前泄露信息。用户明确的组数偏好是可选项目约束，不是模型属性。

改变模型后仅重算受时长影响的分组、时间和切点继承。15秒内能完整承载的同一方案不因切到2.5而自动拉长；超过15秒的方案转到2.0时，在合法事件边界重新分组，不删台词、不加速硬塞。完整一句仍超上限则报告具体冲突，按原有语言边界处理。

## 风格、时代与画幅改变呈现

用户告知风格后直接生成相应全局提示词，记录项目版本，不要求用户提供专业术语或自行写全局段。只有时代、画幅等缺失且确实改变结果时才问；已说明的信息不重复确认。

风格层至少说明角色造型与比例、材质/线条/上色、表演幅度、光影呈现、环境质感以及真正需要的排除项；与角色资产一致。局部镜头仍执行同一套导演逻辑。

| 用户指定风格 | 加入对应表现，而非另一套导演规则 |
| --- | --- |
| 仿真人/真人剧 | 自然皮肤和衣物材质、可见而克制的肌肉与呼吸，真实场景光影；不要把情绪写成发光或无因换肤 |
| 写实3D国漫 | 三维角色与材质、合理接触和重心、布料毛发反馈，表演与镜头仍由剧情选择 |
| 皮克斯式等风格化3D | 已锁定的风格化比例、清晰表情轮廓、材质层次与动画节奏；允许该风格确认的夸张幅度，不强套真人比例、皮肤毛孔或写实国漫负面词 |
| 2D、手绘、水彩等 | 稳定造型、线条、色块/笔触和分层空间；用眼形、眉线、姿态及阴影层次表达同样的情绪与光影因果，不强加PBR或三维皮纹 |
| 其他风格 | 根据用户描述和参考明确表现特征；没有预制模板也使用完整导演与校验流程，不回退到某个默认风格 |

皮肤、外观或材质变化遵守“原因 → 部位与范围 → 程度和过程 → 镜尾状态 → 后镜继承”，所有风格适用。具体纹理按风格选择：2D可用既有色块和线条，写实保留皮纹，风格化角色按既有材质。非人类角色按实际结构表达，不强加人类面部解剖。已经确认的动画压缩伸展或风格化变形可以使用，但不能造成无因换脸、资产漂移或动作结果不连续。

古装与现代只改变服装、器物、建筑、光源种类及时代细节；同样检查来源、方向、接触与连续性。不能把古装油灯、现代电灯、古装负面词、旧示例人物自动带进另一项目。

16:9、9:16或其他画幅只改变取景组织与信息可读性；根据画幅调整前中后景、人物画面占比及必要镜头分配，不改变真实站位和固定场景结构，不因此丢掉动作、听者或关系表达。画幅不决定固定/运动、焦段或剪辑速度。

## 全局预设和最终检查

`global-3d-prompt.md`是具体的写实3D国漫预设，`global-live-action-period-prompt.md`是具体的古装竖屏仿真人预设；两者不是全部风格入口，更不是专业能力开关。匹配且被选用时完整继承；新风格由本技能生成相应版本，不把互相排斥的全局段叠加。既有已锁定版本不静默覆盖。

新风格全局段保留统一标题及输出边界，摄影基准来自项目选择，不能按“所有3D”强制50mm、真人比例或相同景深。固定镜不被全局微动抵消，关键后景不被统一虚化；风格变化不能替代导演方案。

所有组合均运行同样的原文、表演、导演、资产/站位（有条件时）、连续性、格式、人物范围与提示词交接检查。依据 [提示词保真与恢复检查](prompt-preflight.md) 确認情绪、动作和摄影选择实际进入正文。文字通过仍不等于视频效果通过；实际反馈用于修正执行，不把某一风格判成不支持。
