# 生产执行合并规则

本文保留七列表格的职责说明。当前提示词格式以 [纯净视频提示词格式](prompt-format.md) 为准，时长按项目模型配置，表演、资产与连续性按主技能执行；旧表不能覆盖这些规则。

## 表格结构

生产执行页固定保留七列：

1. 集数。
2. 集名。
3. 对应原文章节。
4. 场次顺序。
5. 本镜调用资产。
6. 制作说明与前后衔接。
7. 干净视频生成提示词。

一行代表一次可独立生成的视频分镜任务，时长按项目模型配置：2.0最多15秒，2.5最多30秒。一行内部可以包含多个小镜头，不得再拆成“一行一个镜头”。调用素材、人工制作说明和模型提示词必须分列，防止操作信息污染视频生成提示词。

单集总时长由上游剧本决定，默认90—180秒；明确短样本按记录的例外执行。分镜任务数量不限，按剧情和生成稳定性拆分。同一场次出现多行时重复填写同一场次顺序，按行顺序连续执行。

## 拆分红线

读取项目对应模型配置，不统一按15秒、7镜或4句机械拆分。保持原文逐字一致、完整事件、语言与动作落点；不凑时长，不在一句话或走位中途切组。跨镜续说保持情绪和身体状态，普通单镜默认不超过6秒。

## 三列职责

### 本镜调用资产

第五列只告诉 Patrick 本次生成需要上传或调用哪些素材。逐项写完整原文名称和职责：人物资产锁脸、发型、身形和服装；场景资产锁空间、固定物体和主光；道具资产锁外形与状态；色卡锁颜色关系；首尾帧和站位图锁构图承接；音频资产锁声线、环境声或关键音效。

### 制作说明与前后衔接

第六列只告诉 Patrick 怎样执行：分镜顺序、实际时长、内部镜头数、是否使用上一分镜末帧、站位锚点来源、道具如何承接、缺少什么素材，以及只借站位或动作时禁止复制哪些参考图元素。

### 干净视频生成提示词

第七列按 [纯净视频提示词格式](prompt-format.md) 完整输出：项目锁定的全部全局段 → 本组实际资产等号绑定 → 摄影机运动总设定 → 场景与光影 → 起始站位 → 语言连续性总锁 → 逐镜时间段。不使用旧STYLE LOCK模板替代，不省略资产绑定。制作说明与文件路径仍留在第五、六列。

## 按名称调用资产

视频生成按实际需要调用已核验图片、色卡和音频；首尾帧仅在明确启用时使用，不是必需输入。使用前先读取资产表和上传素材名称，在第五列建立本镜资产调用清单；不要把文件清单复制进第七列视频提示词。

固定写法：

```text
【本分镜调用资产】
人物资产：林砚角色资产图。职责：锁定林砚的脸、发型、身形、深灰风衣和固定伤势状态。
场景资产：南城旧车站四视角场景资产图。职责：锁定入口、铁柱、木长椅、站牌、寄存处、空间比例和西侧暖黄主光。
道具资产：旧怀表三视图道具资产图。职责：锁定圆形比例、三角缺口、银色磨损和表链。
色卡资产：南城旧车站冷灰暖黄色卡。职责：锁定冷灰主色、暖黄强调色、明暗比例和饱和度。
站位资产：分镜1镜头5中景末帧。职责：锁定林砚在雨棚中央偏右的站位与候车室方向线。
音频资产：林砚青年中低音声线。职责：锁定林砚的年龄感、音色和语速。
音频资产：南城旧车站雨夜环境声。职责：提供中雨、远处列车和空站回声。
```

规则：

- 名称必须与资产表、上传文件名或用户明确提供的名字完全一致。
- 禁止使用 `资产1`、`资产 2`、`参考图3`、`IMG-01`、UUID、平台临时编号、`@角色ID` 或“上图中的人物”等指代。
- 每项资产后必须写清锁定职责，不能只堆资产名称。
- 每个独立生成任务都重新列完整资产清单，不能只写“沿用上一分镜所有资产”。
- 干净提示词只使用剧情原文名，例如“镜头从旧怀表的三角缺口开始”；资产文件名只保留在第五列。
- 若某项必须使用但尚未生成或上传，先写 `需补充资产：资产原文名称 + 用途`，不要编造不存在的素材编号。
- 色卡只锁定颜色、饱和度、明暗和冷暖比例，不复制色卡的排版、文字或分格。
- 首帧、尾帧和站位锚点写清具体来源，例如“分镜1镜头5中景末帧”，不能只写“上一张图”。
- 已有音频使用明确名字；没有独立音频素材时，在声音设计中写“待生成声音：声音名称”，不要伪装成已上传资产。

## 参考真人提示词的转换

真人参考提示词可以保留 STYLE LOCK、资产锚定、摄影机运动总设定、逐镜时间、声音先行、色调变化和转场方法，并按已锁定视觉形态编译；仿真人保留真人表达，只有2D或3D项目才作对应转译。

- 只吸收提示词结构和制作方法，不照搬参考片的角色身份、伤势、泥血、尸体、动作、场景、情绪、台词或剧情结果；所有故事内容必须重新匹配当前小说和当前分镜。
- 真人摄影机、电影机、镜头组和实拍胶片参数只在真人写实项目中保留。
- 2D 国漫改写为固定线稿、分层上色、2.5D 视差、受控光影和有限环境运动。
- 3D 国漫改写为固定模型、拓扑、PBR 材质、虚拟摄影机、焦段景深、布料毛发物理和电影级灯光。
- 保留参考中的“哪个资产锁谁、摄影机从哪里到哪里、什么声音先出现、什么色调怎样变化”的工作方法，不照抄不适合漫剧的真人皮肤、摄影器材或导演名字。

## 统一美术风格

在剧本进入正式分镜前确定唯一美术风格，并从人物、场景和道具资产图继承。每行提示词开头完整复写项目已锁定的全局控制段，不允许模型自行换风格。

画面风格可按项目选择真人写实玄幻、3D 建模质感 CG 动画、2D 国漫动画、3D 国漫动画等。场景风格写具体，例如赛博朋克霓虹、国产修仙云海、未来科技科幻、写实都市或悬疑旧城。不要只写“电影感”“高级感”。

色调写具体，例如冷色调、暗黑低饱和、柔和暖色调；有色卡时明确“色卡图只锁主色、辅色、明暗比例和饱和度，不复制色卡排版与文字”。

## 环境光影

光线必须写出来源、方向、色温和对画面的影响：

- 逆光：从人物后方哪个方向进入，勾勒哪侧轮廓和发丝，哪些区域落入阴影。
- 顶光：从正上方或斜上方照射，落在额头、肩部、道具和地面的阴影形状。
- 底光或鬼光：从人物下方向上照射，影响下颌、鼻底、眼窝和背景投影。
- 侧光：从画面左侧或右侧进入，照亮哪半边脸、服装纹理和道具反光。
- 环境光或特效光：霓虹、法阵、屏幕、火焰、月光等怎样改变皮肤、发丝、服装、墙面和地面的颜色。

同一场景、同时段的连续分镜保持相同主光方向。光线变化必须在动作或剧情中写明原因。

## 小镜头写法

每个小镜头写清：

- 连续时间段和景别：全景、远景、中景、近景、特写或局部特写。
- 机位和构图：摄影机高度、人物左右关系、前中后景和画面占比。
- 人物状态：站位、姿态、具体表情部位、视线和朝向对象。
- 动作过程：谁的哪个身体部位，从什么起点沿什么轨迹，以什么速度力度到达什么终点，并产生什么反馈。
- 运镜：从哪里开始、沿哪个方向、围绕谁或什么移动、速度如何、在哪里结束、最终对焦哪里。
- 光线影响：本镜内光线怎样落在人物、道具和环境上。
- 声音：同步对白、呼吸、环境声、动作音和必要音乐；默认无 BGM，除非用户或上游明确要求。
- 结束状态：切镜点必须落在动作完成状态，不能在抬脚、挥手、转头或搬物半途中硬切。

运镜必须具体，例如：

- `摄影机从人物右后方肩部高度开始，沿顺时针方向环绕人物一周，结束在正面近景并对焦双眼。`
- `摄影机从腰部高度跟随林砚向画面左侧移动，保持人物右侧后三分之四角度，最后停在怀表近景。`
- `镜头从旧怀表三角缺口的极近特写缓慢后拉，结束在林砚胸上近景。`

禁止只写“360 度旋转”“跟随镜头”“推镜”“特写一下”。

摄影机运动总设定用于锁定整条分镜的主运动逻辑，例如第一人称贴地持续前推、受伤手持晃动、始终同速跟随人物。小镜头可以改变景别，但不得无原因打断总体运动。若需要从第一人称切到客观全景，必须写明发生在哪个时间点、为什么切换以及切换后的机位。

## 台词与音画同步

按 [纯净视频提示词格式](prompt-format.md) 写动作触发开始、逐镜续说及逐句表演四项，不沿用旧对白句式。音量不能代替情绪；跨镜继承情绪、意图、语气、呼吸与身体状态。对白逐字保留，听者具有符合已知信息的反应。

## 高潮、反转、爽点和钩子

- 高潮：言语羞辱 → 威压 → 动手的三段蓄力；临界点用明确动作、原文台词与有剧情依据的拍法；结束反应按当前事件安排，不硬改台词或固定停顿。
- 反转：先建立主角弱势 → 出现唯一触发点 → 用反派震惊和主角淡定的状态对比完成反转。
- 爽点：精准打击最嚣张的反派 → 给出可视化结果 → 依次表现反派失态、旁人震惊、主角反差。
- 钩子：以特写定格未完成的信息点，不给答案，不写“下集怎样”。

只在剧情确实属于对应类型时使用，不要每个分镜机械套公式。

## 状态继承

除首分镜写 `无（首分镜）` 外，同场景连续剧情的本镜起始状态必须逐项继承上一分镜结束状态：人物站位、姿态、神态、视线、服装伤势、光线、固定场景元素和关键道具。

状态需要改变时，在本分镜的小镜头中完整展示变化过程，禁止跳镜后默认重置。换场时重新建立站位，但保留剧情需要延续的姿态、神态、视线和道具；时间跳转时说明不继承的状态。

特写或局部特写不传递完整站位。若分镜以特写结束，在第六列注明：`本镜末帧为特写，站位锚点来自本镜镜头X（全景/中景/近景末帧）`。若整条分镜全为特写，继承更早的有效站位锚点。

## 道具锚点

每条分镜写清关键道具名称、当前持有者或位置、状态，以及它与上一分镜的关系。道具发生交接、掉落、打开、损坏或消耗时，必须在小镜头内完整呈现过程。

后续分镜使用关键道具时，在第六列写明：`旧怀表来自上一分镜结束状态，当前在林砚右手掌心，表盖打开。` 第七列直接描述起始画面中的同一状态。禁止道具跨分镜自动换手、消失、复原或改变外形。

## 跨分镜参考

首尾帧不作为默认连续性方案。优先继承文字状态、核验资产、轴线与剪辑；启用站位图时按站位技能生成或复用。只有用户明确要求或特殊复杂镜头经审核需要时才使用首尾帧，特写帧不能单独证明完整空间。
