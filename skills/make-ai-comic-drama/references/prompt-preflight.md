# 提示词保真与恢复检查

制作、修改或上下文恢复后先读取本页与 [通用导演逻辑与风格适配](universal-directing-and-style.md)。这里是检查入口，不替代专业技能。先恢复当前项目记录，再只读本场相关分支；不把过往例子当成当前剧情或默认配置。

## 开始时恢复什么

内部保留简短制作记录：用户最新修正、原文与台词版本、模型配置、视觉形态、时代、画幅、全局段原文及版本、实际资产路径与核验状态、启用的站位图模式、上一组结束状态、已完成模块和下一步。一次性文字测试可保存在已有测试目录，不强制建立完整生产项目。历史对话不可见时以文件和可见记录为准，不宣称记得所有历史要求。

本项目用户已确认内容不重复询问。用户新要求优先；主技能及当前模型配置、prompt-format和scene-stability是现行规则，旧案例和旧生产表不能覆盖。冻结的剧情与资产出现矛盾时报告具体缺口，不靠改剧情解决。

## 必须贯通的检查

| 环节 | 读取依据 | 交付前核对 |
| --- | --- | --- |
| 形态与全局 | 主技能、锁定全局段、当前模型配置 | 所有风格共用导演流程；根据用户指定风格、时代与画幅生成全局段，现有预设只是可选样式；全局段各组逐字一致 |
| 原文 | 冻结剧本与语言单元 | 说话人、每句内容、重复次数及顺序相同，既不改字，也不漏掉整句 |
| 逐句表演 | 人物表演技能及输出约定 | 情绪、对象与目的、语气、身体配合写进承载台词的正文；不是只写低声；平静也可成立 |
| 跨镜声音 | 表演承接、连续性检查 | 情绪、意图、语气、呼吸、身体状态不归零；画外声与听者反应分开；独白闭口，无身体的声音不编造人物 |
| 导演表达 | 导演技能、叙事剪辑、摄影语言到画面描述 | 内部六问齐全；拍谁和何时揭示有依据；焦段与术语有大白话；运镜有触发、路径、画面变化和落点，固定有镜内推进 |
| 空间与全员 | 资产锚定、scene-stability、执行技能 | 世界位置与画面左右分开；视线、身体朝向、道具手、全员表演、轴线、遮挡、光源连续；未知角度不编造 |
| 所有风格的表情与外观细节 | 主技能通用表情与局部外观约束 | 表演有部位、幅度、过程与继承；眼睛不发光、脸红不涂色、黑眼圈和淤青不改变全身肤色；不无因新增伤情 |
| 图与绑定 | 资产锚定、启用时的站位图技能 | 查看成品而非只看名字；每组实际资产等号绑定齐全，离场人物不以否定句混入；站位图可复用且不锁死后续镜头，标签不进视频 |
| 时间与剪辑 | 当前模型、prompt-format | 同镜多句的触发和发声不挤占；不凑时长、不默认长镜；非脸部特写最多2秒；动作完成点切；组外转场与下一组首镜一致 |
| 声音与文字 | sound-design、prompt-format | 环境底声连续、接触声有因果、后期音乐不混进生成正文；语言镜禁字幕；剧情UI仅局部放行 |
| 输出与状态 | prompt-only-storyboard-delivery、audits-and-state | 各组独立完整，不写同前；用户要聊天就贴全文；文字、资产、实测声音、视频分别记录状态 |

全局固定与局部执行必须相容。例如已选择的写实3D预设中的“微动”只用于已选运动镜，固定镜明确不漂移；需要读清的后景不得被统一虚化。若局部说明仍与项目锁定全局存在实质冲突，先修项目全局版本并重新核对各组，不用堆更多互相抵消的指令掩盖。

## 最终交接校验

继续运行格式校验和人物范围校验，并运行：

`python scripts/validate_prompt_handoff.py 分镜文档.md 交接核对.json 锁定全局段.txt 人物表演方案.json`

最后一个文件可以是本次各组表演方案组成的数组，顺序须与分镜组一致。方案先通过人物表演技能校验；交接脚本再次核对冻结台词和最终片段的顺序与完整性。

交接核对只作内部记录，格式见 [交接记录模板](../assets/prompt-handoff.template.json)。从上游方案开始填入预期说话人和时间，不能从错误正文倒推原文来让检查通过；编译后补各句在正文里的精确证据短语。每条语言片段按出现顺序记录：所在镜头序号、说话人、四项表演证据、首次触发或续说承接证据，以及本镜内开始偏移、时长和估算或试读依据。续说记录必须包含情绪和身体状态的承接证据。证据须位于本次发声指令之前；画外发声或旁白的身体不适用须明确记录理由并引用画外/闭口等正确执行文字。

校验能拦截：表演证据缺失、证据已从正文删除、正文或全局版本改变、整句遗漏/重复、片段错序、模型配置时长越界、同镜语言时间重叠、解析遗漏的镜头。它不能判断“愤怒”是否符合剧本、证据是否真正属于该人物、构图是否好看或模型是否执行；这些必须逐句逐镜人工审核，不以填满字段冒充。

所有修改完成后重跑受影响的检查。无成品资产或音频时可交付明确标记的文字草稿，不把估算标成实测，也不把文字检查通过写成视频效果通过。
