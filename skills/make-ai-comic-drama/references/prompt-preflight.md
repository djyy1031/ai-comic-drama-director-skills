# 提示词检查入口

普通提示词任务按主技能七步执行，不恢复旧项目、不搜索旧聊天，不串读全套参考。画幅、模型、画风、全局段缺失时集中问用户；资产缺失先问，确认没有才作文字设定。

仅用户明确要求恢复某项目时读取其指定记录，核对本次更正；不得把旧参数带进新任务。完整结构化项目的交接检查可用原有 validate_prompt_handoff.py；轻量任务只用主技能规定的 validate_prompt_light.py，并完成逐镜语义审查。

交付检查：姓名和局部归属、具体设施与站位、摄影机起点/朝向/构图、原文台词、切镜0.5秒内开口、动作表情与语言同步、听者和背景反应、语速与时长、跨镜状态、声音来源/音量/承接、无背景音乐、语言镜末尾独立禁字幕句。标了0.2秒却要求动作做完才说，必须返修。

文字检查不证明生成效果；没有音频或视频不标为实测通过。默认不另交审核记录或建立成套中间文件。
