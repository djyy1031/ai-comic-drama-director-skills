# 纯净视频提示词格式

用户明确只要分镜组提示词时，同时读取 [仅分镜组提示词交付](prompt-only-storyboard-delivery.md)。最终生成一份 Markdown 文档，并使用 `scripts/validate_prompt_only_markdown.py` 校验后交付；不附加资产列表或其他生产表。

## 内外分层

结构化项目中仍分别维护资产矩阵、制作与衔接说明、审核记录和纯净视频提示词。面向视频模型交付的分镜组正文使用本文件规定的单一模板，不把项目状态、文件路径、内部资产ID或审核说明写进去。

## 分镜组正式模板

每个分镜组的可复制正文严格使用以下顺序：

```text
完整粘贴本项目已锁定的全部全局控制段。仿真人古装项目使用【全局固定画质参数】、【全局通用负面提示词】、【全局明暗与反差锁定】、【全局光影规则】；3D项目使用对应3D全局段。

顾平生=顾平生音色=
洛清雪=洛清雪音色=
叶晚星=
场景标准名称=
具体场景机位标准名称=
必要子资产标准名称=
道具、视觉特效、UI或声音标准名称=

【摄影机运动总设定】
人物运动轴线、摄影机允许活动侧、画面左右关系和禁止越轴要求。
【场景与光影】
调用的场景资产、空间结构、光源方向、色温、曝光、阴影、天气和风向。
【起始站位】
人物真实场景坐标、画面坐标、朝向、视线、相对距离和道具状态。
【语言连续性总锁】
只在本组语言跨多个镜头时使用。不登记独立音轨时间；只声明逐镜原文片段依序连续、只说一次、切镜不重启。
【0.0-x.x秒】：景别、机位、构图、动作、表情、视线、运镜；具体动作发生后，角色以具体声音状态开始说或开始内心独白：“原文片段”；环境反应、特效、声音、结束状态。
含语言内容的镜头在全部描述最后空一格追加：视频严禁出现台词、内心独白与系统语音字幕。
……
```

长台词、长内心独白或长系统语音需要多个镜头时，先在结构化语言单元冻结完整原文用于校验，最终提示词只写逐镜原文片段。第一片段由动作触发，后续片段无停顿承接：

```text
【语言连续性总锁】
顾平生的逐镜原文片段属于同一句话，只完整说一次。视觉切镜时语气、音量、呼吸和口型连续；后续片段无停顿承接上一镜，禁止重新起句、重复、漏字或声音状态重置。

【0.0—3.0秒】：50mm双人中景，顾平生睁眼并从椅背稍微前倾，视线落到叶晚星脸上；叶晚星双手抱膝，目光偏低。顾平生身体前倾稳定、与叶晚星对上视线后，顾平生（平静、认真）朝向叶晚星开始说：“你不要看谁不喜欢你，”。叶晚星听见开头后手指轻轻收紧。结束状态：顾平生保持前倾，叶晚星仍低头。 视频严禁出现台词、内心独白与系统语音字幕。

【3.0—6.0秒】：恢复默认50mm，叶晚星肩后朝顾平生的过肩中近景，摄影机缓慢推进约0.2米；顾平生右手指尖轻点椅子扶手。切入本镜时，顾平生保持同一口气、音量和口型，无停顿承接上一镜继续说：“你要看谁喜欢你，知道吗？”。结束状态：顾平生语气进入观点转折。 视频严禁出现台词、内心独白与系统语音字幕。

【6.0—9.0秒】：50mm叶晚星面部近景，顾平生声音转为画外连续声并保持同一呼吸，无停顿承接上一镜继续说：“你不可能做到被所有人喜欢。”叶晚星紧绷的手指逐渐放松，叶晚星抬眼看向顾平生。结束状态：顾平生完成整句并保持注视，叶晚星准备回应。 视频严禁出现台词、内心独白与系统语音字幕。
```

分镜组名称、总时长和必要风险说明写在可复制正文之外。正文第一行必须是项目已经锁定的 `【全局固定画质参数】`。仿真人古装项目读取 [仿真人古装全局固定提示词](global-live-action-period-prompt.md)，3D项目读取 [3D漫剧全局固定提示词](global-3d-prompt.md)。每个独立生成任务都完整粘贴，不写“同前”；禁止把资产、制作说明或分镜标题放在全局固定段之前。

## 资产绑定区

- 资产绑定区位于全局通用负面提示词之后、`【摄影机运动总设定】`之前，不添加额外标题。
- 即使当前只交付分镜提示词、不运行资产清单流程，也必须列出本组视频生成实际需要的角色、音色、场景、机位和道具绑定槽。
- 每一行使用资产表的 `canonical_name`，行尾保留等号作为平台绑定槽位。
- 角色需要对白、内心独白或指定声音时，把角色和音色写在同一行：`角色标准名称=角色音色标准名称=`。
- 角色只出镜、不调用音色时写：`角色标准名称=`。
- 场景母资产、实际使用的每张场景机位、必要子资产、道具、视觉特效、UI、系统音色和其他必要声音各占一行：`资产标准名称=`。
- 只列本分镜组实际调用的资产。不得为了套模板列出空类别，也不得把“角色资产”“场景资产”等类别词当作资产名称。
- 用户提供成品资产时，标准名称、场景结构、固定陈设、光源关系、角色身份、道具状态和声音绑定以通过校验的资产锚定包为准。单张参考图只使用可见地标和参考视角位置，不擅自补写图外格局；摄影机运动不得穿越固定结构或未知区域。
- 等号后不得填写文件路径、内部ID或虚构的平台标签；用户在平台内完成绑定。
- 首帧和尾帧仍非常规资产，只有已通过必要性审核时才进入绑定区。

## 逐镜硬要求

- 时间从0开始，连续、不重叠、不留空，末镜结束时间等于分镜组实际时长。
- 所有视觉镜头都使用独立精确时间段，包括长台词期间的正反打、过肩、双人镜头和反应镜头。禁止使用独立计时的“连续音轨总设定”代替逐镜语言执行。
- 普通对话单镜以2～5秒为主，默认不得超过6秒。超过6秒必须同时写明用户或原文明示的一镜到底要求、`long_take_reason` 和 `long_take_approved=true`；没有批准就必须拆镜。
- 每镜只有一个主要任务。
- 景别、机位和构图服务本镜信息，不必每镜都运镜或转场。
- 运镜写清摄影机从哪里开始、位于轴线哪一侧、沿什么路径、以什么速度、在哪里结束、最后对焦什么；每镜只安排一个主要运镜。
- 动作写清角色名称、身体部位、起点、轨迹、速度力度、终点和反馈。
- 表情写可见部位变化，不能只写“生气、害怕、悲伤”。
- 镜头结束状态必须能成为下一镜头开始状态。
- 视觉镜头可以在一句台词持续期间按语义、视线、动作或反应点切换，声音保持连续；分镜组不能在语言中途无依据截断，也不能切在连续动作或人物走位一半。
- 每个镜头第一帧即进入有效动作、表情、视线、环境反馈或摄影运动。台词和动作完成后立即进入有效反应或结束，不保留无内容的前摇和拖延尾巴。
- 较长镜头必须持续发生可见变化；若一两秒内画面、表演、信息和摄影机均无变化，除非静止本身承担明确叙事功能，否则必须缩短或补充忠于原文的表演进程。

## 明确命名

执行描述中的人物、场景、道具、UI、特效和声音来源全部使用资产表的 `canonical_name`。

资产不仅在组首清单中列一次，还必须在它实际发生作用的逐镜描述中按标准名称再次调用。人物动作的主体、动作对象、发声者、视线对象、持有道具和特效来源均重复写明，不依赖模型根据上下文猜测。一个句子包含多个连续动作时，每个容易产生歧义的动作都重新写出主体名称。

禁止：

- 他、她、它、他们、对方、前者、后者、另一人。
- 这里、那里、该处、这个房间、场景同前。
- 那个东西、武器、桌上的东西等无法唯一绑定的名称。

错误：`李明和张三走在一起，他突然打了一下张三。`

正确：`李明和张三并肩走在金融一班教室中央过道，李明突然抬起右手击向张三左肩，张三向画面右侧踉跄半步。`

原文对白中的自然代词可以保留；命名硬规则针对对白之外的模型执行说明。

## 对白、独白与系统语音

对白格式：

`对话：角色名：（可见表情或动作）【语气：声音语气】朝向对象“原文台词”`

- 台词原文、说话人和先后顺序必须保留，不得擅自改字、删减、消音、替换或调换；合规风险单独标记并做视听转译，不暗改原文。
- 语气来自角色档案和当下状态，允许相邻台词保持相同语气。
- 普通短台词能在一个自然镜头内说完时保持完整。长台词允许按镜头切成连续原文片段，但不得改字、漏字、重复、倒序或从词语中间截断；全部片段顺序拼接后必须逐字等于原文。
- 第一片段必须写清动作触发：`角色完成具体动作后，角色（声音状态）朝向对象开始说：“原文片段”`。内心独白改为：`具体动作或信息出现后，角色嘴唇闭合、无口型，开始内心独白：“原文片段”`。
- 后续片段必须写：`切入本镜时，角色保持同一音色、音量、呼吸和情绪进程，无停顿承接上一镜继续说：“原文片段”`。听者或道具镜头需说明声音为画外连续声。
- 台词时长优先按实际试读或试音；无音频的规划阶段按实际声线、角色状态、语速、重音、呼吸、情绪变化和触发动作估算并标记 `ESTIMATED`。生产前使用 `ACTUAL_READ` 重新校时；固定字数不能作为拆句法规。
- 逐镜时间同时约束画面和当前语言片段。片段可用时长从触发动作完成后开始计算；切镜不能让语言停顿、重新起句、重复、音量重置、呼吸重置或口型跳变。
- 完整语言默认只在一个分镜组内完成。超过当前模型单组上限时先报告限制；确需跨组必须取得明确批准，前组尾镜建立自然转场，后组首镜改用不同景别、机位或主体继续承接，禁止相同镜头重复开头。

内心独白：第一人称画外音，明确什么动作或信息出现后开始，嘴部不张合、无口型。

系统语音：写明具体系统名称、声音来源和是否为画外播报，不生成播报字幕。

上述任一承载语言片段的小镜头，必须在环境音效、动作音效和结束状态之后空一格追加固定句：`视频严禁出现台词、内心独白与系统语音字幕。` 固定句后不增加任何解释。

## 系统UI与字幕边界

- 原文要求人物看到的系统面板、任务文字、倒计时和UI信息是剧情画面元素，不等于台词字幕。
- 全局负面提示词继续保留“禁止任何可读文字”，不得删除或改写。
- 剧情UI使用指定资产锁定文字、位置和样式；只在UI实际出现的小镜头中明确局部放行，写清UI资产标准名称、准确显示文字、显示区域、版式、颜色、出现与消失时间。该局部放行只允许指定UI文字，禁止模型自由添加其他文字。
- 没有剧情要求的字幕、说明文字、Logo和水印一律禁止。
- 每个承载对白、内心独白、旁白、画外音或系统语音的计时镜头，都必须以 `视频严禁出现台词、内心独白与系统语音字幕。` 结束；不能只在音轨总设定或整个分镜组末尾写一次。

## 场景、站位与轴线

- 每组场景描述可独立理解，但继承同一母场景结构和指定机位。
- 同场景相邻组必须分别复写完全一致的空间锚点、时间、天气、主光方向、色温、曝光、阴影方向和风向，不能依赖模型记住上一组。
- 起始站位同时写真实空间坐标与当前画面坐标。
- 人物移动必须完整展示并更新结束站位。
- 明确人物运动轴线或对话轴线、摄影机允许活动侧、人物画面左右顺序、视线和行进方向；正反打、过肩、跟拍和环绕均服从该轴线。
- 默认禁止越轴；确需越轴时，镜头必须展示摄影机经过轴线或先使用轴线上中性镜头重新建立方向。
- 连续分镜组优先使用视线匹配、正反打、动作完成点、声音先行或声音延续衔接，不常规依赖重复首尾帧。
- 特写不能单独传递完整站位；末镜为特写时必须在该镜头结束状态中写出仍有效的空间站位锚点。
- 每个非末组尾镜只写本组实际结束状态与连续锚点；代码块结束后单列“剪辑衔接：”，说明接法、锚点和下一组首镜。下一组必须兑现，下一场画面与时段指令不得提前写入本组正文。

## 默认镜头与特殊镜头

- 3D项目全局默认使用50mm电影虚拟镜头。
- 某个小镜头确需广角、超广角、长焦、微距、鱼眼或其他特殊镜头时，在该小镜头写清镜头类型或焦段、摄影机位置与高度、拍摄方向、运动方式和预期效果，不能只写“使用特殊镜头”。
- 局部特殊镜头只覆盖当前小镜头；下一小镜头未再次声明时恢复50mm默认镜头。
- 选择特殊镜头必须服务于原剧本信息或情绪，不能为了炫技造成空间畸变、轴线混乱或角色外观漂移。

## 特效与声音

- 特效写入实际发生的镜头，并说明来源、方向和对人物环境的影响。
- 环境声、动作声和关键提示声放在对应镜头末尾。
- 不把最终后期 BGM 方案全部塞进视频模型提示词；只保留生成时必须同步的声音要求。
- 光影、转场和音效服务剧情，不堆砌术语。
- 动作或特效场面先按 [动作导演模块调用规则](action-direction.md) 匹配关键词和使用条件，只把当前剧情确实需要的模块编译进提示词；不能把整个案例或全部模块一起套用。按需调用示例见 [Seedance 2.5动作模块案例](examples/seedance-2.5-action-group.md)。
