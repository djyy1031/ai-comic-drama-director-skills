# 核心角色资产提示词固定模板

## 使用规则

核心女主角角色资产必须按本文件顺序编写。不得删除必需章节，不得把正向和负向提示词拆开，不得自由改变六格设定表布局。

提示词开头先写：

- Use case：当前项目需要的 2D 或 3D 漫剧方向。
- Asset type：角色原文名 + 角色一致性设定表。
- Output specification：分辨率、16:9 横向宽幅、文件格式和细节要求。
- 从零设计的完全虚构角色、年龄、国籍或地域、职业、作品类型和剧情身份。

## 必需章节与顺序

### 【整体风格定位】

明确角色属于什么级别的漫剧或动画电影、2D 或 3D、东方或其他地域审美、成熟度、写实与风格化比例、电影感和辨识度。

同时写清“是什么”和“不是什麽”。例如不是普通路人、不是真人照片、不是 Q 版、不是网红脸、不是游戏角色。美感来源必须具体落到五官、骨骼、皮肤或线条、发型、服装、材质和光线。

### 【女主角核心气质】

写明年龄、身份、职业、剧情地位和气质关键词。核心女主角必须有第一眼的视觉吸引力和故事感，但不能只写“漂亮”。

分别说明她不属于哪些错误方向，例如甜妹、萝莉、性感女神、夸张御姐、浓妆网红或时尚模特。

### 【脸部设计】

必须分项写：

- 脸型：额头、面中、下颌线、下巴、轮廓曲线和需要避免的脸型。
- 眉毛：形状、粗细、眉峰、眉尾、毛发或线条质感、轻微自然不对称。
- 眼睛：眼型、眼裂比例、眼尾、双眼皮、虹膜、眼白、角膜或高光、眼神气质和避免项。
- 鼻子：鼻梁、山根、鼻头、鼻翼、三维结构和避免项。
- 嘴唇：上下唇比例、唇峰、嘴角、颜色、妆感和避免项。
- 皮肤或面部材质：肤色、纹理、轻微色差、次表面散射或 2D 上色方式，以及塑料感、蜡像感和过度磨皮禁令。

### 【发型】

写清颜色、长度、直卷、分缝位置、哪侧别耳、额前碎发、飞发、发量、轮廓、毛发系统或 2D 发丝表现。发型必须服务脸部识别，并成为固定特征。

### 【身材比例】

写清身高感、成年人体结构、肩颈、锁骨、腰腹、四肢、腿部比例、站姿和美型程度。必须同时写出禁止的超模比例、极端长腿、极端纤细、夸张腰臀比或不现实结构。

### 【服装固定】

逐件写清上装、内搭、下装、鞋子、配饰、颜色、版型、长度、领口、袖长、接缝和固定识别元素。

继续写【服装材质表现】：布料类型、纹理、厚度、褶皱、起球、重力和模拟方式。六格中的颜色、版型、长度、纹理和鞋子必须完全一致。

### 【角色设定表布局】

横向 16:9 宽幅。整个画面严格划分为 6 个完全等宽的竖向主面板，从左至右排列。

所有面板必须使用相同中性浅灰摄影棚背景、相同摄影机高度、曝光、白平衡、光线方向、渲染质量、角色模型、服装和材质。相邻面板只使用极细浅灰竖线。禁止标题、文字、数字、Logo、水印和粗边框。

六格固定排版：

1. 第一格：完整全身正面。头顶到鞋底完整入画，双手双脚完整可见，中性自然站姿，展示脸、发型、身材比例、全套服装和鞋子。
2. 第二格：向画面右侧旋转约 45 度的完整全身。展示脸部立体结构、耳朵、发型、肩颈、身体比例和服装，必须与第一格同一模型。
3. 第三格：完整全身背面。完全背对镜头，不能回头，展示头发背面、服装背面、肩背、裤装和鞋子后部。
4. 第四格：正面胸上特写。从胸部到头顶，重点展示五官、眼神、脸型、发型、碎发和皮肤或面部材质，是角色识别核心区域。
5. 第五格：主面板内部上下分成三个区域。上部为双手与袖口特写；中部为上装、内搭、下装的材质特写；下部为鞋子特写。全部细节与全身角色一致。
6. 第六格：主面板内部上下分成三个区域。上部为自然开心或轻微笑容；中部为克制生气；下部为安静哭泣。三种表情必须来自同一个模型，脸部骨骼和所有五官完全一致。

不得改成九宫格、四视图、海报、商业写真、头像合集或自由拼贴。

### 【核心美型方向】

用中英文视觉关键词强化当前角色的审美方向，但不能依赖明星、艺术家或现有影视角色名字。关键词要覆盖地域美感、年龄、气质、脸部结构、眼神、身材比例、电影角色感和制作级别。

### 【渲染与最终效果】

3D 角色写清高品质建模、PBR 材质、皮肤次表面散射、眼球角膜、毛发系统、布料模拟、全局光照、环境光遮蔽、接触阴影、色彩管理和电影级抗锯齿。

2D 角色写清线稿、上色体系、阴影层级、五官稳定、发丝、布料纹理、前中后景、统一光线和高分辨率动画设定稿质量。

最终效果要说明观众第一眼应该感受到的角色级别，以及必须避免的“普通 AI 美女”“游戏角色”“商业写真”或“廉价 CGI”。

### 【强制角色一致性】

六个区域必须是完全相同的角色，不是六个相似人物。

逐项锁定：面部骨骼、眼睛、眉毛、鼻子、嘴唇、耳朵、下颌、发际线、发型、肤色、年龄、身材比例、服装、鞋子和材质。

允许变化只包括：角度、镜头距离、表情和局部细节展示。

### 【Negative Prompt】

Negative Prompt 必须与以上正向内容放在同一条提示词末尾，不单独拆列。

至少覆盖：

- 媒介错误：真人照片、真人演员、自拍、商业写真、错误的 2D 或 3D 风格。
- 身份错误：明星脸、网红脸、不同人物、姐妹脸、身份漂移、年龄漂移。
- 五官错误：巨大动漫眼、欧美深眼窝、尖下巴、夸张嘴唇、浓妆、脸部扭曲和左右眼不一致。
- 材质错误：塑料皮肤、蜡像皮肤、玻璃皮肤、塑料头发、贴片头发、廉价 CGI。
- 身材服装错误：超模比例、极端长腿、夸张腰臀比、性感暴露、服装变款、鞋子变化。
- 解剖错误：多余肢体、多余手指、融合手指、缺失手指、手部畸形、身体重复。
- 排版错误：裁头、裁脚、面板重叠、六格不等宽、自由拼贴、九宫格、文字、标题、标签、数字、Logo 和水印。
- 灯光错误：霓虹、赛博朋克、过强轮廓光、过度体积光、过曝 Bloom、过度 HDR 和廉价游戏灯光。

最后用一句话再次锁定：角色审美方向 + 漫剧或动画电影级别 + 成熟气质 + 角色一致性。
