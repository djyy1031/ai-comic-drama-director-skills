# 仅分镜组提示词交付

## 使用条件

用户只要求当前剧本的分镜组提示词，不要求资产列表、生产表、声音表或完整项目目录时使用本模式。用户给出的剧本、全局控制提示词和已锁定项目配置是内容来源；参考案例只提供结构，不得替换当前剧本事实。

开始前仍要确认项目希望的单集时长。用户指定130秒等目标时优先接近，但按本集内容可在约90秒至180秒内调整；用户未指定时默认使用90—180秒正常范围。该目标不能通过空镜、重复反应或拖慢语言强行达成。

## 内部协作，外部单一交付

内部依次完成：

未提供成品资产时，模块顺序保持为：`人物表演资产库 → AI影视导演语言资产库 → 镜头执行与连续性检查库 → 人工智能漫剧导演编译`。

提供成品资产时，模块顺序固定为：`分镜资产接入与空间锚定库 → 人物表演资产库 → AI影视导演语言资产库 → 镜头执行与连续性检查库 → 人工智能漫剧导演编译`。新增模块只在内部提供真实资产证据，不改变现有最终文档格式和提示词效果。

1. 冻结原文事件、人物、台词、内心独白、场景、道具和先后顺序。
2. 若用户提供成品资产，调用 `$ai-storyboard-asset-grounding` 逐项查看实际内容，锁定场景空间、角色身份、道具状态和声音绑定；只有文件名不得算作核验。
3. 调用 `$ai-character-performance-assets`，为所有画面内人物建立当前目标、策略、听者反应、可见身体行为和跨镜状态；背景人物也必须有克制且符合处境的表情或动作语言。
4. 调用 `$ai-cinematic-directing-assets`，把表演节拍转为多个正常镜头，不把一个20～30秒分镜组写成一个长镜头。
5. 调用 `$ai-shot-execution-continuity`，检查第一帧、站位、朝向、视线、道具手、轴线、光线、动作物理、切点、语言承接及已核验资产一致性。
6. 由 `$make-ai-comic-drama` 编译为当前模型可用的纯净提示词，逐字核对语言片段并运行文档校验脚本。

只向用户交付最终 Markdown 文档。除非用户追问，不附人物表演方案、导演镜头表示、检查报告、资产清单、Excel或完整工作流状态。

## 文档结构

文档标题使用：

```text
# 第X集 Seedance 2.5纯分镜提示词 动作触发版
```

没有实际音频时，标题后增加简短时间说明：当前时长是 `ESTIMATED`，依据人物年龄、音色倾向、情绪、语速、重音、呼吸和触发动作估算；生产前使用实际音色进行 `ACTUAL_READ` 校时。

随后增加一行：`项目时长规划：用户目标约130秒；本集根据剧情实际规划为X秒；偏离或贴近目标的原因是……`。用户未指定目标时改写为“采用默认90—180秒正常范围”。整集低于90秒或超过6个分镜组时，分别增加 `时长例外说明：` 或 `分镜组数量例外说明：`。

每个分镜组使用以下结构，顺序不可交换：

````text
## 分镜组一 完整事件名称 26秒

```text
【全局固定画质参数】
完整粘贴项目锁定的全部全局画质、负面、明暗和光影内容，不写“同前”。

发声角色=发声角色音色=
只出镜角色=
当前场景=
当前道具=
【摄影机运动总设定】
写清轴线、摄影机活动侧、镜头允许运动和禁止越轴条件。
【场景与光影】
写清时段、天气、空间结构、主光方向、曝光、色卡和需要继承的物理状态。
【起始站位】
写清每个出镜人物的世界位置、画面位置、朝向、视线、距离和持物状态。
【语言连续性总锁】
只声明本组语言的逐字一致、动作触发、无停顿承接、音色与口型规则，不另建计时音轨。
【0.0—4.0秒】：第一个正常镜头……
【4.0—8.0秒】：第二个正常镜头……
```
````

资产绑定没有额外标题，并且必须紧贴在 `【摄影机运动总设定】` 之前。即使没有运行资产表，也保留空等号供平台绑定；只列本组实际调用项。

## 语言写法

- 第一片段必须先写可见动作或现场事件，再写开始时刻：`角色完成具体动作后，角色（声音和情绪状态）朝向对象开始说：“原文片段”`。
- 内心独白写：`具体信息被角色看到后，角色嘴唇闭合、无口型，立即开始内心独白：“原文片段”`。
- 后续镜头写：`切入本镜时，角色保持同一音色、音量、呼吸和情绪进程，无停顿承接上一镜继续说/继续内心独白：“原文片段”`。
- 切到听者、道具或环境时，声音可以变为画外连续声，但不能重新起句、重置呼吸、漏字、重复或改变原文。
- 同一语言单元的全部片段顺序拼接后必须逐字等于原文。默认不跨分镜组拆一句；确有模型上限冲突时先报告并取得批准。
- 每个承载语言的镜头最后追加：`视频严禁出现台词、内心独白与系统语音字幕。`

## 镜头与时长

- Seedance 2.5每组优先承载一个20～30秒完整事件，最多30秒；事件自然完成时可更短，不为凑时长添加空镜。
- 同一场景且事件连续时，优先合并到接近30秒，并尽量用不超过6个分镜组完成本集；多场景、高密度剧情或复杂动作允许增加，但必须说明原因。
- 一个分镜组必须包含多个正常镜头。普通对话镜头以2～5秒为主，默认不超过6秒。
- 每镜从第一帧进入有效动作、反应、视线或摄影运动，结束状态能够成为下一镜起始状态。
- 对话使用建立镜头、说话者、听者反应、过肩、双人和关系落点等镜头节拍。说话者说话时，听者和背景人物同步呈现符合信息认知的反应，不能木站。
- 分组边界优先落在完整语言、完整动作、完整情绪落点或自然转场之后。禁止把一句话的两半放到相邻组开头和结尾。
- 每个非末组的最后一镜必须直接写出“转场到下一组：”，说明转场方法、连续锚点和下一组建议首镜；下一组第一镜必须按该设计开始。
- 尾镜与下一组首镜使用不同镜头签名。默认禁止同一人物脸部特写直接衔接同一人物脸部特写；应改换主体、景别、动作、道具或环境落点。只有有明确必要性的匹配剪辑可以例外。

## 交付前检查

运行：

```powershell
python scripts/validate_prompt_only_markdown.py "第X集_Seedance2.5_纯分镜提示词_动作触发版.md"
```

检查通过后再交付文件。脚本负责检查每组全局控制段一致、资产绑定位置、镜头时间连续、普通镜头不超过6秒、优先不超过6组、非末组尾镜转场桥、旧式独立音轨缺失、语言首次触发、续说承接和禁字幕尾句。剧情忠实度、逐字原文、人物表演、成品资产一致性、30秒合并合理性与下一组首镜是否真正兑现转场仍需由内部模块共同审核，不能只依赖格式脚本。
