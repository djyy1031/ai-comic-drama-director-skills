# Seedance 2.5 模型配置

只在 `project_config.model_profile = seedance-2.5` 时读取。

## 时长与拆分

- 一个分镜组对应一个视频生成任务。同一场景、同一连续事件优先合并到接近30秒，最多30秒；20秒只是可接受下界，不是优先目标。
- 每集先读取项目时长策略。用户指定130秒等软目标时尽量接近，但内容少可靠近90秒，内容多可延长至180秒内；用户未指定时默认按90—180秒自然规划。禁止为了命中秒数添加空镜或拖慢表演。
- 优先用较少分镜组完成整集，通常不超过6组。场景转换多、剧情密度高、动作复杂或语言容量确实需要时可增加，并记录 `shot_group_count_exception_reason`。
- 分镜组包含多个连续小镜头，不等于单镜头。
- 5～12镜可作为20～30秒任务的宽泛参考，不能写成硬限制。
- 优先保持完整事件、连续对话、连续动作和稳定人物空间关系。
- 普通完整台词不改写、不重复。长台词、长独白或长系统语音需要多镜头时，在同一分镜组冻结完整语言单元，再把原文连续分配到独立计时镜头；第一片段由动作或现场事件触发开始，后续片段无停顿承接，所有片段拼接后逐字等于原文。最终提示词禁止另列独立计时音轨总设定。
- 普通对话单镜以2～5秒为主，默认不得超过6秒；20～30秒是分镜组任务时长，不是单镜头时长。禁止用一个3～27秒镜头承载整段对话，除非用户或原文明示一镜到底并记录批准和理由。
- 禁止把 Seedance 2.0 的15秒上限当作本配置默认拆分点。

## 低于20秒的例外

先尝试与相邻连续事件合并。只有出现以下情况之一才保留低于20秒的分镜组，并填写 `duration_exception_reason`：

- 场景或时间明确切换，合并会破坏空间连续。
- 事件已经完整结束，继续填充只会重复反应或制造空镜。
- 台词、动作或情绪在该点形成不可跨越的自然断点。
- 内容合规或模型复杂度要求必须提前结束。

不得用空镜、重复表情、无意义运镜或强行延长台词填到20秒。

事件自然结束后立即结束分镜组。任何较长镜头都要有动作、微表情、视线、环境反馈或摄影运动持续推进；禁止让模型生成一两秒无变化画面后再进入有效表演。

## 事件与镜头设计

每组围绕一个完整事件链，例如：

- 发现信息 → 理解 → 决策 → 行动 → 反馈。
- 对峙建立 → 试探 → 冲突升级 → 结果或新悬念。
- 连续多人对话 → 关系变化 → 关键反应。
- 动作准备 → 交锋 → 反制 → 落点 → 余波。

镜头数量由事件节点、对白、人物数量、空间变化和动作负载决定。12镜只用于确有必要的快速动作、蒙太奇或高密度反应链；慢情绪和重对白可以减少镜头，但仍必须保持正常计时分镜，不能退化成一个覆盖整组的长镜头。

高强度动作、追逐、高速位移、机械变形或大规模特效场面，按 [动作导演模块调用规则](action-direction.md) 先匹配关键词，再检查使用条件和不适用情况。只调用能解决当前镜头问题的模块；不默认要求完整“准备—执行—接触—结果—余波”，原文缺少的阶段不得补造。摄影机物理响应、慢动作和大范围破坏都必须由当前剧情单独触发。

## 同场景分组与剪辑衔接

- 同一场景内容超过30秒时，在完整语义、完整情绪落点、人物关系变化或完整动作结束处拆组；禁止拆在一句台词中间、连续动作中间或人物走位一半。
- 同场景相邻事件能够在模型负载内自然合并时，优先让分镜组接近30秒；明显偏短时说明为什么不能继续合并，不能默认切成多个20秒小组。
- 相邻分镜组继续使用同一标准场景名称、母场景和必要机位，并在每个独立提示词中完整复写相同的场景结构与光影锁定，禁止写“同前”。
- 同场景连续性主要依靠合理拆组、统一场景描述、固定人物关系、视线匹配、正反打、动作完成点和连续环境声实现。
- 首帧、尾帧和重复静止画面默认不用作连续分镜组的常规衔接手段，避免开头停顿、结尾定格和动作卡顿。只有用户明确要求或特殊复杂镜头无法通过场景、站位与轴线约束解决时才评估。
- 每个非末组尾镜只写本组实际结束状态与连续锚点；代码块结束后单列“剪辑衔接：”，说明接法、锚点和下一组首镜。下一组必须兑现，下一场画面与时段指令不得提前写入本组正文。
- 相邻组不复制同一帧，尾镜与首镜的镜头签名必须不同。上一组若以张三脸部特写结束，下一组默认改从李四反应、双人中景、张三完整动作、道具细节或环境反馈开始；禁止同一人物特写直接硬接同一人物特写。明确设计的匹配剪辑例外必须写出匹配依据和必要性。

## 场景、光影与轴线锁定

同一场景的每个分镜组都必须独立写清并保持一致：

- 门窗、道路、建筑、家具和固定道具的位置。
- 时间、天气、主光来源与方向、色温、曝光、人物阴影方向和风向。
- 人物真实位置、画面左右顺序、朝向、视线和行进方向。
- 人物运动轴线或对话轴线，以及摄影机允许活动的唯一一侧。

没有明确叙事理由时禁止越轴。确需越轴时，必须在镜头内展示摄影机经过轴线或先使用轴线上中性镜头重新建立方向，不能直接跳到另一侧。

## 运镜可执行性

每个移动镜头写清摄影机起点、所在轴线侧、移动方向与路径、速度、停止位置和最终对焦对象。每镜只承担一个主要摄影运动；“大师级运镜”“高级感”“环绕＋推拉＋升降”等堆叠词不能替代可执行路径。

## 2.5连续性重点

20～30秒更容易出现漂移，必须加强：

- 场景真实坐标与当前机位画面坐标。
- 角色站位、朝向、视线和动作轴线。
- 服装、姿态、表情强度和身体状态。
- 道具持有者、左右手、外观和开合损耗状态。
- 主光方向、色温和固定场景元素。
- 中途站位变化的完整展示与状态更新。

复杂多人、交叉动作、重要持物或打斗优先评估 Blocking、人物持物、姿态和互动参考。Start Frame（起始帧）与 End Frame（结束帧）默认必要性为0，仅在用户明确要求或特殊镜头经审核确有必要时提高。

## 2.5审核

必须确认：

- 每组 `duration_seconds <= 30`。
- 是否在同场景可合并的前提下优先接近30秒，是否无理由切出多个偏短分镜组。
- 是否优先不超过6组；超出时是否有具体的场景转换、剧情密度、动作复杂度或语言容量原因。
- 低于20秒时存在具体且合理的 `duration_exception_reason`。
- 没有为追求长时长塞入过量动作、对白或机位变化。
- 未混入 Seedance 2.0 的15秒硬上限或3～7镜默认参考。
- 同场景相邻组是否拆在完整事件或情绪落点，是否复用一致的场景、光影、轴线和人物左右关系。
- 是否依赖重复首尾帧造成停顿；普通连续场景应使用剪辑逻辑和声音连续完成衔接。
- 每个非末组尾镜是否写明下一组转场桥，下一组首镜是否兑现；是否出现相同镜头签名，尤其是同一人物特写硬接同一人物特写。
- 每个运镜是否包含起点、轴线侧、路径、速度、终点和最终焦点。
- 高强度动作是否存在可读的身体动力链，受击和大范围破坏是否发生在接触之后。
- 特效是否有来源、方向、传播先后和环境反馈，是否误把机械、术法或天赋改变成另一种能力体系。
- 局部手持、过焦、滚转和震动是否由动作触发并迅速恢复；是否为了“临场感”整段乱抖。
- 纯净提示词使用 [纯净提示词格式](prompt-format.md)。
