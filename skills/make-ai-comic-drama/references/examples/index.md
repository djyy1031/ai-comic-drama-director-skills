# 可执行案例索引

案例只展示局部思路，不是可复制的最新提示词格式。正式制作先按 [分镜模板、职责与交付检查](../prompt-contract.md) 改写并逐项验收；旧案例里的裸焦距、跨镜指令、默认时长或内部审核语不能进入视频模型正文。人物、场景、焦距和时长都重新按当前剧本与资产确定。

- [Seedance 2.5动作模块按需调用](seedance-2.5-action-group.md)：展示如何只调用剧情真正需要的动力链、位移分离、特效传播和延迟受力模块。
- [连续音轨与正常对话分镜](continuous-dialogue.md)：展示完整音轨只说一次，同时用独立计时的双人、过肩和反应镜头保持正常剪辑节拍。
- [同场景跨分镜组连续性与资产绑定](continuity-and-assets.md)：展示不用首尾帧时如何保持站位、轴线、光影、道具和声音衔接。

读取规则：只读取与当前任务相符的案例。不要为了“案例齐全”把全部案例内容塞入用户交付。
