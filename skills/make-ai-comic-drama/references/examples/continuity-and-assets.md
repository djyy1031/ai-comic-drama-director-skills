# 同场景跨分镜组连续性与资产绑定案例

本例展示不用重复首尾帧时，如何让同一教室里的两个视频生成任务自然衔接。

## 分镜组一结束锚点

```text
资产绑定：顾平生、洛清雪、叶晚星、金融一班教室日间母场景、教室中央过道靠窗侧视角图。
空间锁定：讲台在南侧，出口在东北角；摄影机始终位于中央过道靠窗一侧。顾平生在画面中央，洛清雪在顾平生左侧，叶晚星在左后方。5600K冷白日光从西侧窗户进入，阴影落向东后方。
末镜动作：顾平生说完“走吧，去操场散散心”，右手从洛清雪左肩自然落下。顾平生先转向东北角出口，洛清雪随后松开衣角，叶晚星抬眼看向两人。
结束状态：顾平生面向出口并迈出第一步；洛清雪位于顾平生左后方半步；叶晚星位于洛清雪后方一步。教室远处脚步声减弱，操场风声提前进入。
```

## 分镜组二起始锚点

```text
资产绑定仍使用：顾平生、洛清雪、叶晚星、金融一班教室日间母场景、教室门内朝出口视角图。
空间与光影完整复写：讲台在南侧，出口在东北角；摄影机仍在中央过道靠窗一侧，禁止跨到讲台侧。5600K冷白日光从西侧窗户进入，阴影仍落向东后方。
起始状态：顾平生承接上一组第一步继续朝出口行走；洛清雪位于顾平生左后方半步并开始跟随；叶晚星位于洛清雪后方一步。三人画面左右关系、朝向和步速不重置。
起始镜头：50mm中全景，摄影机沿三人前进方向平稳后退到出口内侧。第一帧直接进入连续行走，操场风声延续并逐渐增强，不重复上一组拍肩、放手或起步动作。
```

## 检查重点

- 两组分别写完整场景和光影，不写“同前”。
- 第二组继承上一组已经完成后的状态，不重复末帧。
- 使用动作完成点和声音先行衔接，不依赖首尾帧资产。
- 机位可以变化，但仍位于同一轴线侧，人物左右关系不翻转。
