# 连续长台词表演单元案例

## 原文条件

林舟需要用一段完整台词安慰程月。台词本身是一个连续思想，不能拆到两个分镜组，也不能为了切镜重复起句。

## 正确写法

```text
完整台词：
林舟（语气平静、认真）朝向程月说：
“你不要看谁不喜欢你，你要看谁喜欢你，知道吗？你不可能做到被所有人喜欢。”

台词音轨覆盖【0.0—9.0秒】，只完整说一遍。镜头变化期间语气、音量、呼吸和口型连续，禁止停顿、重新起句、重复台词或声音状态重置。实际切镜点跟随林舟的自然语速、停顿和情绪，不设置子时间点。

【0.0—9.0秒｜连续台词表演单元】
以50mm双人中景开始，林舟睁开眼，身体从椅背稍微前倾，视线落到程月脸上；程月双手仍抱膝，目光偏低。随后自然过渡至程月右肩后方的过肩中近景，摄影机缓慢推进约0.2米，林舟保持连续口型和同一呼吸，右手指尖轻点椅子扶手。林舟说到观点转折时，镜头自然过渡至程月面部近景，林舟的声音作为画外连续说完；程月紧绷的手指逐渐放松，眼神从失落转为思考。结束状态：林舟保持注视，程月抬眼准备回应。

视频严禁出现台词、内心独白与系统语音字幕。
```

## 检查重点

- 完整台词只出现一次。
- 总时间覆盖整段表演，内部镜头不写死秒点。
- 内部切镜由语义和情绪转折触发。
- 说话人的呼吸、口型、音量和语气连续。
- 听者不是静止背景，而是持续产生可见反应。
