# 导演知识调用

## 作用

把原文中的“生气、害怕、打斗、御剑、追逐”等抽象语义翻译成可见、可计时、符合角色和类型的视听行为。

公式：

`原文语义 + 角色表演档案 + 类型规则 + 情绪强度 + 动作时间预算 + 摄影目的 = 可执行分镜语言`

知识包只能增强表达，不能添加剧情事实、改变人物选择或颠倒事件结果。

## 调用顺序

1. 确认原文实际发生的事件和不可改变信息。
2. 读取主要角色的表演档案。
3. 读取项目配置中的 `genre_packs`，只加载与当前场景相关的包。
4. 按情绪强度和动作时间筛选可用表达。
5. 选择最少但足够清楚的动作、表情、运镜和声音。
6. 检查是否仍忠于原文、符合角色、能在镜头时间内完成。

禁止把整个词库或所有特效一次性塞进提示词。

## 情绪与表演知识

情绪条目至少包含：

- 情绪类型和1～5强度。
- 面部：眉、眼、嘴角、下颌、鼻翼等可见变化。
- 视线与眨眼频率。
- 呼吸、吞咽和声音变化。
- 手部与无意识小动作。
- 肩颈、重心、步态和距离变化。
- 适合的景别、机位和节奏。
- 不适合的夸张表达。

“冷怒”可表现为下颌收紧、眨眼减少、手指缓慢收拢、语速下降；是否采用取决于人物档案，不能让所有角色都这样生气。

## 角色表演档案

主要角色记录：

- 情绪外放或克制程度。
- 常见微动作和身体习惯。
- 爆发方式、退缩方式和撒谎方式。
- 语速、停顿、音量、咬字和口头习惯。
- 与不同人物相处时的距离、视线和姿态差异。
- 禁止使用的不符合性格动作。

同一种情绪必须经过人物档案再表达。

## 动作时间预算

动作词库不只存名称，还要存阶段：准备、执行、接触或影响、反应、恢复或结果。

使用原则：

- 时间值是规划范围，不是逐帧物理真值。
- 连续动作先计算总时间，再决定镜头数量和切点。
- 一个镜头无法容纳完整动作链时，删减次要动作或拆组，不能加速到失真。
- 切镜尽量落在动作完成、冲击反馈或视线转换点。

## 连续台词音轨与正常分镜

- 普通台词保持一条完整表演，不为增加景别机械拆句。
- 长台词先设计完整声音曲线：起始情绪、语速、呼吸、重音、转折、爆发或收束，再选择能承接这些变化的镜头顺序。
- 多镜头长台词设置一条连续音轨，但画面必须拆成独立计时镜头。以中景或双人镜头建立关系，随后按语义、视线、动作和反应点切至过肩、近景或听者反应。
- 普通对话单镜以2～5秒为主，默认不超过6秒。只有用户或原文明示一镜到底时才允许更长，并记录批准状态、不可替代理由和持续画面变化。
- 切镜期间声音和口型必须连续，禁止停顿、重复起句、重复台词、音量重置或呼吸重置。
- 情绪由平静转为激动时，先让视线、呼吸、手部、肩颈和重心逐渐变化，再用景别靠近或稳定镜头承接爆发；不能仅靠语气标签突然跳变。
- 完整语言音轨超过模型单组上限时报告限制，在完整语义停顿处规划下一组；不能删改台词、重复起句或从词语中间截断。

## 现代动作知识包

重点：真实重心、距离、惯性、攻防关系、遮挡和环境反馈。

- 建立空间时优先让双方身体和距离可见。
- 动作按准备、攻击、格挡或闪避、受力反馈、恢复站位组织。
- 不把冲刺、连续拳脚、摔投和起身全部塞进数秒。
- 摄影机服务动作识别；快切可强化反馈，但不能掩盖全部动作。
- 道具和武器持续锁定持有者、左右手和长度比例。
- 重击按支撑脚、胯、腰胸、肩、大臂、小臂、手腕、拳脚或武器的顺序检查动力链；受击方在接触后才出现形变、失衡和整体位移。
- 高速位移与攻击分成可读节拍。只负责接近的镜头明确“只位移、不攻击”，避免模型提前命中或绕到错误方向。
- 高燃动作只在关键词初筛并满足实际使用条件后，按 [动作导演模块调用规则](action-direction.md) 选择最少的导演模块；禁止整套照搬优秀案例。

## 修仙仙侠知识包

重点：术法规则、能量来源、距离尺度、蓄力、释放、防御、余波和空间层级。

- 御剑、轻功、瞬身、结印、剑气、法阵、护盾、威压和法宝分别建立动作与特效规则。
- 术法通常包含起势、聚能、成型、释放、对手反应和环境余波。
- 能量颜色、纹理、方向和光照影响从世界观或资产继承，不能每次随机变化。
- 远距离术法、空中交锋和高速位移必须先建立空间方向和高度关系。
- 不套用现代拳脚的时间尺度和摄影逻辑。

## 摄影语言

选择摄影方法前先回答：本镜要让观众看清空间、动作、信息还是情绪？

- 运镜写明起点、路径、速度、终点和最终焦点。
- 固定镜头也是有效选择；禁止为了显得专业而让所有镜头移动。
- 正反打、过肩和环绕必须服从180度轴线、站位和视线。
- 越轴只在明确表达失衡或关系突变时使用，并建立新的空间方向。
- “大师级”“高级感”“盗梦空间式”等模糊词不代替可执行摄影指令。
- 摄影机可以像现场观察者一样受到动作影响：高速主体掠过时允许跟焦慢半拍，撞击时允许短促震动或轻微滚转，随后必须重新抓焦并恢复稳定；唯一关键接触不能被故意失焦遮掉。

## 知识条目建议字段

```yaml
name: 冷怒
category: emotion
tags: [anger, restrained, confrontation]
intensity: [2, 4]
visible_cues: [下颌收紧, 眨眼减少, 手指缓慢收拢]
voice_cues: [音量不提高, 语速下降, 句尾缩短]
camera_options: [中近景缓推, 眼神特写, 稳定固定镜头]
avoid: [无原因咆哮, 夸张挥舞]
```
