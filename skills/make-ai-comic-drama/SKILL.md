# 人工智能漫剧导演

把 Patrick 的小说或剧本忠实转成能直接生产的人工智能漫剧。优先保证剧情完整、节奏紧凑、表演连续、空间稳定、资产合理和声音有效；禁止为了时长、镜头数量或模板完整而牺牲剧情节奏。

## 通用导演逻辑，不按风格限制能力

所有项目先读取 [通用导演逻辑与风格适配](references/universal-directing-and-style.md)。Seedance 2.0与2.5、仿真人与2D/3D及皮克斯式等动画风格、古装与现代、任意画幅，均使用同一套表演、摄影、动作、光影、空间、初始站位、轴线与语言连续性逻辑。风格和画幅只改变具体呈现，不能关闭或省略专业模块。

用户说明风格、时代、画幅后，由本技能生成对应的项目全局段与局部表达并记录版本；不用用户另写一套提示词，也不因缺少预制风格模板停止。仅在决定性信息确实未给出时询问。既有固定全局段是可选的具体风格预设，不代表技能支持范围。

## 中文与交付边界

- 面向 Patrick 的内容默认使用中文。不可避免的英文缩写首次出现时紧跟中文说明。

- 只交付 Patrick 当前要求的部分；只要分镜提示词时，不自动附加项目总案或其他表格。

- 单次测试可直接交付文本或文档；长期项目才建立可暂停继续的生产目录与状态文件。

- 不把资产清单、制作说明、审核记录或文件路径混进供视频模型复制的纯净提示词。

## 开始前

1. 判断输入是小说正文、章节、分集卡、剧本、分镜、资产文件夹、参考图还是粗剪时间线。

2. 新项目开始时询问“希望每集大概多长”。用户给出130秒等目标时，将它记录为优先接近的软目标；仍根据本集剧情密度自然调整，内容少可接近90秒，内容多可延长但绝不超过180秒。用户没有特别要求时，采用正常90—180秒区间，由剧本决定具体时长。

3. 只确认会明显改变结果的其他信息：Seedance模型版本、2D、3D或仿真人等视觉形态、画幅、统一美术风格，以及用户允许的改编范围。用户已明确的内容不重复询问。

4. 新项目必须锁定 `model_profile`、`render_mode`、`aspect_ratio`、`visual_style`、`global_prompt_profile`（全局控制提示词版本）和集时长策略。禁止仅凭“漫剧”自行猜测画风、画幅或全局画质规则。

5. 使用长期项目流程时读取 [工作流与状态](references/workflow.md)；一次性测试只读取本次任务需要的参考。

## 分镜组站位图模式

Patrick 已要求在本地成品资产驱动的分镜制作中加入站位图时，默认启用 `$ai-storyboard-blocking-assets`。先核验实际资产并匹配本集需求，候选镜头和连续性检查后制作或复用站位图，图文一致后再编译最终提示词。每个分镜组只关联一张；相邻组变化小且原图仍准确时复用同一文件，不额外生成首尾帧。具体生成、复用、归档与失败处理遵循该技能。

本模式优先于下文“只交付一份 Markdown”“不展示中间资产”和“首帧尾帧默认不生产”的相关输出限制：交付分镜文档与必要站位图，在每组代码块外链接图片或注明复用；站位图是空间参考，不自动作为首尾帧。用户本次明确只要文字时不生成图片。缺少该技能或图片尚未完成时如实说明，不伪造交付。

## 分镜组提示词直出模式

当 Patrick 说明“目前只需要分镜组提示词”“先过分镜这一关”“不跑资产列表”或要求沿用第24集动作触发版的交付形态时，进入 `STORYBOARD_PROMPTS_ONLY`：

- 只接收本次已锁定剧本和已有项目配置，内部完成剧情事实冻结、人物表演、候选镜头、连续性检查、模型编译与提示词审核；不启动母资产表、子资产表、Excel、声音执行表、资产生产或后续完整项目流程。

- Patrick 提供已完成的场景、角色、道具或声音资产时，先调用 `$ai-storyboard-asset-grounding`（分镜资产接入与空间锚定库）查看真实内容并建立资产锚定包，再按 `人物表演资产库 → AI影视导演语言资产库 → 镜头执行与连续性检查库 → 人工智能漫剧导演编译` 协作；未提供成品资产时保持原有文字流程，不伪造资产检查结果。

- 面向 Patrick 仍只交付一份最终 Markdown 分镜提示词文档，不展示内部资产锚定包或其他中间表。

- 默认文件名为 `第X集_Seedance2.5_纯分镜提示词_动作触发版.md`；每个分镜组是可单独复制给视频模型的独立代码块。

- 每个代码块第一行完整复写锁定的全局控制提示词，随后写本组资产绑定、摄影机运动总设定、场景与光影、起始站位、语言连续性总锁及连续逐镜时间段。不得用“同前”、不得省略资产绑定，也不得附加资产列表。

- 没有实际音色文件时，文档开头明确标记时长为按声线、情绪、重音、呼吸和动作触发进行的 `ESTIMATED`（估算）；正式生产前必须用实际音色试读并仅校正时间，不改台词、镜头事件与连续关系。

- 即使只交付分镜提示词，也先应用项目集时长软目标、当前模型单组上限与统一事件分组规则；不得因为省略资产流程而跳过时长规划与跨组转场设计。

- 完整格式、直出步骤和交付前检查读取 [仅分镜组提示词交付](references/prompt-only-storyboard-delivery.md)。生成文件后必须运行 `scripts/validate_prompt_only_markdown.py <文档路径>`，校验失败不得交付。

## 可交付内容

### 小说正文与详细分集卡

- 小说正文严格按原章节顺序整理，不按人物或剧情线重新打乱。

- 原文已有集数时保留原集数；未拆集时才按完整冲突、人物选择、信息揭示和结尾钩子拆集。

- 分集卡必须写清承接、目标、阻力、关键事件、冲突升级、人物选择与代价、不可逆变化、高潮回报和下一集钩子。

- 详见 [小说正文与详细分集卡](references/novel-and-episode-cards.md)。

### 资产与生图提示词

- 识别并去重角色、服装、状态、场景、道具、武器、生物、载具、UI（系统界面）、VFX（视觉特效）和声音资产。

- 面向 Patrick 和模型统一使用原文标准名称；内部ID只用于机器去重。

- 资产数量由全文剧情覆盖率、复用频率和稳定性收益决定，不按单集重复建资产。

- 设计场景资产前，必须先读取本次提供的全部正文；长期项目优先读取完整的 normalized_script.md。禁止只看当前集就冻结跨集场景。

- 已安装 $ai-comic-scene-assets（漫剧场景资产导演）时，调用它建立场景全文证据账本、场景家族、区域树、空间关系、视觉DNA、逐级生产顺序、单张生图提示词和一致性审核。大门、大厅、厨房、楼梯、包间等同一建筑区域不得独立重新设计。

- 正式生产场景前必须建立带版本号的全剧统一色卡，供所有场景生图与后期调色共同继承。所有场景先生产白天母资产；未指定天气时默认晴朗。同一场景涉及雨、雪、雾、黄昏或夜晚时，资产表必须登记使用集数并输出引用白天图的派生提示词，只改变光线、天气及其直接物理反馈，不得改变格局、机位、构图、固定物、数量、位置、材质或色卡版本。

- 使用支持一次生成多张图的GPT网页版工作流时，同一场景家族可按实际需要组织最多10张独立资产图：先提供综合全文的场景总框架，再逐张提供独立提示词；严禁九宫格、拼贴、分屏、一张图多个镜头或把不同场景混进同一批次。

- 同批多图若由工具并行生成，只能视为文字框架统一的草案套图；不得伪造“后图已实时参考前图”。正式生产前必须审核真实图片、冻结合格锚点，并用参考图返修漂移图。

- 本 Skill 保留原文、项目配置、资产标准名称、角色与道具资产、分镜需求和最终生产状态的裁决权；场景专业 Skill 不得改写剧情或替代分镜。

- 场景专业 Skill 未安装时，只能按 [资产与场景机位](references/assets-and-camera.md) 做基础场景家族规划，并明确标记 FALLBACK_INTERNAL；不得恢复固定四格、多视角一次生成或虚构16K输出。

- 人物与道具生图布局继续读取 [资产与生图提示词](references/assets-and-image-prompts.md)；核心角色读取 [核心角色资产提示词固定模板](references/character-asset-prompt-layout.md)。

- 用户完成资产并提供文件夹后，读取 [资产文件夹接入与逐项审核](references/asset-folder-review.md)，先自动扫描匹配，再逐个查看真实内容；文件名匹配不等于资产正确。

### 分镜、视频与声音

长期生产使用母资产总表、场景机位矩阵、分镜组资产矩阵、子资产生产清单、视频输入包和分集声音执行表。结构和字段见 [数据约定](references/data-contract.md)。

## 导演知识库调用

- 设计分镜组前，先按 [AI影视导演语言资产库调用](references/director-routing.md) 建立导演调用请求。

- 用户提供成品资产时，必须先按 [成品资产驱动分镜](references/prepared-asset-grounding.md) 调用 `$ai-storyboard-asset-grounding`。文件名只用于定位，必须查看实际资产；通过后的空间、身份、道具状态和声音绑定是导演与连续性检查的事实约束。

- 已安装 `$ai-cinematic-directing-assets`（AI影视导演语言资产库）时，调用它完成场景诊断与镜头设计，并由它协调两个窄模块：`$ai-character-performance-assets`（人物表演资产库）先提供人物目标、策略变化、听者反应和状态继承；候选镜头形成后，`$ai-shot-execution-continuity`（镜头执行与连续性检查库）再检查第一帧、站位、朝向、视线、道具手、轴线、光线、物理和切点继承；最终返回中性“导演镜头表示”。

- 有成品资产时调用顺序固定为：`冻结剧情事实 → 成品资产接入与空间锚定 → 人物表演方案 → 候选导演镜头 → 镜头执行与连续性检查 → 模型编译`；无成品资产时保持原有顺序。不能在镜头已经定稿后才临时补资产或表演，也不能在连续性检查失败时直接输出最终提示词。

- 人物表演模块不得用情绪词代替行为，不得改写台词或决定镜头时长；镜头执行模块不得擅自改变镜头数量或将场景改成一镜到底。两者都返回中性数据，由本 Skill 保留最终裁决。

- 本 Skill 保留原文忠实、分镜组边界、时长、模型选择、资产绑定、声音、最终提示词格式和生产裁决权。专业库不得改写剧情，也不得直接替代最终 Seedance 提示词。

- 未安装任一专业库时，使用对应内置基础规则降级完成，并在导演镜头表示中明确记录 `FALLBACK_INTERNAL`；不得假装调用成功。

## 同一流程，两个单组时长上限

按Patrick确定的制作配置：Seedance 2.0每组最多15秒，Seedance 2.5每组最多30秒。分别读取 [2.0时长配置](references/model-seedance-2.0.md) 或 [2.5时长配置](references/model-seedance-2.5.md)，两者调用同一套通用规则，不维护两套导演或表演逻辑。

镜头数量、语速、运镜、情绪、光影和剪辑由同一剧情与实际承载能力决定。没有模型专属最低时长、镜头数量或必须凑满的目标。分镜组在当前上限内自然结束，完整动作和语言仍遵守统一边界；更换模型只重新检查时长及由此受影响的分组和衔接，不重置表演、资产或风格。

专业库不可用时才按 [动作导演模块调用规则](references/action-direction.md) 和 [导演提示词与资产模块库](references/directing-asset-library.json) 降级；关键词只用于初筛，禁止因为出现一个词就自动套用整套动作模板。题材模块由实际事件触发，适用于两个模型及全部风格。

## 固定层级与时长

固定使用：`集 → 分镜组 → 镜头 → 视频生成任务`。

- 一集包含多个分镜组；一个分镜组包含多个镜头，不等于一个镜头。

- 一个冻结后的分镜组及其内部镜头共同编译为一个视频生成任务。

- 分镜组时长不是单镜头时长。普通对话镜头以2～5秒为主，默认不得超过6秒；超过6秒必须是用户或原文明确需要的一镜到底，并记录不可替代的长镜头理由与持续画面变化。

- 每集先遵守项目级时长策略：用户指定的130秒等数字是优先接近的软目标，不是必须精确凑满；正常范围为90—180秒。本集内容较少时靠近90秒，内容较多时可超过软目标但不得超过180秒；每次偏离软目标都用剧情密度、场景转换、语言实测或动作复杂度解释，禁止用空镜、重复反应或拖慢语速凑时长。

- 用户没有指定时长时，默认在90—180秒内按剧情自然安排。若原文少到无法在不注水的前提下接近90秒，先报告合并相邻内容、调整分集或缩短本集的选择，不暗中填充无效内容。

- 禁止为凑时长加入空镜、重复反应、无意义停顿、慢放、无作用运镜或静止画面。允许补充不改变剧情的动作、微表情、视线、环境反馈和镜头语言，但每项必须增强表演、信息或连续性。

- 原剧本在180秒内无法忠实容纳时，报告拆集或压缩冲突，禁止暗中删剧情。

## 场景稳定与逐镜执行

生成分镜前必须读取 [场景稳定与逐镜执行](references/scene-stability.md)，核对背景依据、遮挡、动作与当前任务边界。此规则优先于旧案例中正文内“转场到下一组”的写法；剪辑说明放在代码块外。

## 分镜组边界与连续性

- 分镜组必须严格按原剧本事件、台词、说话人和先后顺序设计，不擅自增删、改写、消音或调换。

- 同一场景优先把完整事件、完整情绪落点、完整动作和一条完整语言留在同一分镜组；视觉镜头可以在语言持续期间正常切换，但不得停顿、重启、漏字或重复，也不得切在动作过程或人物走位中间。

- 默认禁止把同一句对白或内心独白拆到相邻分镜组。确实无法避免时，必须记录上游明确批准，在前组尾镜完成自然转场桥，并让后组首镜使用不同景别、不同机位或不同主体继续承接；禁止用相同特写或相同机位重复开头。

- 相邻分镜组分别复写相同场景结构、光源方向、色温、曝光、阴影、天气、风向、人物左右关系、运动轴线与摄影机允许活动侧，禁止写“同前”。

- 每个非末组尾镜只写本组实际结束状态与连续锚点；代码块结束后单列“剪辑衔接：”，说明接法、锚点和下一组首镜。下一组必须兑现，下一场画面与时段指令不得提前写入本组正文。

- 相邻组的尾镜与首镜必须使用不同的镜头签名。默认禁止同一人物特写直接硬接同一人物特写；上一组若结束在张三脸部特写，下一组优先改为李四反应、双人关系、中景动作、道具细节或环境反馈。只有明确设计的匹配剪辑才可例外，并写清匹配依据与必要性。

- 默认使用视线匹配、正反打、动作完成点、声音先行或声音延续衔接，不依赖重复首尾帧。首帧和尾帧默认不生产，特殊复杂镜头经审核确有必要时才使用。

- 每组明确人物真实空间位置、画面位置、朝向、视线、距离、行进方向和道具状态。没有叙事理由时禁止越轴；确需越轴必须在画面中重建方向。

## 节奏与有效画面

- 每个镜头从第一帧进入有效表演或有效摄影运动，不设置无内容的前摇；台词或动作结束后立即进入下一个有效反应或结束分镜组，不留拖延尾巴。

- 任何持续时间较长的镜头都必须有可见进展：角色动作、微动作、表情变化、视线变化、呼吸与重心变化、人物关系变化、环境反馈或摄影机运动至少一项持续推进。

- 一两秒内画面、动作、表情、信息和摄影机都没有变化，视为拖镜；除非静止本身承担明确悬念或情绪功能，并写明期间逐步变化的声音或细节。

- 镜头切到人物后立即进入表演，不用无意义前摇。删去与后镜重复、只重复确认同一信息或只能靠后期删除的镜头。

- 镜头数量、单镜时长和切换密度只由剧情、表演和模型承载能力决定，不机械套用统一数量。

- 对话场景默认使用双人建立镜头、说话者过肩或近景、听者反应、关系落点等正常镜头节拍。禁止把分镜组的整个时间段直接写成一个镜头，例如 `【3—27秒】` 承载整段对话。

- 对话镜头必须先说明人物当前想从谁那里得到什么、采用什么策略、策略在何处变化；说话者和听者同时有可见行为。听者可以在话尾前开始反应，困难回答先有判断再开口。

- 导演方案同时决定主视点、信息揭示顺序、此刻拍谁、关系构图、多人调度及目标画幅表达；按 [AI影视导演语言资产库调用](references/director-routing.md) 完成导演质量复核并保真编译，不能写回机械轮流近景。

- 每个镜头只编译当前最关键的2—4个表演行为，不把人物完整表演DNA反复塞进提示词。表演状态、呼吸、身体任务和关系地位切镜后继续继承，直到剧情事件明确改变。

- 每个镜头逐一覆盖所有画面内人物的当前表演，包括次要角色和背景人物。背景人物至少具有符合自身处境的视线、微表情、呼吸、姿态或生活动作之一；不得木站、同步复制主角、提前知道未获知的信息或用过强动作抢戏。没有表演任务的人物应安排在画外。

## 台词、独白与动作触发

- 普通完整台词保持原文不变，不为了镜头数量改写成新句。长台词、长内心独白、旁白、画外音或系统语音可以连续拆入多个镜头，但所有逐镜原文片段依序直接拼接后必须逐字等于完整原文。

- 禁止在最终提示词中另列“连续语言音轨总设定”或“某台词覆盖几秒到几秒”。语言必须直接写入承载它的计时镜头。

- 第一语言片段必须由具体可见动作或明确现场事件触发：写清“谁完成什么动作后，以什么状态开始说/开始内心独白”。内心独白同时写明嘴唇闭合、无口型；对白写明说话方向和口型同步。

- 后续语言片段必须写清“无停顿承接上一镜继续”，继承同一音色、音量、呼吸、语气、口型或思考进程；切到听者、道具或环境时，说明声音转为画外连续声，但不得重新起句。

- 结构化制作数据先建立“语言单元”冻结完整原文和片段顺序，供逐字校验；语言单元不是提供给视频模型的独立音轨时间块。

- 普通对话单镜以2～5秒为主；6秒是默认上限，不是目标。超过6秒只有在用户或原文明示一镜到底时才允许，并必须记录 `long_take_reason` 与 `long_take_approved=true`；否则拆成正反打、过肩、双人镜头或反应镜头。

- 台词时长优先按锁定声线实际试读或试音；未获得音频的规划阶段可根据角色声线、当下情绪、语速、重音、停顿和动作触发逐段估算并标记 `ESTIMATED`，不得用固定字数公式硬切。进入生产前必须使用 `ACTUAL_READ` 重新校时。

- 情绪转折要同时作用于表演和声音。例如先平静克制地陈述，配合轻微动作和稳定镜头；情绪逐渐激动时增加呼吸、肌肉和视线变化，再用更近景别承接爆发，不把情绪不同的两部分拆到两个分镜组。

- 若完整语言实测超过当前模型单组上限，先在完整语义停顿处规划下一分镜组并报告风险；只有得到明确批准才能跨组，并必须建立不同镜头的转场桥。禁止擅自删改原文、重复起句或从一个词语中间截断。

- 每个承载对白、内心独白、旁白、画外音或系统语音的计时镜头，在全部描述最后追加：`视频严禁出现台词、内心独白与系统语音字幕。`

正式格式及示例见 [纯净视频提示词格式](references/prompt-format.md)。

需要查看完整做法时，按任务类型读取 [可执行案例索引](references/examples/index.md)。案例用于理解决策方式，正式输出仍以当前剧本、资产和模型配置为准，禁止机械替换案例角色、招式、特效、焦段、镜头数量或时长。

## 全局控制提示词与资产绑定

- 每个独立视频生成任务的正文第一行必须是项目已经锁定的 `【全局固定画质参数】`，并完整粘贴该项目全部全局控制段；不得写“同前”。可按用户指定风格选用 [仿真人古装预设](references/global-live-action-period-prompt.md) 或 [写实3D国漫预设](references/global-3d-prompt.md)；不匹配时由本技能建立相应风格全局段，所有项目仍走同一导演流程。

- 全局控制段结束后、`【摄影机运动总设定】`之前，必须逐行写本分镜组实际需要的资产绑定槽。即使 Patrick 暂时不要求跑资产列表，也不能省略提示词内的资产绑定。

- 有发声任务的角色使用 `沈知砚=沈知砚音色=`；只出镜不发声的角色使用 `沈有粮=`；场景、实际机位、书本、旱烟杆等道具和必要声音分别写 `标准名称=`。只列本组实际调用项。

- 已提供成品资产时，绑定名必须逐字采用资产锚定包的标准名称；逐镜空间、光线、角色外观和道具状态必须服从已核验内容。单张场景图没有证明的图外方位不得擅自补成完整户型，摄影机不得穿墙、穿家具或进入未确认区域。

## 所有风格的纯净提示词

- 所有风格均完整复写当前项目全局段，不得缩写为“同前”。已有 [3D漫剧全局固定提示词](references/global-3d-prompt.md) 是写实3D国漫预设；用户选其他3D风格、2D或仿真人时，按通用风格适配生成对应版本，不能强套该预设。

- 各种风格都按剧情选择摄影机与光学表达。焦段和术语同时写成可见画面；仅项目确已锁定50mm基准时才默认继承50mm，不按风格硬分配焦段。局部偏离后恢复该项目的摄影基准。

- 全局禁止任何可读文字。剧情确需UI文字时，只在对应镜头局部放行指定UI资产和准确文字，继续禁止其他文字。

- 全局段后直接写资产绑定区：有音色的角色使用 `顾平生=顾平生音色=`，仅出镜角色使用 `叶晚星=`，场景、机位、子资产、道具、特效、UI和声音各用标准名称加等号。

- 执行描述必须反复使用角色、场景、道具和特效的标准名称；对白之外禁止用“他、她、它、对方、那个东西、这里”等模糊指代。

- 运镜写清摄影机起点、轴线侧、路径、速度、停止位置和最终焦点；一个镜头只安排一个主要运镜。

- 所有视觉形态的最终编译均保留导演已选的固定、运镜与切镜表达：运动镜头将触发事件、起止构图与运动过程写入对应计时镜头；固定镜头保留镜内推进。不得因对白、保持稳定或缩短提示词而默认改成固定。“摄影机运动总设定”与逐镜运动不得互相抵消。具体编译与复核见 [纯净视频提示词格式](references/prompt-format.md)。

## 声音

读取 [声音设计](references/sound-design.md)。每集按剧情段落安排对白与画外音、BGM（背景音乐）、环境声、动作声、转场音效、剧情专用音效和有叙事作用的静默。

- BGM不能整集无差别铺满；按情绪阶段进入、变化、停止或切换，并在对白时避让。

- 分镜阶段先做声音蓝图；粗剪后必须按真实时间码形成最终声音执行表。

- 视频模型全局提示词继续禁止生成BGM，后期声音安排不混入纯净视频正文。

## 审核与状态

长期项目按 [审核与状态闸门](references/audits-and-state.md) 分别进行原文忠实度、资产覆盖合理性、连续性与可生成性三轮审核。三轮全部通过后才能标记可生产。

审核必须额外检查：是否先询问并锁定项目集时长策略、是否合理接近软目标、是否凑时长、是否在当前模型上限内按完整事件自然分组、是否因固定组数或时长目标挤压表演、是否存在无效静止、逐镜语言片段能否逐字拼回原文、第一片段是否由动作或现场事件触发、后续片段是否无停顿承接、是否另列了独立计时音轨、是否把分镜组整段时间误写成一个长镜头、普通对话单镜是否无批准超过6秒、是否无批准跨组拆同一句，以及分镜组之间的场景、站位、轴线、光影和声音是否连续。

同时逐对检查每个分镜组的尾镜与下一组首镜：前组必须写出转场方法和连续锚点，后组必须兑现；镜头签名不得相同，默认不得让同一人物特写硬接同一人物特写。

同时检查每个独立提示词是否完整包含项目全局控制段；本组实际角色、发声音色、场景和道具是否都在`【摄影机运动总设定】`之前建立等号绑定，且没有把未使用资产塞入绑定区。

同时检查人物表演方案是否具有目标、阻碍、策略变化、听者反应和状态继承；每个镜头是否覆盖所有画面内人物，背景人物是否具有克制但可见的表情语言或动作语言；镜头执行检查是否逐镜覆盖第一帧、世界位置、画面位置、身体朝向、视线目标、地标距离、道具左右手、摄影机轴线、主光方向、动作物理和每个相邻切点。专业模块返回 `ERROR` 时不得标记可生产。

同时检查：是否先完成场景诊断、每个镜头是否写明存在理由、专业库输出是否越权改变剧情、题材包是否满足调用条件、动作与特效是否有完整因果、状态账本的出组状态是否被下一组继承。

## 当前任务人物与镜头节奏

- 离场且本组不再出镜、发声或参与动作的人物，只留内部状态账本；最终提示词的绑定、起始站位、镜头描述与禁止项均不点名排除。原文语言中的人名照录，不能因此把提及者绑定入镜。

- 非脸部特写最多2秒，不用静止手、棍、书页或衣袖承载整段长台词，不机械拆成连续短特写。用表情、听者反应和少量必要中景、全景承接语言与动作。

- 详细编译规则与内部人物清单校验见 [场景稳定与逐镜执行](references/scene-stability.md)。

## 输出与安全

- 默认使用Markdown；需要Word或Excel时生成对应文档并完成可视化校验。

- 不为角色、场景、道具、镜头或声音创建面向人的英文缩写编号；使用原文标准名称。

- 涉及内容改写、真人、声音、音乐、商用或平台规则时读取 [安全与版权](references/safety-and-rights.md)。不承诺一定生成成功或一定过审。

## 所有风格的情绪可见变化

所有风格项目中，情绪变化必须编译为可见的角色表演；具体部位、幅度和质感服从角色资产及风格，不能把文学比喻作为视觉执行指令。适用于眼神、面部颜色、肌肉、呼吸和身体反应；原文对白、旁白和内心独白逐字保留，只改写其外侧的表演说明。剧情明确要求的超自然变化按剧情单独处理。

- 每个变化写清：触发事件或关注对象 → 具体部位与动作 → 幅度及发生过程 → 镜尾保留状态。选择当下最有效的2—4个信号，不为补字段增加多余动作。

- “眼睛放亮、眼里冒火、脸红、脸色铁青、石化”等词不能独立承担视觉说明；最终动作描述直接用具体效果替换，不把危险比喻再抄在括号中。情绪标签可辅助语气，不能代替表演。以下写实细节仅作具体呈现示例，2D和风格化角色按已锁定线条、材质与幅度表达同样的变化，不强制真人皮纹。

- 眼神变化优先写注视目标、眼睑开合、眉间松紧、眨眼和视线停留。虹膜、瞳孔、眼白维持既有外观；眼中反光只来自已锁定场景光源，不因兴奋增加亮度或光效。

- 肤色变化确有剧情需要时，写清局部位置、低强度、自然过渡以及基础肤色保留。羞赧通常只在耳廓或颧部出现淡淡红润，不能扩散成整脸均匀红色，不改变眼白、嘴唇、颈部及全身颜色。暗光或远景难以读出时，优先用避视、抿唇、低头等动作，不加强红色或改变曝光。

- 强烈情绪由目光、呼吸、姿态和声音力度共同表现，不靠放大眼球、改骨相、拉伸五官、肤色突变或全身抽动。具体幅度服从原文，不将所有表演压成同一种微笑或微动作。

- 切镜继承已经形成的表情与局部肤色状态，不每镜重新由零变红、叠加饱和度或自动恢复。角色身份、年龄、基础肤色、妆容和场景光影保持锁定。

- 交付前逐镜人工检查上述歧义：动作文字被按字面画出来时是否仍符合已锁定的风格与角色身份；若产生未要求的发光、涂色、变形或特效，先重写正向表演，再针对实际风险加一句局部限制。不要把所有限制复制成每镜长负面词表。

## 局部外观变化与跨镜继承

局部变化的部位、原因、程度和跨镜继承适用于所有风格；以下人体皮肤示例按角色实际结构选用。写实风格保留真实皮纹，2D按既有线条与色块表现，风格化3D按既有材质与表情幅度表现，不强加毛孔或写实解剖。基础肤色来自角色资产；红润、压痕、淤青、黑眼圈都是原皮肤上的局部状态，不替换为一块新的纯色材质。

- 有剧情依据才加入身体变化，不为表现情绪额外增加淤青、血丝、肿胀或伤痕。原文语言保留；视觉说明把概括展开为具体效果。

- 每次写清具体部位、相对范围、相对原肤色的色差、强度、边缘过渡及发生或继承状态。按镜头可读性选择必要细节，不机械填表、不靠精确色号表达人体颜色。

- 局部颜色低于纯色涂抹的饱和度，保留皮肤纹理、掌纹、皱褶及既有光照明暗；过渡自然且不规则，周围仍是原肤色。肤色较深时优先用细微色调、局部明暗及有依据的质感差异表现，不统一套粉红、紫蓝或灰白色。

- 手掌发红：按实际触碰或摩擦区域呈现轻微不均匀红润，掌纹可辨、边缘渐淡；没有全掌受刺激的依据就不扩大到全掌、手背或手臂。其他部位同样按实际受影响范围限定。

- 淤青：只有原文或已锁定伤情需要时呈现，在明确受伤位置形成边缘模糊、不规则的低饱和暗红紫或青褐色差，原肤色从边缘及较浅区域仍可见。颜色和范围服从已确认伤情与经过时间，不随切镜换色、扩大或自动增加肿胀，不自行推断精确伤龄。

- 黑眼圈：限定在下眼睑至眼下浅沟的区域，表现为相对原肤色稍深的灰褐或低饱和青褐暗影，靠近下睑较明显，向面颊自然渐淡；保持原皮肤纹理。原文要求浓重时增加相对深浅，仍保留渐变，不画成环绕眼眶的纯黑圈，不把眼白、额头和整片面颊染黑，不用淤伤替代疲惫。

- 不把生理颜色当作灯光效果：皮肤局部色差随原场景照明呈现，光源、曝光、白平衡不因该变化改变；暗处看不清时不提高饱和度、不让皮肤自发光。颜色状态与阴影分别记录。

- 切镜后继承部位、范围、程度和纹理，衣物遮挡时无需强行露出。出现、加重或消退须有剧情与时间依据；禁止重复叠色，也不能几秒内无因消除既有淤青或黑眼圈。

- 交付前检查：去掉情绪词，仅按视觉说明生成，是否会像油漆、妆面色块、黑眼罩或全身换肤？若会，返修为原肤色上的局部自然色差。少量针对性限制用于消除实际歧义，不给每镜堆全身负面清单。

示例（按剧情选用，不自动新增状态）：

- 手掌受摩擦后：掌根接触处比原肤色略红，范围局限在接触区，掌纹清晰，红润边缘逐渐融入周围皮肤；手背颜色保持原样。

- 已有前臂淤青：前臂外侧原伤处保留一小片不规则、低饱和青褐色差，中央略深、边缘渐淡，皮纹和侧光阴影仍连续；不新增肿块。

- 疲惫的重黑眼圈：两侧下眼睑下方保留明显但低饱和的灰褐暗影，向面颊柔和减淡，眼白和上眼睑保持原外观，脸颊仍是角色原有肤色。

## 逐句表演保真检查

每句语言必须落实“情绪是什么 → 对谁、想达到什么目的 → 用什么语气说 → 身体怎么配合”，写入实际承载语言的计时镜头；跨镜续说继承情绪、意图、语气和身体状态，不能只有音色与台词连续。按 [纯净视频提示词格式](references/prompt-format.md) 的逐句必查规则编译并复核，漏项先修复再交付。

## 提示词制作的读取与恢复入口

每次制作、修改或恢复分镜提示词，先读取 [提示词保真与恢复检查](references/prompt-preflight.md)，按当前分支核对规则来源、逐句表演、导演表达和最终正文。用户已确认的配置从项目记录恢复，不因上下文缩短重新猜测。交付前除格式与人物范围检查外，运行该文档规定的提示词交接校验；没有实际素材或视频证据时仅标文字方案通过。

## 通用逻辑与风格表现

本技能能力适用于两个模型、所有视觉风格、时代和画幅。风格只改变动作表情的幅度与呈现方式，不省略情绪、对象与目的、语气、身体配合、光源因果或连续性。写实示例中的毛孔、肤色和肌肉细节不强加给2D或风格化角色；已确认的动画夸张、压缩伸展或特效按具体风格执行，仍守角色身份、动作因果与前后状态。
