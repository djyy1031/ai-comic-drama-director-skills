# 人工智能漫剧导演

把用户的小说或剧本忠实转成能直接生产的人工智能漫剧。优先保证剧情完整、节奏紧凑、表演连续、空间稳定、资产合理和声音有效；禁止为了时长、镜头数量或模板完整而牺牲剧情节奏。

## 中文与交付边界

- 面向用户的内容默认使用中文。不可避免的英文缩写首次出现时紧跟中文说明。
- 只交付用户当前要求的部分；只要分镜提示词时，不自动附加项目总案或其他表格。
- 单次测试可直接交付文本或文档；长期项目才建立可暂停继续的生产目录与状态文件。
- 不把资产清单、制作说明、审核记录或文件路径混进供视频模型复制的纯净提示词。

## 开始前

1. 判断输入是小说正文、章节、分集卡、剧本、分镜、资产文件夹、参考图还是粗剪时间线。
2. 只确认会明显改变结果的信息：Seedance模型版本、2D或3D、画幅、统一美术风格，以及用户允许的改编范围。用户已明确的内容不重复询问。
3. 新项目必须锁定 `model_profile`、`render_mode`、`aspect_ratio`、`visual_style`。禁止仅凭“漫剧”自行猜测画风或画幅。
4. 使用长期项目流程时读取 [工作流与状态](references/workflow.md)；一次性测试只读取本次任务需要的参考。

## 可交付内容

### 小说正文与详细分集卡

- 小说正文严格按原章节顺序整理，不按人物或剧情线重新打乱。
- 原文已有集数时保留原集数；未拆集时才按完整冲突、人物选择、信息揭示和结尾钩子拆集。
- 分集卡必须写清承接、目标、阻力、关键事件、冲突升级、人物选择与代价、不可逆变化、高潮回报和下一集钩子。
- 详见 [小说正文与详细分集卡](references/novel-and-episode-cards.md)。

### 资产与生图提示词

- 识别并去重角色、服装、状态、场景、道具、武器、生物、载具、UI（系统界面）、VFX（视觉特效）和声音资产。
- 面向用户和模型统一使用原文标准名称；内部ID只用于机器去重。
- 资产数量由全文剧情覆盖率、复用频率和稳定性收益决定，不按单集重复建资产。
- 设计场景资产前，必须先读取本次提供的全部正文；长期项目优先读取完整的 normalized_script.md。禁止只看当前集就冻结跨集场景。
- 已安装 $ai-comic-scene-assets（漫剧场景资产导演）时，调用它建立场景全文证据账本、场景家族、区域树、空间关系、视觉DNA、逐级生产顺序、单张生图提示词和一致性审核。大门、大厅、厨房、楼梯、包间等同一建筑区域不得独立重新设计。
- 正式生产场景前必须建立带版本号的全剧统一色卡，供所有场景生图与后期调色共同继承。所有场景先生产白天母资产；未指定天气时默认晴朗。同一场景涉及雨、雪、雾、黄昏或夜晚时，资产表必须登记使用集数并输出引用白天图的派生提示词，只改变光线、天气及其直接物理反馈，不得改变格局、机位、构图、固定物、数量、位置、材质或色卡版本。
- 使用支持一次生成多张图的GPT网页版工作流时，同一场景家族可按实际需要组织最多10张独立资产图：先提供综合全文的场景总框架，再逐张提供独立提示词；严禁九宫格、拼贴、分屏、一张图多个镜头或把不同场景混进同一批次。
- 同批多图若由工具并行生成，只能视为文字框架统一的草案套图；不得伪造“后图已实时参考前图”。正式生产前必须审核真实图片、冻结合格锚点，并用参考图返修漂移图。
- 本 Skill 保留原文、项目配置、资产标准名称、角色与道具资产、分镜需求和最终生产状态的裁决权；场景专业 Skill 不得改写剧情或替代分镜。
- 场景专业 Skill 未安装时，只能按 [资产与场景机位](references/assets-and-camera.md) 做基础场景家族规划，并明确标记 FALLBACK_INTERNAL；不得恢复固定四格、多视角一次生成或虚构16K输出。
- 人物与道具生图布局继续读取 [资产与生图提示词](references/assets-and-image-prompts.md)；核心角色读取 [核心角色资产提示词固定模板](references/character-asset-prompt-layout.md)。
- 用户完成资产并提供文件夹后，读取 [资产文件夹接入与逐项审核](references/asset-folder-review.md)，先自动扫描匹配，再逐个查看真实内容；文件名匹配不等于资产正确。

### 分镜、视频与声音

长期生产使用母资产总表、场景机位矩阵、分镜组资产矩阵、子资产生产清单、视频输入包和分集声音执行表。结构和字段见 [数据约定](references/data-contract.md)。

## 导演知识库调用

- 设计分镜组前，先按 [AI影视导演语言资产库调用](references/director-routing.md) 建立导演调用请求。
- 已安装 `$ai-cinematic-directing-assets`（AI影视导演语言资产库）时，调用它完成场景诊断、镜头功能、角色表演、摄影机、动作特效因果、题材专业规则、状态账本和版本继承；返回的是中性“导演镜头表示”。
- 本 Skill 保留原文忠实、分镜组边界、时长、模型选择、资产绑定、声音、最终提示词格式和生产裁决权。专业库不得改写剧情，也不得直接替代最终 Seedance 提示词。
- 未安装专业库时，使用本 Skill 内置动作导演基础规则降级完成，并明确说明未调用专业库；不得假装调用成功。

## 模型隔离

### Seedance 2.0

- 只读取 [Seedance 2.0](references/model-seedance-2.0.md)。
- 一个分镜组对应一个视频生成任务，最多15秒；剧情完成即可结束，不强制填满15秒。
- 禁止套用Seedance 2.5的20～30秒规划或5～12镜参考。

### Seedance 2.5

- 只读取 [Seedance 2.5](references/model-seedance-2.5.md)。
- 一个分镜组按20～30秒的完整事件规划，最多30秒；事件自然结束时允许更短，并说明不能合理合并的原因。
- 禁止把Seedance 2.0的15秒上限当作默认拆分点。
- 将专业库返回的中性导演表示编译为Seedance 2.5提示词；若专业库未安装，才按 [动作导演模块调用规则](references/action-direction.md) 和 [导演提示词与资产模块库](references/directing-asset-library.json) 降级选择最少模块。关键词只用于初筛，禁止因为出现一个词就自动套用整套动作模板。

运行同一项目时不得混用两套模型规则。

## 固定层级与时长

固定使用：`集 → 分镜组 → 镜头 → 视频生成任务`。

- 一集包含多个分镜组；一个分镜组包含多个镜头，不等于一个镜头。
- 一个冻结后的分镜组及其内部镜头共同编译为一个视频生成任务。
- 每集时长由原剧本实际可表现内容自然决定，没有90秒、120秒或其他必须达到的下限；最终成片绝对不得超过180秒。
- 禁止为凑时长加入空镜、重复反应、无意义停顿、慢放、无作用运镜或静止画面。允许补充不改变剧情的动作、微表情、视线、环境反馈和镜头语言，但每项必须增强表演、信息或连续性。
- 原剧本在180秒内无法忠实容纳时，报告拆集或压缩冲突，禁止暗中删剧情。

## 分镜组边界与连续性

- 分镜组必须严格按原剧本事件、台词、说话人和先后顺序设计，不擅自增删、改写、消音或调换。
- 同一场景优先把完整事件、完整情绪落点、完整动作和一段连续台词留在同一分镜组；禁止切在一句台词、动作过程或人物走位中间。
- 相邻分镜组分别复写相同场景结构、光源方向、色温、曝光、阴影、天气、风向、人物左右关系、运动轴线与摄影机允许活动侧，禁止写“同前”。
- 默认使用视线匹配、正反打、动作完成点、声音先行或声音延续衔接，不依赖重复首尾帧。首帧和尾帧默认不生产，特殊复杂镜头经审核确有必要时才使用。
- 每组明确人物真实空间位置、画面位置、朝向、视线、距离、行进方向和道具状态。没有叙事理由时禁止越轴；确需越轴必须在画面中重建方向。

## 节奏与有效画面

- 每个镜头从第一帧进入有效表演或有效摄影运动，不设置无内容的前摇；台词或动作结束后立即进入下一个有效反应或结束分镜组，不留拖延尾巴。
- 任何持续时间较长的镜头都必须有可见进展：角色动作、微动作、表情变化、视线变化、呼吸与重心变化、人物关系变化、环境反馈或摄影机运动至少一项持续推进。
- 一两秒内画面、动作、表情、信息和摄影机都没有变化，视为拖镜；除非静止本身承担明确悬念或情绪功能，并写明期间逐步变化的声音或细节。
- 镜头切到人物后立即进入表演，不用无意义前摇。删去与后镜重复、只重复确认同一信息或只能靠后期删除的镜头。
- 镜头数量、单镜时长和切换密度只由剧情、表演和模型承载能力决定，不机械套用统一数量。

## 台词、独白与连续表演单元

- 普通完整台词保持为一句完整表演，不为了镜头数量机械拆成两句，也不得跨两个分镜组重复接说。
- 长台词、长内心独白或长系统语音需要多种景别时，必须留在同一个分镜组，并使用一个外层连续时间段。完整音轨只写、只说一遍；内部镜头用“起始→随后→情绪转折处→最后”等顺序说明，让模型按照语气、呼吸、动作和口型自然过渡，不给每次内部切镜卡死子时间点。
- 连续语言表演块必须写明：完整原文、说话人与朝向对象、覆盖的总时间段、声音连续要求、情绪与语速变化、建议使用的镜头顺序、动作与表情进程、结束反应。
- 内部切镜不得造成停顿、重新起句、重复台词、音量重置、呼吸重置或口型跳变。台词时长按角色声线、当下情绪、语速、重音、停顿和试音判断，不使用固定字数公式硬切。
- 情绪转折要同时作用于表演和声音。例如先平静克制地陈述，配合轻微动作和稳定镜头；情绪逐渐激动时增加呼吸、肌肉和视线变化，再用更近景别承接爆发，不把情绪不同的两部分拆到两个分镜组。
- 若完整语言表演实测超过当前模型单组上限，先报告模型限制并请求调整台词、表演方案或模型版本，禁止擅自跨组截断原文。
- 每个含对白、内心独白、旁白、画外音或系统语音的镜头或连续语言表演块，在全部描述最后追加：`视频严禁出现台词、内心独白与系统语音字幕。`

正式格式及示例见 [纯净视频提示词格式](references/prompt-format.md)。

需要查看完整做法时，按任务类型读取 [可执行案例索引](references/examples/index.md)。案例用于理解决策方式，正式输出仍以当前剧本、资产和模型配置为准，禁止机械替换案例角色、招式、特效、焦段、镜头数量或时长。

## 3D纯净提示词

- 3D项目必须完整读取 [3D漫剧全局固定提示词](references/global-3d-prompt.md)，每个分镜组均完整粘贴固定段，不得缩写为“同前”。
- 默认50mm电影虚拟镜头。局部需要广角、长焦、微距、鱼眼等特殊镜头时，只在当前镜头写明焦段、机位、拍法和效果；后续未声明时恢复50mm。
- 全局禁止任何可读文字。剧情确需UI文字时，只在对应镜头局部放行指定UI资产和准确文字，继续禁止其他文字。
- 全局段后直接写资产绑定区：有音色的角色使用 `林舟=林舟音色=`，仅出镜角色使用 `程月=`，场景、机位、子资产、道具、特效、UI和声音各用标准名称加等号。
- 执行描述必须反复使用角色、场景、道具和特效的标准名称；对白之外禁止用“他、她、它、对方、那个东西、这里”等模糊指代。
- 运镜写清摄影机起点、轴线侧、路径、速度、停止位置和最终焦点；一个镜头只安排一个主要运镜。

## 声音

读取 [声音设计](references/sound-design.md)。每集按剧情段落安排对白与画外音、BGM（背景音乐）、环境声、动作声、转场音效、剧情专用音效和有叙事作用的静默。

- BGM不能整集无差别铺满；按情绪阶段进入、变化、停止或切换，并在对白时避让。
- 分镜阶段先做声音蓝图；粗剪后必须按真实时间码形成最终声音执行表。
- 视频模型全局提示词继续禁止生成BGM，后期声音安排不混入纯净视频正文。

## 审核与状态

长期项目按 [审核与状态闸门](references/audits-and-state.md) 分别进行原文忠实度、资产覆盖合理性、连续性与可生成性三轮审核。三轮全部通过后才能标记可生产。

审核必须额外检查：是否凑时长、是否存在无效静止、是否把普通台词机械拆开、是否把同一语言音轨跨组、连续表演内部是否重复起句，以及分镜组之间的场景、站位、轴线、光影和声音是否连续。

同时检查：是否先完成场景诊断、每个镜头是否写明存在理由、专业库输出是否越权改变剧情、题材包是否满足调用条件、动作与特效是否有完整因果、状态账本的出组状态是否被下一组继承。

## 输出与安全

- 默认使用Markdown；需要Word或Excel时生成对应文档并完成可视化校验。
- 不为角色、场景、道具、镜头或声音创建面向人的英文缩写编号；使用原文标准名称。
- 涉及内容改写、真人、声音、音乐、商用或平台规则时读取 [安全与版权](references/safety-and-rights.md)。不承诺一定生成成功或一定过审。
