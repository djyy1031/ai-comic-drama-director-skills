# 原创测试示例

下面的简短案例只用于验证工作流，不对应任何现有小说或影视作品。

## 输入剧本

```text
第1集
1-1 夜 内 综合训练教室
出场人物：林舟、苏澄

停电后的教室只亮着应急灯。讲台上的练习长剑忽然轻轻震动。
苏澄压低声音：“林舟，你听见了吗？”
林舟示意苏澄留在原地，独自沿中央过道靠近讲台。
长剑骤然离开桌面，剑尖转向林舟。
林舟侧身避开，抓住剑柄，发现剑身浮现一枚发光印记。
系统提示：获得临时技能“破风斩”，持续十分钟。
门外传来急促脚步声，两人同时看向后门。
```

## 推荐调用方式

```text
请使用 $make-ai-comic-drama 处理以上原创剧本。
模型使用 Seedance 2.5，16:9，3D 国漫美型 CG 风格。
走完整流程，但每一步先给审核摘要；剧情自然结束，不为凑时长拉长镜头。
```

## 预期检查点

- 将“长剑异动—躲避—夺剑—技能出现—门外来人”视为完整事件链，不机械按固定秒数拆散。
- 明确教室轴线、角色站位、长剑运动路径和下一组可继承的结束状态。
- UI（用户界面）只允许显示指定技能文字，其他画面禁止任何可读文字。
- 对白镜头末尾带固定禁字幕句。
- 资产清单至少覆盖角色、角色音色、母场景、主机位、练习长剑、技能视觉特效、系统面板和系统提示音。
