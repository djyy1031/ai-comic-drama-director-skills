# AI 漫剧导演 Skills

一套面向 Codex 的人工智能漫剧生产技能包，把小说、章节或剧本整理为可审核、可继续生产的项目，并生成适配 Seedance 2.0 / 2.5 的资产方案、分镜组、连续镜头提示词和分集声音设计。

> 当前公开版：人工智能漫剧导演 v2.3.0 + AI 影视导演语言资产库 v1.0.0。

## 包含内容

- `make-ai-comic-drama`：主流程 Skill，负责原文整理、分集、资产规划、分镜组、视频提示词、连续性审核、资产文件夹接入和声音设计。
- `ai-cinematic-directing-assets`：专业导演知识 Skill，负责场景诊断、镜头功能、人物表演、摄影语言、动作动力、特效因果、空间连续性和题材专业规则。

两者配合时，主流程 Skill 负责生产裁决，导演语言资产库只提供可调用的专业镜头方案，不擅自改写剧情。

## 主要特点

- 固定生产层级：集 → 分镜组 → 镜头 → 视频生成任务。
- Seedance 2.0：单个分镜组最多 15 秒，剧情完成即可结束。
- Seedance 2.5：优先按 20～30 秒完整事件规划，最多 30 秒；无法合理合并时允许更短。
- 每集时长由剧本信息量决定，禁止为了凑时长拖镜头；单集不超过 180 秒。
- 长台词保留为同一连续音轨，在同一分镜组内自动切换景别，避免跨组断句。
- 锁定轴线、站位、光影和前后状态，默认不依赖首尾帧硬接。
- 资产按剧情覆盖率、复用频率和稳定性收益生产，不强制每个场景制作固定数量机位图。
- 视频纯净提示词与资产清单、制作说明、审核记录分层输出。
- 支持 UI（用户界面）、VFX（视觉特效）、系统语音、音色、环境声、动作声和 BGM（背景音乐）的分集规划。

## 安装

### 方法一：下载发布包

在仓库的 Releases（版本发布）页面下载两个独立压缩包，并分别导入 Codex：

1. `make-ai-comic-drama-v2.3.0.zip`
2. `ai-cinematic-directing-assets-v1.0.0.zip`

完整流程建议两个都安装。只安装主流程 Skill 也能运行，但专业导演语言会使用内置基础规则降级完成。

### 方法二：从源码安装

将 `skills` 目录下的两个 Skill 文件夹复制到 Codex 的个人 Skills 目录，然后重新加载 Codex。

## 使用示例

完整制作：

```text
请使用 $make-ai-comic-drama，把下面剧本按 Seedance 2.5、16:9、3D 国漫美型 CG 风格走完整流程。先输出分集判断、资产清单和分镜组规划，审核通过后再生成纯净视频提示词。
```

只调用导演知识：

```text
请使用 $ai-cinematic-directing-assets，分析这场双人对峙的轴线、镜头功能、人物表演和特效因果，不改写原台词。
```

详细输入与输出示例见 [examples/README.md](examples/README.md)。

## 验证

两个 Skill 都带有结构校验和自动测试。修改后请运行各自的 `tests`，并确认 `SKILL.md`、引用文件、模板和脚本没有缺失。
