# AI 漫剧导演 Skills

一套面向 Codex 的人工智能漫剧生产技能包。既可以把小说、章节或剧本整理为可审核、可继续生产的完整项目，也可以只生成适配 Seedance 2.0 / 2.5、可直接复制使用的分镜组提示词文档。

> 当前源码版：人工智能漫剧导演 v3.0.0 + 人物表演资产库 v1.6.0 + AI影视导演语言资产库 v1.9.0 + 镜头执行与连续性检查库 v1.8.0。其他三个技能保留现有版本。

## 包含内容

- `ai-storyboard-blocking-assets`：制作和复用分镜组站位参考图，用户只要文字时不生成图片。

- `make-ai-comic-drama`：主流程 Skill，负责原文整理、分集、资产规划、分镜组、视频提示词、连续性审核、资产文件夹接入和声音设计。
- `ai-storyboard-asset-grounding`：成品资产证据 Skill，负责真实查看用户已完成的场景、角色、道具和声音资产，并锁定分镜使用的空间、身份、状态和绑定名。
- `ai-character-performance-assets`：人物表演 Skill，负责人物目标、策略变化、身体行为、听者反应、背景人物表演、语言动作触发、跨镜状态继承，并提供70条可按需调用的表情动作参考。
- `ai-comic-scene-assets`：场景资产专业 Skill，负责全文扫描、场景家族、空间关系、统一色卡、白天母资产、时间天气变体和跨集一致性生图提示词。
- `ai-cinematic-directing-assets`：专业导演知识 Skill，负责场景诊断、镜头功能、人物表演、摄影语言、动作动力、特效因果、空间连续性和题材专业规则。
- `ai-shot-execution-continuity`：镜头落地检查 Skill，负责第一帧、站位、身体朝向、视线、道具手、摄影轴线、光线方向、动作物理、切点和语言承接检查。

普通分镜提示词默认使用轻量七步流程：当前剧本 → 确认本次参数 → 分析用户资产 → 表演与节奏 → 导演复核 → 连续性检查 → 逐镜提示词与声音。缺项直接问，不检索旧配置，不自动生成资产或成套中间表。复杂任务才加载对应专业参考；所有技能保留完整项目能力。

## 主要特点

- 固定生产层级：集 → 分镜组 → 镜头 → 视频生成任务。
- Seedance 2.0：单个分镜组最多 15 秒，剧情完成即可结束。
- Seedance 2.5：单个分镜组最多 30 秒，按完整事件自然结束；与2.0共用导演逻辑，不设最低时长或固定组数。
- 每集时长服从本次用户目标和剧情信息量，不设默认最低时长，不凑时长。
- 支持 `STORYBOARD_PROMPTS_ONLY`：只生成分镜组提示词文档，不自动附带资产列表、Excel、声音表或完整项目目录。
- 支持“剧本 + 已完成资产”直出分镜：文件名只负责定位，必须查看真实内容并锁定场景结构、角色身份、道具状态和声音绑定。
- 单张场景参考图不虚构画外户型或世界方位；镜头机位和运动必须服从已确认空间，禁止穿墙、穿固定家具或进入未知区域。
- 景别、摄影机位置、主要运镜和光学手法分层表达；动作加入身体路径、微动作与听者反应，特效必须有剧情与物理因果。
- 台词、内心独白、旁白和画外音直接写入承载它们的计时镜头：第一片段切镜0.5秒内开口且动作同步，后续镜头无停顿承接；禁止另列覆盖整段时长的独立语言音轨。
- 普通对话镜头以2～5秒为主，默认不超过6秒；禁止把20～30秒分镜组误写成一个长镜头。
- 长语言可跨多个正常镜头连续说完，但逐镜片段拼接后必须逐字等于原文，默认禁止跨分镜组拆一句。
- 所有画面内人物都必须有符合处境的表情、视线、呼吸、姿态或动作反应，包括背景人物。
- 每个独立分镜组完整复写全局控制提示词，并在摄影机设定前保留本组角色、音色、场景和道具的等号绑定槽。
- 锁定轴线、站位、光影和前后状态，默认不依赖首尾帧硬接。
- 资产按剧情覆盖率、复用频率和稳定性收益生产，不强制每个场景制作固定数量机位图。
- 同一建筑先建立完整场景家族和空间连接，再按需生成最多10张独立场景图；禁止九宫格、拼贴和把同一地点重新设计成多个场景。
- 场景先建立全剧统一色卡和白天母资产；雨、雪、雾、黄昏、夜晚按使用集数登记，并引用白天图只修改光线和天气。
- 视频纯净提示词与资产清单、制作说明、审核记录分层输出。
- 支持剧情所需UI、视觉特效、系统语音、环境声、动作声与点缀音效；BGM由用户后期处理，未经明确委托不规划或生成。

## 安装

### 方法一：历史发布包（不含2026-09-22更新）

本次更新已提供源码；请用下面方法二或方法三安装最新版本。以下压缩包保留为旧版归档：

1. [人工智能漫剧导演 v2.14.0](releases/make-ai-comic-drama-v2.14.0.zip)
2. [人物表演资产库 v1.5.0](releases/ai-character-performance-assets-v1.5.0.zip)
3. [AI 影视导演语言资产库 v1.8.0](releases/ai-cinematic-directing-assets-v1.8.0.zip)
4. [镜头执行与连续性检查库 v1.7.0](releases/ai-shot-execution-continuity-v1.7.0.zip)
5. [分镜资产接入与空间锚定库 v1.0.1](releases/ai-storyboard-asset-grounding-v1.0.1.zip)
6. [漫剧场景资产导演 v1.3.1](releases/ai-comic-scene-assets-v1.3.1.zip)

7. [分镜组站位资产 v1.1.1](releases/ai-storyboard-blocking-assets-v1.1.1.zip)

文件校验值见 [SHA256SUMS.txt](releases/SHA256SUMS.txt)。

只制作分镜组提示词时至少安装前四个 Skill；要让已有场景、角色、道具和声音资产真正约束分镜，再安装第五个成品资产接入 Skill。需要规划或生产新场景资产时安装第六个场景资产 Skill。只安装主流程 Skill 也能降级运行，但不会获得完整的专业能力。

### 方法二：从源码安装

将 `skills` 目录下需要的 Skill 文件夹复制到 Codex 的个人 Skills 目录，然后重新加载 Codex。

### 方法三：在另一台电脑直接从 GitHub 安装

公司电脑打开 Codex 后，直接发送下面这段话；系统自带的 `$skill-installer` 会从本仓库安装五个分镜 Skill：

```text
请使用 $skill-installer，从 GitHub 仓库 djyy1031/ai-comic-drama-director-skills 的 main 分支安装以下目录：
skills/make-ai-comic-drama
skills/ai-character-performance-assets
skills/ai-cinematic-directing-assets
skills/ai-shot-execution-continuity
skills/ai-storyboard-asset-grounding
```

安装完成后的下一轮对话即可调用。如果电脑上已经存在同名旧版文件夹，请先关闭 Codex，把 `%USERPROFILE%\.codex\skills\` 中对应旧文件夹改名备份，再重新执行安装。

## 使用示例

完整制作：

```text
请使用 $make-ai-comic-drama，把下面剧本按 Seedance 2.5、16:9、3D 国漫美型 CG 风格走完整流程。先输出分集判断、资产清单和分镜组规划，审核通过后再生成纯净视频提示词。
```

只生成分镜提示词：

```text
请使用 $make-ai-comic-drama，根据我本次给出的剧本、参数和资产制作分镜提示词。缺少画幅、模型、画风或全局约束时先问；我确认没有资产后按剧本安排空间。先优化表演和节奏，再调用导演技能复核，最后检查连续性。对白切镜后0.5秒内开口，动作表情同步；写清具体人物、机位和逐镜声音，不添加背景音乐。提示词直接发在聊天中。
```

只调用导演知识：

```text
请使用 $ai-cinematic-directing-assets，分析这场双人对峙的轴线、镜头功能、人物表演和特效因果，不改写原台词。
```

只制作跨集一致的场景资产：

```text
请使用 $ai-comic-scene-assets，读取完整剧本，先建立全剧色卡、场景家族和白天母资产，再生成逐张独立场景图提示词，并登记雨天、黄昏和夜晚版本的使用集数。
```

详细输入与输出示例见 [examples/README.md](examples/README.md)。
